# 第六十九章 深夜的遗失

关系记录被盗后的第一夜，城里没有发生袭击。

人们只是开始给不该开门的人开门。

一个使用旧同僚声音的复制体进入军械库，守卫明知面孔陌生，却本能地认为对方值得信任。另一具复制体来到医站，只说一句“她以前允许我代领”，药师便交出
本应双重核验的药物。

最早报告异常的是蕾贝尔。

午夜过后，她在复制站外看见一名已经死去多年的侍从。那人外貌并不完全相同，甚至没有使用旧声音，却让她产生一种强烈确信：自己曾允许他在任何时候进入卧
室。

她拔刀割伤手掌。

疼痛没有使亲近感消失。

“它们偷的不是记忆。”她说，“是记忆后面的许可。”

我们把城内关系分成可以说出的部分。

谁能进入家门，谁可代领药物，谁的话无需再次核验，谁在危急时有权替自己作决定。这些许可平日很少被写下，却比姓名更直接地维持生活。

复制机制从档案、通信与旁观记录中拼出它们。

只要足够多人曾看见某人被允许靠近，它便能复制那种“他本来就应该在这里”的感觉。

深夜里，城门一座接一座自行开启。

没有守卫叛变。

每个人都相信自己正在执行一段早已存在的关系。

克鲁斯下令全城停止依据熟悉感放行，所有许可改用临时口令。命令刚发布，一具复制体便使用他的声音重复另一条更严厉的版本，要求拘捕所有无法证明关系者。

两道命令都像他。

第二道甚至更符合人们对秩序军政的想象。

克鲁斯亲自来到街上，没有要求众人仅凭真身面貌相信自己。他公开说明命令来源、承担者与撤回条件，并允许边站回查。复制体只会重复最绝对的部分，无法解释
以后由谁负责。

这成为第一处差异。

蕾贝尔则面对自己的旧部。

一支红衣队伍在城南集结，声称遵从嗜血女爵归来。他们不是复制体，而是真实的人。关系记录使他们重新感到旧誓仍然有效，仿佛多年分离与背叛从未发生。

“你可以重新带领我们。”领队说。

蕾贝尔看着那些熟悉面孔。

她没有否认过去曾接受他们效忠，也没有把所有责任推给复制机制。

“那份誓约结束了。”

“你没有正式解除。”

“因为当时我只顾着逃。”

“那我们算什么？”

这个问题比复制体更难处理。

真实关系也会因没有好好结束而成为可被利用的入口。蕾贝尔不能只说那不是现在的我，因为那些人确实替过去的她承担过后果。

她在城南当众解除旧誓，并承诺对未结报偿逐项清算。有人接受，有人愤怒离开，还有三人仍坚持称她女爵。

关系没有因一句解除立刻消失。

至少它不再被当成永远有效的默认许可。

城中临时建立三次确认。

熟悉感只能触发询问，不能直接放行；旧口令必须说明最后一次有效时间；涉及身体、财产与武器的替代决定，需要本人或持续见证重新确认。

这套办法极慢。

医站门前排起长队，军械调度几乎停止，许多真正亲密的人也因被要求核验而感到羞辱。一名父亲对守卫怒吼，自己照顾女儿十二年，凭什么今日还需证明可以进病
房。

女儿从床上回答：“让他进。”

一句当下的同意，比十二年份被盗走的关系记录更有效。

午夜将尽时，复制体改变方式。

它们不再冒充具体亲友，而开始拆分关系。一个复制体拥有母亲的担忧，另一个拥有伴侣的亲密，还有一个只复制下属对命令的服从。它们没有完整身份，却能分别
打开不同的门。

我们无法再问“你究竟是谁”便解决。

必须问“你正在使用哪一种关系，以及本人是否仍然允许”。

黑书记追踪被盗资料，发现所有关系记录都流向高空。

不是任何城塔，也不是天界。

它们沿一条早已停用的星路离开世界，像有人在极遥远处收集现世不断拆分的人格部件。

最后一扇被打开的门属于星路观测站。

值守者没有受伤，只失去一段关于“为什么必须关闭此门”的记忆。门外没有复制体，只有一小撮不断发光的宇宙尘。

尘埃排列成斯菲尔曾使用的契约节奏。

宙灵兽已经在归途。

它带回的东西，比被盗记录更加古老。
