# 第二十七章 宙灵兽契约

斯菲尔理解潮汐、轨迹和声音，不理解所有权。

天界最初送来的契约写满“领空”“许可”与“越界”。斯菲尔只听了开头，暗面便吞掉半页光文。克鲁斯承认失败，把契约交给我。

我们改用古歌。

九枚星屑负责标记世界能够承受的光暗范围，锁骨天梯以开合节律表示天界流量，斯菲尔则用低鸣回应自己的需求。里斯本从以太层观察重力变化，将每一次共鸣转换成可供凡人理解的曲线。

第一次演奏，天梯节律太快，斯菲尔误以为遭到驱逐，暗潮压低了整座倒影城。

第二次，九枚星屑过度分散，祖核旧伤险些再次张开。

第三次，我们没有要求斯菲尔永远遵守固定边界，只约定三个可以识别的信号：光暗失衡时发出三段低鸣；需要进入天梯范围时先绕行一周；任何一方无法维持约定，先退回星环而不是继续吸收。

斯菲尔以自己的灰色伤痕回应。

它从伤痕中剥下一枚细小星核，悬在天梯与世界之间。星核会记录双方每一次能量交换，不判断背叛，只保存发生过的偏离。

这便是宙灵兽的签字。

天界同盟也将一枚锁印交给星核。里斯本提醒，契约并不能确保和平，只能让失衡在造成毁灭前被看见。

“若它仍然越界呢？”有人问。

“那就先判断是恶意、误读，还是它根本没有其他活路。”我说，“记录过的约定不是不会破裂，而是破裂后仍能找到从哪里开始修复。”

斯菲尔在天幕上完成第一周绕行。古歌沿锁骨天梯传入天界，又由倒影城的夜间镜面反射到地底。穆拉姆的沉眠虫卵、科尔托的蜂群和远方星屑都短暂回应。

世界第一次拥有跨越诸界的共同节律。

可星核记录的第一项偏离并不来自斯菲尔。

天界一侧有人暗中提高了光流，试图借斯菲尔净化凡界深渊。控制指令藏在一枚古老符号里，只有重新点燃旧符文炉，才能知道它替谁说话。
