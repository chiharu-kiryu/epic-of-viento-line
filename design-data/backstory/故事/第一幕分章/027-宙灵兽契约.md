# 第二十七章 宙灵兽契约

斯菲尔不肯落地。

他沿天界同盟上空盘旋了三日，每次靠近月律塔便改变形态。人们有时看见巨兽，有时只看见一片移动星影，还有人坚持那是一条由声音构成的长蛇。

宙灵兽没有固定外貌。

他以经过不同星域时保存的节奏维持自身。若一个地方只允许一种形状，斯菲尔便宁愿不进入。

天界同盟需要他的星路。

祖核碎片出现以后，许多古神遗物开始向天外发送信号。若没有斯菲尔引导，那些信号会在世界边缘不断回返，最终像失重灾难一样压向现实。

克鲁斯提出契约。

斯菲尔没有回应文字。

他绕塔一周，发出三段不同频率的低鸣。月律团把第一段解释为同意，地核工会却认为那只是测量回声。

蒂莉帕带来一只旧星鼓。

她没有试图翻译，先把斯菲尔的三段节奏原样敲回。第三次敲击时，她故意漏掉末尾一拍。

斯菲尔立刻停下。

他俯冲到塔顶，巨大的星影几乎覆盖所有人。

蒂莉帕没有后退。

“你在意缺掉的部分。”她说。

斯菲尔以星光敲响鼓面。

漏拍得到补全，随后又出现一段新的节奏。

这成为他们最初的交流方式。不是把宙灵兽语言翻译成人类句子，而是先承认节奏变化本身有意义。

契约谈了七日。

斯菲尔拒绝“效忠”，也拒绝成为天界坐骑。他愿意开放星路，是因为信号回返同样会伤害他。每一段无法抵达的古神呼唤都在他的身体里留下重复震动，使他逐渐分不清哪些节奏属于自己。

“你也在被复制。”我说。

星鼓响了一长两短。

蒂莉帕译作：“我在被经过。”

这比复制更准确。

斯菲尔并不害怕别人留下痕迹，他害怕所有经过自己的声音最终被误认为他的声音。

契约因此不写永久身份。

天界同盟可以请求通行，不能把星路称作领地。

斯菲尔可以拒绝开启，也可以在旅途中改变形态。

任何信号抵达星路前，必须保留来源；经过斯菲尔以后产生的变形，不得自动归为原发送者意图。

最重要的是三段节奏：

第一段允许接近。

第二段表示拒绝。

第三段切断双方连接。

克鲁斯认为第三段太容易使整个世界失去星路。

“若危机发生时他离开呢？”

蒂莉帕反问：“若没有离开的能力，这叫契约还是囚笼？”

斯菲尔在高空等待。

百叶没有以创世者身份保证世界不会滥用。千花也没有用梦读取他的真实意愿。他们只作为见证者，承认自己无法替双方预测未来。

最终，星核被放在月律塔顶。

它不是控制核心，而是一面能够记录节奏差异的鼓。斯菲尔每次开放星路，星核只保存本次同意，不把一次允许延伸为永久许可。

契约签署时，他第一次落地。

星影收拢成一只比马略大的深色兽形，背部仍流动着遥远星光。蒂莉帕走近，按照约定先敲接近节奏。

斯菲尔回应。

她把手放在他额前。

不是驯服。

只是一次被双方确认的触碰。

星路随即打开。

无数古神信号从世界边缘涌入。斯菲尔将它们分成不同节奏，引向能够承受的位置。天界同盟第一次看见世界之外的广阔路径，也第一次拥有与远方互通的能力。

所有人都在庆祝。

只有崧科发现星核多出一圈微弱回声。

每当现世沿斯菲尔进入星路，星路也会保存现世留下的节奏。契约规定双方都能切断，却没有说明那些已经进入对方身体的痕迹如何退出。

“要暂停吗？”崧科问。

斯菲尔看着已经疏散的古神信号。

一长，一短。

继续。

他知道风险。

也选择先解决眼前正在发生的回返灾难。

我把多出的回声写进契约附页，没有称它为失败。

后来，身份碎片正是沿这圈回声进入旧星路；斯菲尔也因此必须远行，把现世留下的东西一段段追回。

那不是契约遭到背叛。

是连接从来都不只允许一方经过。
