# 第四十九章 监视者的第一次缺席

西尔西斯从不迟到。

准确地说，人们早已忘记观测也可能缺席。他的目光覆盖道路、仓库与边界，隐身者会显形，异常信号会被标出。许多流程表面上由四方运行，最后却都依赖一句“
监视者已确认”。

他缺席一个时辰后，整个系统开始停滞。

军政不敢放行车队，商联拒绝进入无视野区，地核工会暂停地下作业，月律团则不断扩大侦测光，反而使普通居民无处保留隐私。

我取消“西尔西斯确认”这一必填项。

每处改由三种不完全观察交叉：现场人员目击、设备记录、事后可复查痕迹。三者都不如监视者迅速，却不会因为一双眼睛闭上便全部失效。

第一批替代记录人来自最不起眼的位置。

守门人知道谁在异常时段进城，药仓搬运者记得哪些箱子重量不对，边民能从动物迁移判断地下动静。他们过去只是被观察的对象，如今第一次成为观察体系的一部
分。

结论变慢，误报却比预想更少。

第二个时辰，三份记录同时指向低地废港。那里没有复制体踪迹，却持续出现西尔西斯的观测副波。有人把他囚禁在港区，用他的能力扫描全境。

营救队没有等待监视者替自己确认路线。

齐草标出可逆道路，里卡尔使用月光短距探查，商联车夫提供废港暗道。每个人只看见一部分，拼在一起仍足够行动。

临行前，西尔西斯的声音突然从所有观测设备中响起：

“不要来。”

语调完全准确，内容也可能是复制。

我们没有服从，也没有忽略。我把它标为未经本人二次确认的高风险警告。

低地废港已经燃起长达数里的白色火线。

一名天使骑士独自站在火中，把每一个试图穿越的复制体重新推回港内。他的盔甲正在熔化，背后却仍保持一条供平民撤离的窄路。

那条路随时会断。
