# 第十三章 深渊开裂

黑色阶梯并非人工开凿。

每一级都像某种巨大生物脱落的甲片，踩上去会传来迟缓的搏动。石匠走在最前，只下了二十级便停住。他将灯贴近墙面，火光竟被岩石一点点吞没。

“这不是井。”他说，“井有底，也有回声。”

这里两者都没有。

我们系上三条绳索继续下降。里卡尔每隔十级在墙上刻一道月痕，我则记录温度、气味和绳长。越往下，空气越湿冷，暗绿色黏液也越多。它不会腐蚀皮肤，却让人
逐渐分不清距离。石匠几次伸手抓取近在眼前的绳结，指尖却落在半臂之外。

第一只虫从黏液里爬出时，只有指甲大小。

它没有攻击，绕着我们的灯转了两圈便坠地死去。随后是第二只、第三只。它们的生命极短，仿佛离开深处的某种意志便无法继续存在。

里卡尔提议返回。我正要同意，脚下忽然裂开一道细缝。

缝隙没有向两侧扩展，而是向下延伸。我的目光落进去，仿佛也随之不断下坠。里面没有熔岩或地下河，只有一层又一层互相覆盖的黑暗。每一层都传出不同的低语
：失去姓名的人、被祖核遗忘的影子、尚未诞生便被归潮带走的生命。

深渊不是一个地点。

它是世界所有未能归还之物堆积出的伤口。

祖核崩落后，被六道排斥的残余沉到这里。漫长岁月中，它们彼此吞噬、繁殖，终于形成能够向上呼吸的意志。昨夜的失重，正是深渊第一次把呼吸送到地表。

我刚写下判断，裂缝中便伸出一根半透明丝线，缠住石匠脚踝。里卡尔一枪斩断，断口喷出的黏液使他眼前一片模糊。他没有继续攻击，只顺着我的声音后退。

我们带着一截丝线返回井口。

初代议会在地图上划出不可接近区，镇民开始向南撤离。但我拒绝把裂缝标作“敌境”。敌境意味着只需考虑如何战胜对方，伤口却要求人承认自己曾经留下什么。

当天夜里，深渊扩大。

北方森林的地面出现数百道呼吸般开合的细缝，大群短命虫从中涌出，却没有扑向城镇，而是朝同一个方向搬运枯枝、尸骨和散落的微光。

它们在筑巢。

灰痕上方，一双庞大而模糊的复眼短暂睁开。那不是穆拉姆。某个更古老的意志正借深渊观察地表。

九枚星屑围绕我的手腕旋转，百叶的声音再次出现：

“若要我介入，必须先为神力写下边界。”

这一次，他没有只留一句话。

一张由白光构成的契约在井口缓慢展开。
