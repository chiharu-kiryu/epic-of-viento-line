# 第一百一十一章 宗谱与证件

千花失梦后的第一天，月律团拒绝承认她能主持任何仪式。

这不是惩罚。

所有传统誓仪都以梦痕确认灵魂连续。一个人在睡眠中留下的情绪、关系与自我反应，被视作比面貌更难伪造的证明。

如今，千花无法通过自己参与建立的任何一项规则。

她明明站在会场中央，证件却显示：

关系依据不足。

一名官员建议用创世宗谱证明。

这个办法立刻引起更大争议。

若连千花都要靠血缘与创世谱系证明自身，普通无名者又凭什么被承认？何况宗谱只能记录谁从何处而来，不能决定一个人此刻愿意成为什么。

百叶当夜没有入睡。

第三日，身体终于无法继续支撑，他在宗谱室桌边短暂睡着。我与月律团看护守在一旁，想确认血亲梦中是否仍保留千花。

水镜里出现创世海岸。

百叶独自站在岸边。

第一阵潮自行归来，六道也像从来没有争论便依次展开。所有原本由千花托住、质疑或拒绝的部分，都被梦境改写成世界自然发生的过程。

百叶醒来后，第一句话是：“我梦见她了吗？”

没人回答。

他看见水镜，脸色一点点变白。

现实记忆告诉他千花是妹妹，情感仍在，梦却已经替他准备了一段没有妹妹也能成立的人生。若这种改写继续，现实关系会不会也逐渐变成一条需要文书证明的知识？

宗谱审查组由此成立。

任务不是给千花补一张更有权威的证件，而是建立历史关系与当下身份之间的映射。宗谱可以提供线索，证件可以维持现实责任，两者都不能绝对替代本人记忆与持续行动。

“谁有资格见证一个人是自己？”月光骑士问。

百叶没有回答创造者。

千花也没有回答血亲。

她把手放在审查桌上。

“先由我。”

她亲自陈述名字、与百叶的关系、参与过的创世行为，以及如今无法进入梦境的状态。她没有用“幻梦之赐”证明自己，因为那正是已经失效的能力位置。

“我是千花。”她说，“不是因为还能给你们梦。”

百叶随后作为兄长见证。

他没有宣称记忆绝对可靠，而是讲了三件宗谱从未保存的小事：千花第一次造梦后连续数日害怕入睡；祖核崩落以前，两人曾因一块无名石影争吵；她在最生气时不会提高声音，只会把每个字说得更慢。

千花纠正了第二件事的时间。

百叶坚持自己的版本。

兄妹第一次在公开审查里保留互相矛盾的记忆。

旧界与四方提交他们在不同时期的持续行动，我则提供紫路中与她有关、尚未被梦境改写的历史片段。

证据并不完全一致。

百叶记得她在祖核崩落前穿白衣，紫路里却是深色长袍；她认为第一次造梦发生在六道形成以后，古神碑留下相反顺序。

若神明记忆是绝对标准，至少一位创世者必须被判定伪造。

审查组没有选择更尊贵的证词。

他们只确认：站在这里的人能够回应这些矛盾，也愿意承担以“千花”之名延续的关系与责任。

证件更新为：

梦痕缺失。

身份连续。

原因待复核。

我在会场白板写下：

我们不靠血缘书写资格。

宗谱说明关系可能从何处开始，不能决定关系必须如何结束；证件帮助制度找到一个人，不能比本人更有权定义姓名。

一周内，审查组开始清理英雄档案、技能记录与现实身份之间的冲突。称号被复制者不再因档案重合自动失去资格，拒绝家族旧名的人也能让责任沿新名字继续。

蕾贝尔来到审查室。

她把R-17烙印与自己的新证件并排放在桌上。

“如果能力消失，我还是不是档案里的蕾贝尔？”

“由你先回答。”千花说。

“是。但档案里那个人也不全是我。”

她在见证页留下名字，成为第一位不以血缘、神力或梦痕证明千花的人。

真正重要的发现来自创世宗谱末端。

百叶与千花的谱系之后，本应连接最初六道与古神。那里有一条被反复刮除的旁枝，既没有姓名，也没有生命类别。

刮痕很旧。

百叶看见时，手指停在纸上。

“你知道。”千花说。

不是询问。

旁枝末端仍残留一行见证：

凡世无处安放之物，由梦代为记得。

千花不记得自己许下过这份承诺。

百叶却记得。

“后面还有一句。”他说。

“在哪里？”

他没有看妹妹。

“我删了。”

宗谱室里没有人说话。

千花把证件收回袖中。

她没有当场质问，也没有替兄长保留体面。

“把原页找出来。”

“可能已经不在。”

“那就找你为什么认为自己有权删。”

百叶点头。

这一次，他没有用创世时代的危险作为立即解释。

宗谱只能证明他曾经做过删改。

至于那条誓言为何被隐藏，又让谁承担了漫长后果，必须到保存旧誓原本的地方重新查明。

在那之前，水镜先发生了故障。
