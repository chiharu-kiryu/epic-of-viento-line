# 第一百一十一章 宗谱与证件

千花没有昏迷。

她仍能看见、说话，也记得自己是谁。可任何人在梦中寻找她，都会遇见一块平整的空白。与她有关的梦并未被删除，而是自动改写成没有她也能成立的形状。

百叶梦见创世时，只看见天地自行展开。

我梦见初次进入紫路，路的尽头没有等待我的人。

那些改写过于自然，以至于醒来以后，我们必须依靠现实记录才能意识到缺少了什么。

月律团首先提出身份危机。许多古老仪式以梦痕确认灵魂连续，千花如今无法通过任何一项。她明明站在会场中央，证件却显示“关系依据不足”。

一名官员建议用创世宗谱证明。

这个办法立刻引起更大争议。

若连千花都要依靠血缘或创世谱系证明自身，普通无名者又凭什么被承认？何况宗谱记录谁从何而来，不能证明一个人此刻愿意成为什么。

宗谱审查组因此成立。

任务不是替千花补一张更有权威的证件，而是建立历史关系与当下身份之间的映射。宗谱可以提供线索，证件可以维持现实责任，两者都不能绝对替代本人记忆与持续行动。

“谁有资格见证一个人是自己？”月光骑士问。

百叶没有回答“创造者”。

千花也没有回答“血亲”。

她把手放在审查桌上，说：“先由我。”

她亲自陈述自己的名字、与百叶的关系、参与过的创世行为，以及如今无法进入梦境的状态。随后，百叶作为兄长见证，旧界与四方记录她在不同事件中的持续行动，我则提交紫路中与她有关、尚未被梦境改写的历史片段。

证据彼此并不完全一致。

百叶记得她在祖核崩塌前穿白衣，紫路中却是深色长袍；她自己认为第一次造梦发生在六道形成以后，古神碑则留下相反顺序。若以神明记忆为绝对标准，至少有一位创世者必须被判定为伪造。

审查组没有选择最尊贵的证词。

他们记录差异，并确认一件更基本的事：此刻站在这里的人能够回应这些矛盾，也愿意承担以“千花”之名延续的关系与责任。

证件因此更新为“梦痕缺失，身份连续待复核”，而非“无效”。

我在会场白板上写下：

我们不靠血缘书写资格。

宗谱能说明关系从何处开始，不能决定关系必须如何结束；证件能帮助制度找到一个人，不能比本人更有权定义姓名。

一周内，审查组开始清理英雄档案、技能记录与现实身份之间的冲突。称号被复制者不再因档案重合自动失去资格，拒绝家族旧名的人也能让责任沿新名字继续。

真正重要的发现来自创世宗谱最末端。

百叶与千花的谱系之后，本应连接最初的六道与古神。那里却有一条被反复刮除的旁枝，既没有姓名，也没有生命类别。

旁枝末端写着一行残缺见证：

“凡世无处安放之物，由梦代为记得。”

千花看着那句话，很久没有说话。

她不记得自己许下过这份承诺。

百叶却记得。

只是直到此刻，他才承认，那不是创世法则。

那是一条尚未履行完的私人誓言。
