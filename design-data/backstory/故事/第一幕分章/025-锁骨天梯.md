# 第二十五章 锁骨天梯

锁骨天梯并非真正的骨。

它由无数陨落圣翼的骨架与金属熔铸而成，形状像一副连接胸腔与肩部的巨大锁骨。古代天门依靠它分担两界压力，如今失去另一侧支撑，正缓慢向倒影城倾斜。

若任其坠落，半座城会被贯穿。

克鲁斯主张重开天国之门，把天梯拉回原位。莱萨却从阴影中现身，警告天界一旦取得通道控制，凡界将再次失去关闭门扉的权利。

这是我第一次见到堕落天使。

她的光之心脏已经破碎，银白圣光与深渊暗影在伤口中交织。天界称她为背叛者，她也没有因此投向深渊。她只是站在两者之间，拒绝让任何一方垄断解释。

萨莎提出第三条路：把天梯改造成分层通道，而非恢复旧门。

蒂莉帕以圣剑切开损坏骨架，塔赞用长枪固定承重点，克鲁斯负责引导天界一侧的压力，莱萨则将溢出的光暗力量导入自身。每个人都在承受自己最熟悉、也最可能
被其吞噬的力量。

工程持续三日。

天梯最终被分为四层：最外层供紧急撤离，中层运输物资，内层传递信息，最深处只用于双方使者通行。层级不代表贵贱，而是不同风险所需的反应时间。

我拒绝在通道入口刻下任何神名。

那里只写着每一层的用途、关闭方式，以及谁拥有暂停通行的权力。凡界和天界各持一半锁印，任何一方都不能独自开启最深层。

第一批通过天梯的不是军队，而是从天界战争中逃出的伤者。莱萨站在出口替他们疗伤，每修补一个人，自己身上的暗纹便加深一分。

克鲁斯走到她身旁，没有称她“堕落者”。

“莱萨。”他说。

她抬头看他，许久才应了一声。

名字比和解先到。

锁骨天梯稳定后，五名长期维护者决定共同承担通道责任：克鲁斯、塔赞、莱萨、萨莎与蒂莉帕。他们信奉的光并不相同，甚至有人早已被天界除名。

但当天梯再次震动时，五个人同时伸出了手。

天界同盟最初的形状，就在那一刻出现。
