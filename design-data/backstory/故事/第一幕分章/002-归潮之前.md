# 第二章 归潮之前

潮声出现以后，海仍没有形成。

它只是某种反复的意愿，从无形深处抵达岸边，又退回尚未存在的远方。每次拍击都留下一点变化：第一次有了前后，第二次有了远近，第三次使石头边缘浮出一层湿润的暗色。

时间便这样开始流动。

后来许多创世典籍把这一刻写得庄严。它们说百叶划定时间，千花召来原初之潮，六道在神意中依次展开。可我站在紫路上看见的，并不是如此整齐的场面。

第一阵真正的潮水来得太猛。

无形突然获得重量，整片岸地向下陷落。百叶放入其中的黑石被水流抛起，在尚未稳定的空间里同时出现在数个位置。千花托起的光落入水中，产生无数彼此重叠的倒影，每一道倒影都试图成为唯一的太阳。

百叶立刻收紧岸线。

他把散开的石头一块块拉回，使它们只占据一个位置。那些来不及归位的石影在挤压中破碎，发出近似骨裂的声音。

“太窄了。”千花说。

“不窄，它们会彼此穿过。”

“你刚刚毁掉了多少可能？”

“不毁掉，连一块石头都留不住。”

他们的争论没有停下潮水。

千花伸手探入浪中，把那些即将消散的石影收进光里。每一片影子都保存着石头原本可能落下的位置。光因此越来越重，压得她手臂发抖。

百叶看见了，却没有让岸线重新散开。

他只是把一块最大的黑石推到千花脚下，让她能够站稳。

这是我第一次理解他们的关系。

百叶不会因妹妹难过便放弃结构；千花也不会因兄长提供支撑便停止质疑。他们彼此相爱，却从未把相爱误作意见相同。

潮水连续往返七次。

第七次退去时，岸边留下第一片真正的湿地。它不再同时位于多个地方，也没有被固定得完全不能改变。百叶允许石与水在一小段时间内互相推动，千花则把未能成为现实的倒影收在潮面之下，不再让它们争夺同一位置。

“它们去了哪里？”百叶问。

“没有去哪里。”千花说，“只是暂时不要求它们成为现在。”

这句话后来被许多梦术师奉为起源。

可她当时说得很轻，甚至带着疲惫。那不是法则宣告，只是为一场失败找到的临时安置。

紫路把我带到离他们更近的地方。

我仍无法被看见，也无法影响过去。潮水穿过我的身体，没有寒意，只带来许多不属于我的感受：石影来不及成形的惶恐，光第一次发现自己会被遮挡时的惊讶，还有一种最模糊的愿望，反复寻找能够停留的位置。

我想把这些全部记下。

光页却无法承受。每写下一种感受，前一行便开始淡去。紫路似乎只允许我保存已经发生的形状，不能替那些未成之物补出完整语言。

我第一次感到记录的边界。

看见不等于能够保存。

能够保存，也不等于有权替它命名。

潮水退至最远处时，千花忽然走入海中。水面没有浮力，她的身体不断下沉。百叶抓住她的手腕，另一只手将岸线向前延伸，试图在她脚下造出新的地面。

“我听见里面有东西。”她说。

“那只是没有落定的回声。”

“回声也要先有声音。”

她潜得更深。

百叶没有松手。

我沿紫路跟下去，看见海面之下漂浮着成千上万的微小光点。它们不是生命，更像每次潮汐没有实现的去向。多数光点很快暗下，少数却不断靠近彼此，仿佛试图拼出一种能够回应的轮廓。

千花伸出手。

光点便朝她掌心聚拢。

百叶猛地把她拉回岸上。几乎同一刻，海下的轮廓向上抬起，第一次显出近似面孔的空白。

它没有眼睛，也没有嘴。

我却清楚感觉到，它在看。

潮水随即合拢，把轮廓压回深处。

千花跪在岸边，手中多了一粒没有颜色的光。百叶盯着那粒光，很久没有说话。

“它只是残余。”他说。

“也许。”

“不能让每一种残余都要求一个位置。”

“我没有答应它位置。”

千花把光放回水中。

“我只是承认，我听见了。”

第一片真正的海在他们面前形成。潮汐获得周期，石头开始沉降，光也终于能在水面留下单一倒影。

一切看起来比此前稳定。

只有我知道，海面之下仍有一个未能成形的轮廓，记住了有人曾经回应过它。

紫路继续向前。

岸边出现六道尚未连接的裂隙，分别通向世界可能延续的不同方向。

百叶俯身触摸第一道。

千花则回望海面，像在确认那粒无色的光仍在那里。

归潮已经完成。

真正艰难的事，是决定潮水退去以后，什么能够留下。
