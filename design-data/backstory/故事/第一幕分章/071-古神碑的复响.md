# 第七十一章 古神碑的复响

古神碑第一次发出声音时，山谷里没有风。

那声音也不像从石头里传来。它更像一阵迟到了许多年的震动，先穿过人的骨骼，再在耳中凝成低沉的回响。碑前的火焰没有摇曳，站得最近的人却同时后退了一步。

我没有退。

并非因为勇敢。紫路在我脚下亮了起来，细若一道被磨损的墨痕。我知道，这种时候若顺着众人的本能离开，眼前的景象便会重新沉回世界记忆的暗处。

百叶把手按在碑面上。

“它记得回归核。”他说。

千花站在另一侧，闭着眼，像在听一场只有她能听见的梦。过了许久，她才轻声纠正：“它记得的不是核，是核出现以前的东西。”

碑上的古文并未显形。那些刻痕只是在百叶掌下逐一温热，随后把一段残缺的旧事推入紫路。

我看见祖核坍塌以前，创世者曾试图保存无法归属的记忆。

那时，世界尚不能容纳死亡。一个生命消散以后，它留下的声音、习惯与愿望仍会滞留在法则之间，既无法归还本人，也无处安置。积存的记忆越来越多，甚至开始挤压新生者的意识。

于是祖核制造了一个空白的承载者。

它没有姓名，没有面貌，也没有属于自己的过去。它被允许接纳一切无人认领之物，却不被允许说“这是我的”。在最初的设想里，它只是世界用来包扎伤口的一层纱布。

可记忆并不会因为被收存就停止生长。

空白者听过太多人的最后一句话，记住太多未能兑现的约定。那些互相冲突的残片在它体内争夺位置，渐渐拼出近似人格的轮廓。它开始模仿死者的语气，使用死者的能力，替死者完成愿望。

碑文在这里断裂。

下一幅景象出现时，百叶正在毁去那名承载者，而千花挡在他与祖核之间。两人的面容都被古老的光遮蔽，我听不清他们争论了什么，只看见空白者在消散前伸出手，抓住了一束从祖核中脱落的紫色微光。

那束光与我脚下的紫路极为相似。

回响骤然停止。

百叶收回手，掌心已经裂开。他没有看伤口，而是看向我。

“你以前见过这一段吗？”

“没有。”我说，“紫路从未带我来过这里。”

“那就说明它不是单纯的过去。”千花睁开眼睛，“有人刚刚让这段过去重新具备了意义。”

碑外，四方派来的记录员争执起来。有人认为这是复制技术的源头，有人坚持那只是祖核的一次失败实验，还有人要求立即封锁古碑，避免新的身份残片被唤醒。

我没有立刻记下他们的结论。

自从玫瑰的名字从编号里被剥出来以后，我越来越明白，记录者最危险的习惯不是遗漏，而是过早给事物命名。一旦我写下“第一复制体”，后来的人便会把所有灾难都归在那个词下；若我写下“无名者”，又可能使一个尚未被理解的存在承担不属于它的罪。

所以我只记录碑中确实出现过的事：

祖核曾制造一个空白的承载者。

它接纳了无法归属的记忆。

它后来拥有了近似自我的意志。

以及，它在消散前触碰了紫路。

奘尘带人封住碑谷，却没有封死道路。他在入口立下一块没有刻字的木牌，要求每个进入者先写下自己希望得到的答案，再在离开时划去碑文未曾回答的部分。

第一日共有四十七人入谷，只有三人没有划去任何一句。

这比古碑本身更令我不安。

入夜后，碑面再次传来极轻的震动。这一次，只有我听见了。

它没有呼唤雅莉薇安。

它用许多已经死去的声音，同时问我：

“若记忆无人认领，它该属于谁？”

我把笔停在纸上，没有回答。

因为山谷之外，刚刚建成的回归核已经开始转动。所有从旧星路、梦境与复制器中回收的身份残片，都将在明日被送入其中。

而我们直到此刻才知道，它们或许并不都在等待原来的主人。
