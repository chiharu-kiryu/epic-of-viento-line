# 第三十七章 雅莉薇安在审判台

我站上审判台时，没有携带账册。

记录者最容易利用的权力，是比别人更早整理出一个有利于自己的版本。我把试航原始记录交给季芃修封存，只凭记忆接受询问。

指控有三项。

我未经四方同意开启封箱；在确认巴尔存在后没有立即下令攻击；事后先救治水手，延迟了现场封存。

我承认全部事实，不承认它们自动等于有罪。

军政代表认为程序必须在危机中仍然有效，否则每个人都能用“救人”替越权辩护。萨姆克证明若再晚十个呼吸，污染将不可逆。商联代表则指出，开箱引发的载重变化险些使第二艘船触礁。

没有哪一方完全错误。

审判官问我是否后悔。

“我后悔没有在试航前要求紧急开箱条款。”我说，“但若回到当时，我仍会切断铅封。”

席间出现不满。有人认为这证明我拒绝服从共同规则。

我提出，审判应区分三件事：行为是否违反条文，行为在现场是否必要，条文本身是否遗漏了必然出现的例外。第一项可以定罪，后两项决定如何修复。

季芃修第一次支持我的主张。

最终裁决认定我越权成立，暂停我参与四方封存事务三十日；同时要求四旗制度增加紧急处置条款。巴尔问题另行评估，不能因为他曾摧毁巢核便被记录成可靠盟友。

裁决之后，我要求举行复述会。

每名证人必须用对方能够认可的方式复述其立场。军政承认程序延迟可能杀人，我也承认个人判断可能让公共监督失效。复述不代表同意，只证明争议没有被方便地缩成善恶。

审判没有让我无罪，也没有把我塑造成受迫害者。

它给越权留下后果，也给制度留下修改入口。

暂停期间，我被安排管理南城药仓。许多人认为那是轻罚，直到第一批来自四方的药物同时抵达，标签互不相通，剂量标准也完全不同。

仓门外，已有数百名病人排队。

我宁愿再站一次审判台。
