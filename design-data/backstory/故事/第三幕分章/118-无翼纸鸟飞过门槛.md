# 第一百一十八章　无翼纸鸟飞过门槛

无翼纸鸟不会飞。

千花把它折成时，没有给它翅膀。

它来自没有外部的梦，是一个无法离开共同内部的愿望。后来梦被归还给做梦者，纸鸟停在梦与醒之间，没有主人，也没有可以前往的外面。

如今，它落在门框上。

纸身没有文字。

若写上问候，它会成为信；若画上地图，它会成为指路物；若在背面记录当前世界，它又可能被当作代表整个世界的礼物。

我们什么也没加。

千花站在门边，没有伸手取回。

“它是你的梦。”我说。

“曾经是。”

“你愿意让它过去吗？”

“过去不是我能给它的方向。”

缇洛也没有触碰。

两枚亮点随着纸鸟折痕移动，像在观察。风线沿基石裂缝轻响，却没有形成足以托举纸张的气流。

第一阵风来自潮底港。

海风吹起纸鸟一角。没有翅膀，纸身只在木框上翻了半圈，险些落回地面。千花抬手，又停住。

若她接住，纸鸟会继续留在当前世界。

若不接，也可能被雨水冲毁。

放手不是保证自由。

只是停止替它维持原位。

第二阵风没有来源。

基石另一侧一层薄片移动，门槛上的压力改变。纸鸟沿木框滑向错开的平面，却在边缘停住。当前海风只能把它送到这里，缇洛一侧的变化也不能直接把它拉过去。

两种风没有接成道路。

纸鸟卡在中间。

纸张开始变薄。一半受当前空气湿度影响，另一半则被陌生光线切成数层。若继续停留，它可能像当年门槛上的女孩一样从中间裂开。

千花走近。

缇洛也同时靠近。

我们不知道对方要救纸鸟、取走它，还是移除危险物。千花没有通过梦读取，只把一根手指放在当前纸角下方。

缇洛让灰色薄片托住另一侧。

双方没有共同抬起。

千花先向上，缇洛却向侧面，纸身折出新痕。第二次，千花只施加极小力量，等待陌生薄片变化。缇洛也停顿，再把压力从侧面转到下方。

这是共同举石留下的节律。

不是语言。

它只适用于双方都承受一个物体重量时。

纸鸟比石头轻得多，仍需要重新协调。石头的危险会迫使双方合作，纸鸟却随时可以被任一边放弃。共同动作不再由求生保证。

千花抬起一寸。

缇洛跟随。

第三阵风从梦醒边缘吹来。

没有外部的梦仍保存最后一处无法归属的空白。风经过空白，不携带梦境内容，只让纸鸟短暂失去“必须留在内部”的性质。

纸身越过门槛。

不是从当前空间飞到另一个坐标。

它先离开千花能够做梦的位置，又被缇洛一侧的薄片接住。中间没有连续道路，也没有一阵风走完全程。

无翼纸鸟确实飞过去了。

当前世界的人欢呼一声，又很快停下。我们不能确认“过去”在缇洛那边意味着什么。纸鸟也可能只进入错开平面的另一层，尚未抵达任何完整地方。

缇洛把纸鸟托在一枚亮点旁。

纸张没有被翻译。

它没有长出异界翅膀，也没有变成对方能够理解的形状。缇洛尝试展开折痕，纸鸟险些散开，便停住动作。

千花没有阻止。

一件离开创造者的东西，也会被别人以不熟悉的方式触碰。尊重不是要求远方永远按我们的使用说明保存它。

缇洛最终没有拆开。

陌生薄片把纸鸟放到基石另一端。那里没有天空，纸鸟也没有继续飞。它只安静停留，像一张不要求被阅读的空白纸。

门槛开始关闭。

千花下意识向前一步。

她曾因弥珂的消失失去共同梦，如今又要看着最后一件无主梦物离开。只需在关闭前伸手，或许仍能把纸鸟取回。

她叫了一声：

“缇洛。”

两枚亮点亮起。

缇洛没有把纸鸟递回。

也没有解释。

千花退后。

错开平面逐层合拢。纸鸟、薄片与亮点一同从当前视野消失。风线仍沿基石裂缝存在，不能用于追踪。

我们不知道纸鸟后来去了哪里。

它也没有带回对方世界的消息。

可门槛关闭后，千花发现自己的梦里多出一处很小的风口。风口不是纸鸟留下的影像，也不通向缇洛。它只是某件曾属于梦的东西真正离开后，内部无法自行填平的
缺席。

千花没有修补。

第一件飞过门槛的东西没有翅膀，没有名字，没有使命。

它不代表和平，也不证明航路恢复。

双方只是先后托住它，在各自的风中给出一小段力量，并允许它离开任何一边能够完整解释的地方。
