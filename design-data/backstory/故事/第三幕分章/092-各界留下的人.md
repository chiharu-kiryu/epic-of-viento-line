# 第九十二章　各界留下的人

风线中断的第五年，潮底港不再称瑟缇为异界来客。

不是因为她成为当前世界的人。

只是“来客”暗示终有一日离开，而没有谁知道归程是否仍存在。

她住在旧通航台附近，帮人辨认关系留下的伤。完美翻译消失后，许多当前世界医者重新把看不见的靠近当成情绪。瑟缇不能替他们理解全部，只能指出某段疼痛来
自一份正在远处拉扯的联系，而非血肉本身。

有人问她是否想家。

她有时回答，有时不回答。地方语言已经恢复，沉默也重新可以只是沉默。

每个世界都留下了一些人。

斯菲尔留在骨纹世界。

风线断裂时，他正在帮助一座移动城区辨认静星停顿。左翼携带当前星光，右翼已经长出骨层，身体中部则保留瑟缇故乡的一小段关系。若强行选择所属，他会被拆
成三个都不完整的答案。

无海之城起初把他安置在旧生长层，那里专门存放无法随新季变化之物。

斯菲尔拒绝了。

他不是遗物。

他重新学过一次飞，如今又要学怎样在没有天空交接的世界生活。骨纹城市不需要飞行，移动依靠蜕落与新生。他便把无法展开的左翼嵌入一条高层街道，让当前星
光成为夜间辨认旧季的标记；右翼仍随当地骨层生长。

他没有成为塔。

每到下一季，他会把自己从街道中取出，换到另一处。哪条街愿意接纳他，哪条街便拥有一段不属于本地的夜空。没有地方因此必须永久收留。

维尔萨留在无海之城更远的生长带。

她曾驮过没有海的城区，也把大部分水留在当地。断航之后，那些水无法返回当前世界，逐渐形成一片不符合骨纹季节的小湖。

当地人问她是否要把水收回身体。

维尔萨说，那已经不全是她的水。

湖中混有骨片、当地尘埃和无数居民借水迁移时留下的痕迹。收回等于把一段共同生活重新称为个人财产。她只取走维持自身所需的一部分，其余任由无海之城决定
。

后来，那片湖仍没有变成海。

骨纹居民用蜕落薄片在水上行走，维尔萨则在岸边学习不以潮汐判断季节。她偶尔会朝当前世界曾经所在的方向望很久，但从不说湖是临时停泊。

祖克同时留在两界。

当前河岸的幼苗已经长成大树，凝石之界的根则继续化为纹路。风线断裂后，两部分失去同步。树在风中生长，石根却停留在最后一次共同节律里。

我们不知道该说哪一个是祖克。

河岸的他拥有语言与记忆；石中的他保存扎根时交出的那部分身体。若把石根视作残留，便否认凝石之界接纳的是一个活着的部分；若把树视作返回者，又像在宣称
能说话的一边更完整。

祖克自己给不出答案。

“等有一天再遇见，”他说，“先问石头认不认得我。”

更多留下者没有英雄的名字。

一个当前世界的厨师留在瑟缇故乡。他做的食物无法被当地身体直接食用，只能通过共同改变两种材料来分享。断航后，没有人需要他继续维持第一次宴席的传统。
他本可以停止，却在当地开了一间没有共同菜肴的厨房。

客人各自带来材料。

他只负责让不同锅灶在同一时刻发生变化。

一个骨纹孩子留在潮底港。她每年蜕层，当前房屋无法容纳那些不断扩大的旧壳。邻居最初把壳当垃圾，后来用它们修补海堤。孩子长大后才知道，故乡的旧层原本
不这样使用。

她没有因此变成当前世界的人，也不必替整个骨纹世界批准这种做法。

一段来自静星边缘的生命则留在界外之钟里。

它只在特定停顿显形。静星航路中断后，停顿失去外部校准，却仍偶尔发生。港口人把钟声停住的那一瞬称为“它醒了”，却不能确认醒与睡是否适用于它。

断航的前十年，留下者常被当作通向故乡的最后钥匙。

人们研究瑟缇的关系、斯菲尔的骨翼、维尔萨的水和祖克的石根，希望从他们身体里重新找到坐标。每次失败，留下者便更像损坏的门。

瑟缇最后把旧通航台拆成居所。

她用门框搭床，用路标做桌，把那块曾标记返回方向的关系灯改成普通窗扇。有人指责她毁掉未来重开航路的遗物。

“它先是我每天生活的地方，”她说，“才可能是你们以后研究的门。”

这句话没有总词典翻译。

有人听懂，有人只听见拒绝。

各界留下的人慢慢停止住在港口、门边和观测站。他们迁入街区，建立关系，也有人独居。他们不再每天证明自己来自哪里，也不必假装已经属于这里。

“留下”不再只是一场事故的结果。

它开始成为一种现在。

第二十年，我为他们重新整理记录。旧档案按照出发世界分类，新记录却无法这样写。骨纹孩子的记忆一半来自潮底港，当前厨师的生活已嵌入关系世界，斯菲尔的
双翼更拒绝被放进同一栏。

我最终没有建立新分类。

每个人单独一页。

姓名之后不写归属，只写他们愿意说明的经历。空白处留给以后，也留给永远不必回答的部分。

那一年，瑟缇第一次不在风线消失的纪念日去海边。

她留在家里修一把椅子。

锤声从旧门框搭成的屋内传出，带着潮底港很重的地方口音。邻居听不完全懂，仍知道她正在生活。

世界没有把留下者送回原处。

他们也没有成为异界留给我们的纪念品。

当归途消失，一个人并非只能等待。

有些根会在不被称作故乡的地方，长出不必证明归属的下一季。
