# 第006章 风的双向

瑟缇在当前世界的第一夜没有呼吸。

她胸口仍在起伏，薄片也随空气开合，却没有任何气体真正进入身体。阿尔法测得周围空气不断流向她，又从皮肤缝隙原样离开。她需要的不是我们所称的吸入。

门外灯光每暗一次，她的胸腔便收缩；灯光重新亮起，身体才舒展。

她的呼吸留在影子那边。

周能够短暂托起自己的影子，却不能把她的影子从另一个世界拉来。克鲁斯也不敢用圣光建立生命循环，那可能把门外所有替她承担呼吸的人一并接入天国之门。

到了第二夜，瑟缇的两枚薄片开始发黑。

千花在梦里寻找暂称弥珂的孩子。灯场比过去暗，许多人围在一处空影旁，以彼此靠近维持起伏。瑟缇每留在当前一息，他们便要共同完成一次类似呼吸的动作。

这不是他们主动同意的长期照护。

瑟缇跨门时，双方都不知道影子不能同行。门外的人正在承担一项没有被说明期限的关系。

“送她回去。”守门者说。

门只允许风向我们这边流。瑟缇能够跨来，是因为许多灯光共同缩短了距离；回程需要当前世界也对门外承担一段空间。我们尚未做过。

塞立尝试抬高门槛，让地面朝外倾斜。门没有变化，内陆却出现一道朝陌生天空下坠的坡。百叶展开六道，又发现门外不承认我们对往返的区分。

帕加把那根没有刻度的空尺劈成两条。

他没有真正切断共同改变过的金属，只沿中间锻出两道可以分别受力的细槽。一槽承接门外吹来的风，另一槽空着，等待我们使某种东西向对面移动。

“送什么？”我问。

“先送风。”

时朵从新港海面收起一团潮湿空气。她没有降雨，只让水汽沿第二道槽缓慢流动。空气抵达门槛时停住了。对我们而言，风由压力与温度推动；门外的风却沿关系远
近移动。一团与任何门外存在都没有关系的空气，没有去处。

瑟缇从软网上伸出短枝，碰了碰水汽。

蓝色液体从她伤口渗出一滴，进入雾中。门外灯场立刻有一盏灯升高。潮湿空气获得了一段能够抵达的关系，沿空槽穿过门框。

陌生世界第一次起雾。

灯下的人群迅速散开。有人薄片紧闭，有人追着水汽移动，还有一处地面遇水后完全失去光。时朵立即停止输送。

我们送出的第一口风也造成了伤害。

弥珂在梦中展示，一名门外居民接触水汽后身体变得过近，各部分无法再维持距离。我们不理解那是否等于受伤，只能看见周围人正在将它轻轻拉开。

瑟缇也看见了。她发出尖锐短音，用短枝重击空尺。第二道槽被砸弯，剩余水汽全部停在门中央。

她不是被动接受救治的来客。

她停止了自己赖以建立回程风的一次尝试，因为代价落在另一个人身上。

我们重新调整。时朵不再送入整团潮气，只让瑟缇自己从雾中选择一缕。门外也不再以整个灯场替她呼吸，而由三盏主动升起的灯轮流靠近影子。千花每次都确认升
灯动作仍表示靠近，不把第一次理解当作永久规则。

双向风终于形成。

它不是同一股空气来回流动。门外风使瑟缇胸腔起伏，当前水汽则沿她选择的关系抵达三盏灯附近。双方都能随时停下自己的一侧，也必须承受停下后瑟缇可能再次
缺氧的风险。

第三次循环完成时，她胸口发黑的薄片恢复一点颜色。

门外传来细微声响。

起初像金属摩擦，随后变成许多高低不同的短音。我们以为那是语言，千花却在梦中看见灯下的人正在因陌生雾气改变颜色。那些声音来自他们的身体，不一定是在
对我们说话。

槐姐仍然听了一会儿。

“有一段像笑。”

没人能确认。

我把这句话记在个人感受里，没有移入共同事实。

双向风持续到黎明。门框没有扩大，两个世界也没有因此彼此理解。我们只是第一次不再让所有维持接触的力量都来自同一边。

瑟缇醒来后，用短枝在空尺两槽之间添了一道可以开合的小桥。

她先打开，又亲手关上。

然后把短枝交给我们。
