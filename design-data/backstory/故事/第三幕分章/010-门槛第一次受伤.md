# 第010章 门槛第一次受伤

门槛流出的不是血。

裂缝每张开一次，我们这边便掉下一块陌生灯光，对面则出现一小片新港石板。两个世界没有互相吞并，却开始从伤口交换不属于自己的结构。

第一块灯光落到地面时，一名守军的左脚失去重量。

他没有受伤，脚却无法再独自踩住石面，必须由旁边的人抓住才能站立。与此同时，门外某处多出一块始终向下坠的地面，三盏灯被压得无法升起。

门槛受伤，伤口把两套规则随机漏向彼此。

帕加试图用当前金属封住裂缝。铁片刚覆盖，我们这边停止掉落灯光，对面却出现一堵无法绕开的坚硬距离，许多门外居民被隔在彼此之外。

他立即拆除。

百叶用六道托住裂口，门外的关系随之被分成六类。弥珂在梦中发出强烈拒绝。千花还没来得及退出，灯场便有一部分被归入生，一部分被归入死，其余四类对方根本没有对应经验。

百叶也收手。

每一种只来自一边的修复，都会让另一边承担材料背后的世界规则。

门外开始修复。

细长肢体围绕裂缝编织灯光。当前世界的石板立即失去固定位置，门前所有人被彼此关系拉动。关系亲近者撞到一起，有争执的人则瞬间被抛出数十步。我与千花相距不远，却因她对我的担忧骤然靠近，肩膀重重撞在一起。

“停！”千花在梦中示意。

对方没有立刻停止。他们也许只看见门槛不断漏出无法承受的石板，正像我们急于阻止灯光掉落。

双方都在修复对自己可见的伤。

裂缝因此越来越深。

瑟缇从软网上爬下。称呼入口尚未重新开放，没有人能用声音阻止她。她拖着不习惯当前重力的身体来到门边，把短枝插进裂缝。

门外立即有许多灯向她靠近。

她的影子仍在那里。瑟缇正用自己跨在两界的身体，把双方修复力量引到同一个承担者上。石板停止漂移，灯光也不再掉落，所有冲突却开始撕扯她。

胸口两枚薄片先后断开。

蓝色液体从身体涌出，沿短枝流入门伤。门外也传来某种结构断裂的声音。千花在梦里看见弥珂冲向瑟缇影子，伸出一条细肢托住。

裂缝正好从它们接触处穿过。

弥珂的一部分灯光被切下，落入当前世界。那不是完整身体，只是一只由光构成、比纸鸟大一些的手。它在门槛上挣扎，无法回到另一边。

门槛第一次伤到一个明确正在行动的人。

千花退出梦境，跪到光手旁边。她没有直接触碰，只把紫色圆面铺在手与裂缝之间，让弥珂自行选择是否靠近。光手颤动数次，最终落在梦面边缘。

对面编织停止了。

帕加也撤下所有金属。百叶收拢六道，时朵关闭双向风。双方第一次同时不修复。

裂缝没有继续扩大。

它保持开放，石板与灯光也停在各自已经落下的位置。原来门伤无法在双方都追求恢复原状时愈合，因为每一边的“原状”都要求另一边交出已经进入的部分。

瑟缇仍被短枝钉在裂缝中央。

我们问不到她是否允许救援。称呼薄片在千花手中，只能让千花叫她。千花靠近，发出那个暂用声音。

瑟缇胸前一片碎片轻响。

千花指向她，再指向当前这一侧，做出靠近动作。瑟缇没有回应。她的意识可能已经离开，也可能正在门外影子中处理另一部分伤。

克鲁斯提出先把她移到当前软网，保留以后拒绝的可能。千花没有代替她答应，只重复动作，等待到短枝末端出现一次微小弯曲。

那是允许，还是伤口抽动，无人确定。

我们仍然先救。

帕加剪断短枝靠当前的一端，塞立让地面不再托举，只维持平坦。瑟缇倒向软网时，门外影子被裂缝扯长，弥珂的光手也向另一边滑去。

千花松开紫色圆面。

光手没有留在我们世界，沿梦的边缘回到裂缝，却只回去一半。剩余部分化成一枚陌生光点，嵌在门框伤口里。

门没有复原。

我们用空尺弯成两个互不闭合的支架，分别托住石板与灯光。对面也留下未完成的编织，不再要求裂缝消失。伤口因此获得一个能够暂时存在的形状。

瑟缇昏迷到次日清晨。

她醒来后，第一件事是摸向自己脚下。

仍然没有影子。

门外灯场也不再传来完整的呼吸节律。裂缝切断了她与影子之间大部分连接。

她必须选择留在当前世界，或冒险穿过仍在受伤的门槛。
