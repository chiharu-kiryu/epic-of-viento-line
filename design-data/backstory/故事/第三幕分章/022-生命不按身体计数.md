# 第022章 生命不按身体计数

六条蓝环在第二日变成了九条。

没有新的环从山里出来。原有两条在移动时各自分开，另有三条碰到同一盏灯后合成一条更粗的光带。按身体形态计数，数字在六、九、七之间变化；按震动周期，它们始终维持同一组回应。

救援物资却必须按数量分配。

每条蓝环需要一段不受固定重力压迫的软槽。希尔芙只能在当日制造六段。若把粗光带算作一个身体，刚好足够；若分开后的每一条都能独立受伤，至少有三条得不到保护。

“让它们自己选。”有人说。

蓝环没有使用灯升降，也没有对千花的梦面作出回应。马力克的震动能改变其动作，不能证明它们理解选择。将无法表达者排除在分配外，与替它们决定同样危险。

阿尔法列出三套安排。

第一套保护六个当前形体；第二套按持续回应划分，只铺一条巨大软槽；第三套保护每处分裂可能，需要九段，材料不足。

他没有给概率。

帕加建议先铺一条可拆槽，遇到分裂再分。这样会使最初所有蓝环共享同一空间，若它们并非一个生命，可能构成强迫接触。

瑟缇走进环群。

她没有代表门外生命发言，只把自己的承重绳分成六段，分别放在蓝环能够主动触碰的位置。四条环避开，两条靠近，粗光带则同时做出两种动作。

它内部至少存在分歧。

我们不再把粗光带当作一个统一选择者。希尔芙将六段软槽拆成十二块短板，不能完整保护任何一条，却允许不同部分自行拼接。蓝环开始移动短板，有的围成一处，有的保持距离。

第三个时辰，山体再次震动。

托盘西侧即将塌落，蓝环必须离开。救援者无法等它们把所有短板排完，只能连同当前排列一起搬运。

一名搬运者抓起最外侧蓝环。

其余八条同时僵直，门外数十盏灯熄灭。他立即松手，蓝环落地后仍没有恢复。抓住一条身体，似乎触及了整个回应周期。

救援因此停了两息。

山石已经落下。希尔芙让机械只抬短板，不直接接触蓝环；瑟缇用短枝敲出移动节奏，马力克也从火星传来低频震动。七条环跟随短板离开，两条留在原地。

没人知道那是拒绝，还是已经无法移动。

帕加托住落石，给两条环多出五息。第五息结束时，一条缩回山体，另一条被岩石覆盖。

伤亡报告无法填写。

身体受压一条，持续回应中断一处，门外灯光熄灭数量则从七变为二十余，又在夜里恢复一半。任何一个数字都没有撒谎，也都不能独自回答“死了几个”。

我们改写救援记录。

第一栏写可见身体变化，第二栏写持续回应，第三栏写门外关系变化，第四栏留给当事生命能够表达的自我划分。无法确认处不填零。

这套记录很繁琐。

粮食、住所和医疗仍会遇到实际配额。生命边界未知不能让资源自动变多。我们只能在每一次分配中说明按哪一种临时单位行动，以及可能遗漏谁。

夜里，被岩石覆盖的蓝环重新发出三短、两长。

身体没有挖出，回应却仍存在。马力克听见后在火星巢穴旁敲击一次。

阿尔法没有把伤亡数从一改回零。

他写：

“一处身体被覆盖。回应尚存。是否持续为此前生命，未知。”
