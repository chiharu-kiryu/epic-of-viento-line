# 第055章 蕾贝尔拒绝异界军旗

门外军旗不是布。

它由所有受固定尺度伤害的关系组成。三丈通道压碎的灯光、被夹板固定的身体、天国之门排出的重力，以及被“代表”称呼压向中心的死者，全都沿同一种愤怒靠近。

翻译系统需要为这段关系寻找当前形状。

它选择了蕾贝尔的血。

未来军旗曾借她尚未发布的命令征召死者，现实之战里她也公开撤销旧日与未来声音的当前指挥权。共同词典因此把“能够集结伤者并赋予方向的人”映到她身上。

红色关系从门缝进入，缠上她的手腕。

没有强迫跪拜，也没有命令。她只要接受，门外分散灯群就能获得一支可与四方军队对抗的共同阵线。当前被尺度炮伤害的人也开始靠近。

“他们需要指挥。”四方中的反战者说。

“指挥能让对面谈判。”

“没有军旗，他们只会继续被各个击破。”

这些话并非全错。分散拒绝在战争中很难抵抗集中武器。四方可以一次发射尺度炮，门外每处灯群却必须分别表达不靠近。军旗能把许多具体伤害变成足以阻止炮击的力量。

蕾贝尔握住红色关系。

门外灯墙立刻升高，当前数百名伤者也看向她。只要她说出敌人，军旗便会完成。

她问：“谁愿意加入？”

翻译系统回答：“所有受伤者。”

“我问的是谁愿意。”

系统无法逐一确认。军旗由伤害相似性形成，把疼痛本身视作共同同意。有人确实想战斗，也有人只想回家，还有一些生命甚至不把自身变化理解成伤。

蕾贝尔松手。

红色关系没有离开，开始沿血液向上生长。拒绝成为指挥官不等于军旗失去需求。若她完全切断，门外阵线可能寻找另一个更无法拒绝的身体。

她割开手腕。

不是献血。她把与自己相连的那一段军旗从身体分离，放到缄城广场。任何具体生命可以主动靠近，也可以保持距离。

第一批有四十余名当前伤员。

门外则有多组灯光升高，洛姆十段身体中只有六段参与。剩余四段仍住在接收区，不因共同体多数自动入军。

红色关系缩小，却变得更稳定。

蕾贝尔没有担任统帅。加入者分别说明愿意承担什么：守住伤员撤离路、阻止尺度炮发射、保护门外哀悼区。没有人被要求同意进攻当前城市。

仍有人希望复仇。

三名当前士兵主张摧毁四座炮架，一组门外灯群要求切断所有固定空间。它们也可以组织行动，却不能借同一军旗把防御者一起征入。

广场上因此出现三面不同红色结构。

疼痛没有自动团结所有人。

四方把这一过程视作异界武装在缄城集结，要求蕾贝尔解散。她回答，自己没有权力替主动加入者解散，只能停止提供个人血印与指挥。

“那你站哪边？”军官问。

“站在我每一次决定的地方。”

这句话无法用于军事地图。

夜里，最大的红色关系试图再次缠回她手腕。它需要一个名字与面孔，才能被两界识别成军队。

蕾贝尔把未来血印原件放到地上。

“我曾经会接。”

她没有否认欲望。统一军旗能让她迅速阻止尺度炮，也能让所有受伤者的声音抵达谈判桌。

“今天不接。”

军旗失去中心，分成许多较小关系。有些因此脆弱，有些反而第一次能够自己改变方向。

远处，四方军队也在重新编组。

门外至少四组防御关系分别升起。

没有一面异界军旗统一它们。

下一场冲突将由更多具体行动者发动，也更难用斩首一名指挥官来结束。
