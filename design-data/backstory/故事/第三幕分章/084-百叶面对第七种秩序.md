# 第八十四章　百叶面对第七种秩序

百叶来到潮底港时，正确世界的门已经关闭。

他没有先看白线。

他去看那些因门关闭而失去亲人的人，看中断的医疗航路，也看没有影子的女孩。她坐在界外之钟下，手掌仍保留门内获得的温度，手臂却冷得无法被当前世界辨认。

“你把自己分开了吗？”百叶问。

女孩摇头。

完美翻译想解释这个动作，百叶抬手让它停下。

白线第一次没有服从。

摇头的全部含义仍出现在每个人意识中：女孩不认为自己曾经完整，也不认为门槛把她切成两人；她只是拒绝由某一边决定另一边算不算残缺。

百叶听完，向她行了一礼。

“那么，是我问错了。”

随后，他才抬头看那条贯穿诸界的白线。

创世之初，秩序并非一种。

百叶曾见六道从混沌中分出，使存在可以沿不同方式延续。生与死不是唯一尺度，梦与醒也不互为虚假。后来者常把六道画成轮、树或上下排列的层级，那些都只是各时代试图理解创世的图。

六道之间会冲突，却不能互相证明对方只是错误。

白线不同。

它不从创世中分出，也不属于任何已知世界。它诞生于群岛相望以后，来自我们希望不同尺度能够公平比较、不同语言能够完整理解、不同后果能够找到共同答案的愿望。

它是第七种秩序。

不是更高的一道，而是一种要求所有“道”都能被写进同一关系的秩序。

百叶伸手触碰白线。

潮底港的天空立刻出现创世时的景象。混沌展开，六道分立，最初的光与最初的影各自获得方向。那并非幻象，而是白线对百叶记忆的完美翻译。

每个看见者都理解了创世。

没有神秘，没有缺页，没有只属于创世者的经验。六道如何形成、为何分立、百叶曾在哪一刻犹豫，都被准确呈现。

我本应为这份记录欣喜。

紫路追寻了无数时代，仍有许多创世空白。如今答案就在眼前。

百叶却立即收回手。

景象没有消失。白线已经将创世翻译成所有世界都能理解的事件。骨纹世界看见六个生长方向，瑟缇故乡看见六种最初关系，静星则把它们接入六次停顿。

每一种理解都正确。

创世也因此不再发生在任何具体地方。

它成为一个可以套用到所有宇宙的共同起源。

“你创造了它吗？”我问百叶。

“没有。”

“那它能约束你吗？”

白线替他展开答案之前，百叶主动说：“能。”

第七秩序不承认创世者位于秩序之外。百叶的神力、记忆与判断都只是可被翻译、比较和校准的局部现象。他若试图摧毁白线，行动造成的全部损害会立刻显现，并被纳入唯一答案。

他抬起手，六道在掌中展开。

生可以让白线成为生命，死可以结束它，梦可以使它失去现实边界，醒可以把它逐出想象。其余道路也分别提供毁坏、封印或重生的方法。

每一种方法都被第七秩序准确理解。

白线没有抵抗，只在天空列出后果：

摧毁共同尺度，会使十二条航路立刻中断。

摧毁完美翻译，会让大量正在接受跨界医治的伤者失去沟通。

摧毁唯一答案的计算，则可能使正确世界永远无法重开，门内的人与贝塔一同失去归途。

百叶若动手，仍能成功。

可成功不再等于胜利。

第七秩序不是从外部侵入的敌人。它扎根在每一次获救、每一次被正确理解和每一次对公平的请求中。摧毁它，便要同时摧毁我们确实从中得到的善果。

“你是创世神。”有人在门边对百叶说，“重新创造一个没有白线的世界。”

百叶望向他。

那人刚刚失去进入正确世界的妻子。他不是盲目崇拜神力，只是相信创造者应当能够纠正世界。

“我若重新创造，”百叶说，“新世界会把你们现在承受的后果算作旧世界遗留，还是算作从未发生？”

那人答不出来。

重新开始也是一种抹除。创世神最容易犯的错误，便是把不能解决的历史变回尚未发生的材料。

百叶收起六道。

白线随即把他的克制解释为最优决定：暂不摧毁，观察第七秩序变化，保留未来行动可能。

“不。”百叶说，“我不是暂缓正确行动。”

完美翻译继续说明，他其实也不确定该做什么。

“也不是因为不确定。”

每一句拒绝都被更完整地理解。百叶越说，白线越能准确描述他的立场。

最后，他停止解释。

他走到没有影子的女孩面前，坐在地上，与她一起看那道关闭的门。一个创世神与一个无法确认是否完整的异界生命并肩沉默。

第七秩序仍在翻译他们。

可这一次，百叶没有试图保护自己的神秘。他只是拒绝让理解自动成为命令。白线可以知道他想摧毁什么、保留什么、害怕什么，却不能替他完成选择。

入夜后，他去找千花。

“六道之内，白线都能找到对应。”他说，“我要你去一个没有外部的位置。”

千花看着哥哥。

“没有外部，怎么回来？”

“我不知道。”

这是第七秩序降临后，百叶第一次给出没有被补全的答案。

千花闭上眼。

她要做一个不把白线赶出去、也不把自己藏在白线之外的梦。

一个根本没有“外面”的梦。
