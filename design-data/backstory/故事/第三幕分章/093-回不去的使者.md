# 第九十三章　回不去的使者

栖砾的使者任期，在风线中断后的第十七年结束。

他来自无海之城东层。

“栖砾”是他抵达当前世界后选的名字。故乡以骨纹生长次序称呼他，那个称呼每一季都会变化，无法固定写在纸上。完美翻译存在时，人们知道该如何随季节调整；总词典撕毁后，只剩栖砾愿意继续回应的两个字。

他的任期却写得十分清楚：

直到东层完成第九次蜕落。

按照断航前最后一份生长图，第九次蜕落应在十七年后发生。可风线消失，我们看不见东层，也不知道当地季节是否仍按原有速度推进。

有人认为任期已经结束。

有人认为在收到故乡确认前，他必须继续履职。

四大阵营更希望他留下使者身份。栖砾是当前世界唯一仍能解释东层旧协议的人。过去的贸易、伤者照看与留居者权益，都需要一个可以代表无海之城的签字。

栖砾自己说：“我不知道东层现在还有没有。”

这句话使所有文书失去根基。

使者之所以能说“我们”，是因为背后有一个仍能回应、撤回和纠正他的共同体。断航后，栖砾对故乡的了解停在十七年前。他可以忠实重复旧决定，却无法知道留下的人是否改变主意。

他每多代表一天，便多把记忆中的东层冒充成现在的东层。

任期最后一日，他来到潮底港旧议事厅。

桌上放着七份等待签署的文件。

第一份要求保障骨纹留居者保留旧层。

第二份处理无海之城遗留水体的所有权。

第三份希望未来航路恢复时优先联系东层。

每一项看起来都保护他的故乡。若拒绝签字，当前世界可能趁失联削减权利；若签字，他又在替无法联系的人决定未来。

栖砾读完，将使者骨印从胸口取下。

骨印仍在生长。它与无海之城最后已知季节保持同样纹路，像故乡仍通过它延续。

“这能证明东层存在吗？”有人问。

“只能证明我还在养它。”

他把骨印放在桌上，没有签署任何文件。

四大阵营的代表提醒他，放弃身份后，骨纹留居者将失去正式代表。栖砾承认这个后果。他没有说凡事应由每个人自行决定，那会忽略一些无法使用当前制度发声的人。

“我可以继续帮助他们，”他说，“但不能因为他们需要帮助，就说我仍代表一个听不见我的世界。”

一名年轻骨纹留居者站起来。

她出生在潮底港，从未去过无海之城，却一直由使者馆记录为东层后裔。她问栖砾：“你不代表东层，那你能代表我们吗？”

栖砾看着她肩上与当前海风共同形成的骨纹。

“不能。”

女孩很生气。

“那你能做什么？”

“坐在这里，听你自己说。”

他们谈了一整夜。

没有共同代表，没有统一声明。七名骨纹留居者分别说明哪些旧习仍对自己重要，哪些只是当前世界替他们保存的想象。有人要保留蜕层，有人早已不再蜕落；有人想未来返回东层，有人只希望故乡若仍存在，知道自己没有等待。

栖砾把这些话逐份记录。

他不在末尾写“无海之城居民共同意见”，只写说话者姓名与日期。

天亮时，使者任期结束。

使者馆的旗没有降下，因为旗绳早已与骨质墙面长在一起。栖砾也没有烧毁骨印。他把它埋在馆外，让那段由自己维持十七年的故乡纹路自行决定是否继续生长。

第二天，旧议事厅仍有人来找他。

一名商人要求解释断航前的债务，一位母亲想知道骨纹孩子发热时是否该蜕层，还有人只是希望听他说几句无海之城旧方言。

栖砾能回答的便回答。

不能回答的，他不再以使者身份给出确定意见。

人们很不习惯。

过去，使者的价值正是替远方说话。如今他总说“这是十七年前的做法”“这是我的判断”“我不知道东层现在怎样”。答案变得零碎，也无法作为权威引用。

可东层在这些限定中，反而不再被冻在断航那一刻。

它可能改变，可能毁灭，可能已进入我们无法想象的新季。栖砾的无知给故乡保留了现在。

同一年，其他世界也有回不去的使者卸下身份。

有人拒绝，继续守着旧命令；有人把使团改成留居者互助之所；也有人坚持只要故乡没有正式召回，自己便永远在任。没有共同规则能够判断哪种选择正确。

栖砾只做了一件额外的事。

他给无海之城写了一封信。

信中没有报告当前世界局势，也没有代表骨纹留居者提出请求。他只写：

“第九次蜕落是否已经发生，我不知道。若你们仍记得我，我已不再以旧任命替你们说话。我现在叫栖砾。”

信写在一片从使者骨印上自然脱落的薄层上。

没有风线，没有地址，也没有可以投递的门。

栖砾把它放进潮底港的海水。

海水当然不会流向无海之城。

薄骨片沉入港底，很快被泥沙覆盖。

所有人都以为这封信不会抵达。

许多年后，我们才知道，同一时期，无海之城有一名当前世界的使者也写下了一封无法寄出的信。

他的名字叫临舟。

那封信走了整整一百年。
