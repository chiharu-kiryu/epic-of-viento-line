# 第002章 不共享一寸

双方第一次共同测量，使门缩小了半尺。

变化发生得很慢。最初只有百叶注意到，六道外的风经过门框时比昨日更窄。等帕加把第二道刻度留在石片上，陌生天空已经被门沿切去一部分。

我们的测量正在固定两界之间的距离。

在当前世界，长度描述物体占据多少空间；门外的尺度却更接近两个存在愿意共同承担多少分离。双方越相信刻痕能够换算，石片便越努力让两套空间服从同一关系，门也随之被压缩成那条线允许的大小。

“停止测量。”百叶说。

对面的细长肢体仍贴在石片上。我们停下以后，它反而加快改变刻度。灯光连续闪烁，像在催促，也像门突然缩小使对方惊慌。

阿尔法无法判断。

他习惯让数字减少不确定，如今每取得一个更精确的数值，两界便更深地被该数值改变。完全不测则无法知道门何时关闭，也无法警告对方。

帕加拿来两根金属尺。

第一根刻当前单位，第二根不刻任何数字，只在双方每次行动后留下材料实际发生的形变。他把有刻度的尺放在地上，将空尺递向门槛。

细长肢体没有接。

空尺穿过门框后迅速变长，末端落到我们看不见的位置。帕加若继续握住，它可能把两个世界像布料一样拉到一起；若松手，我们将失去第一件主动送往对面的工具。

“放。”阿尔法说。

“它还没接住。”

“继续握持的风险高于失去工具。”

帕加没有服从计算。他先松开三根手指，观察金属形变。空尺仍被两边拉扯，却不再增长。对面的肢体也后退一节。

双方都在试探怎样放手。

最后一根手指离开时，空尺悬在门中央。它既没有落向我们，也没有飞入对面。两界各自在尺上留下的力量形成暂时平衡。

门停止缩小。

阿尔法围绕空尺建立新的记录，不再问它“有多长”，只记录每次接触使哪一段发生何种变化。对面似乎也采取相同办法。石片背面的刻线不再追求与我们相等，而是标出门框缩小时他们那边哪些灯熄灭。

其中三盏灯始终没有重新亮起。

我们不知道灯代表生命、建筑还是测量节点。帕加要求把本次接触记录为可能造成三处损失。四方使者反对，认为缺乏证据会引发恐慌。

“那也不能写成无损。”他说。

最终索引留下三种表述：灯熄灭；原因与门缩小的关系未确认；不得据此宣告对方伤亡或安然无恙。

第二日，对面送回空尺。

金属没有刻度，却多出许多细小弯曲。希尔芙发现每一处弯曲都对应我们一侧的动作：帕加松指、阿尔法移动仪器、守军后退，以及孩子把无翼纸鸟从石片上抱开。

对方没有记录长度。

它们记录我们如何改变这件东西。

孩子在空尺末端摸到一处最浅的凹陷。那是纸鸟曾用纸角踩过的位置。凹陷旁有一个陌生凸点，像另一边的存在也在同一时刻触碰。

“它还在吗？”孩子问。

没人知道。

我们将空尺重新放回门中央，没有再刻数字。此后双方轮流使它发生一种微小变化，再等待另一边回应。帕加加热一端，对方让另一端变得柔软；我们弯曲，另一边没有复原，只在弯角旁添出第二种方向。

两界仍不共享一寸。

但我们开始拥有一件共同改变过、又不完全属于任何一套尺度的东西。

第四夜，陌生灯光沿空尺排列成一道门形。

门形中央出现一个很小的人影。

千花在同一时刻从梦中惊醒。她说，自己刚刚遇见那个站在灯下的孩子。
