# 第029章 第一份双界地图

我们需要地图，是因为下一次救援不能再开错天空。

昴负责星光，徐从空中记录当前地形，霍克沿地面确认每一处门伤。司度没有绘图，只在遇见人时问他们准备去哪里。门外则通过蓝端传来灯光距离与山体变化。

没有一项能直接叠在另一项上。

当前地图有方向、长度和高度。门外没有固定北方，也没有脱离关系的远近。同一座山会因居民分散而变大，某盏灯若停止与我们接触，便从地图上远去，却不一定移动。

第一版把灯光投影成坐标。

地图刚完成，门外三处灯群被迫排列成三角。它们之间原本能自由改变的距离开始符合纸上比例。我们立刻销毁。

第二版完全不用坐标，只画双方已发生的接触：石片、空尺、呼吸蓝膜、天国之门和黑暗凹处。它不显示事物在哪里，只显示通过哪一次行动能够抵达。

救援队拿到后找不到路。

“地图不能只避免伤害，也得让人能走。”霍克说。

司度把目的地写到每条关系旁边。

不是“蓝带位于何处”，而是“希望为蓝带送去分散石层”；不是“受压灯场距离多远”，而是“这条行动过去曾让一层方向抵达那里”。路线不保证重复有效，使用前必须重新确认对方是否仍升灯靠近。

第三版由许多可移动纸片组成。

当前地形画在纸上，门外关系刻在蓝片里，中间用没有刻度的细环连接。任何纸片不能覆盖蓝片，蓝片也不能替当前地面改变位置。行动者只能在两者之间添一条暂时路线，并写下使用后两边各发生什么。

它不是一张全景图。

却足以让第一批修复物资避开此前受压灯场。

瑟缇在蓝片上选择三处升灯关系，塞立准备对应方向石层。徐从空中确认输出点不会立即压住居民，霍克则在地面检查绳路。司度最后问门外那三处灯是否仍愿意靠近。

第二处灯已经落地。

路线被划去。不是擦除历史，而是标记此次不能使用。

两层分散石顺利抵达其余接点。当前一间屋失去固定地面，门外一处灯群获得侧向活动空间。地图把两边变化分别留下，没有用同一种颜色表示“改善”。

第一份双界地图因此被接受。

四方立即要求副本。门外也有许多灯群希望获得。复制本身却会制造新的关系：每多一张地图，就多一套能够让某些地点被当前行动抵达的路线。

我们只制作局部副本，由对应接点保管。

西尔西斯负责记录谁看过哪一部分，不监视地图外的生活。拉吉斯则指出，控制副本仍可能变成控制通道。地图的持有者不能因为保管路线，便拥有路线另一端。

规定写下以后仍然有人私抄。

一名测绘员把三处蓝片位置拓印到普通纸，想带回本方。拓印离开新港时，纸面突然向内凹陷，形成一条能够容纳手指的深沟。

他没有画出真正坐标。

却让“纸上的这里”和“蓝片上的那里”第一次建立稳定对应。

我们把手指伸到沟边，里面吹出既非当前海风、也非门外双向风的空气。

第一份双界地图没有只描述两个世界。

它在两套无法重合的尺度之间，画出了一处新的地方。
