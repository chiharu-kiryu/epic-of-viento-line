# 第六十九章　拉吉斯出售一次归程

拉吉斯说要出售归程时，潮底港安静了很久。

不是因为这句话荒唐，而是因为大家都听懂了它的诱惑。

风线成为航路后，最先增长的不是远行，而是等待。港口里住满了回不去的人：有人缺少一段关系，有人的故乡已经蜕去旧季，有人必须等待静星尚未到来的停顿。
官署可以记录他们，使者可以同情他们，航船也愿意搭载他们，却没有谁能承诺一次完整的抵达。

拉吉斯带来的正是承诺。

那名灰衣旅人把失效的归途标记放在桌上。标记是一片半透明甲壳，外侧刻着当前世界的方位，内层却长着骨纹，中央还有一小块不会随身体移动的影子。

“你叫什么？”拉吉斯问。

旅人说出一个短促的音。翻译记录没有反应，瑟缇也无法在关系中找到它的落点。拉吉斯便没有追问，只暂时称他为持标者。

“你从哪里来？”

持标者指向失效标记。甲壳内部浮现一座极小的门，门后似乎有许多人共同抬着某种重物。影像只持续一瞬，随后碎成三种互不相容的方向。

“你拿什么买？”

持标者摊开手掌，里面空无一物。

围观的人发出失望的声音。拉吉斯却把甲壳翻过来，注意到旅人的掌纹正在逐渐变浅。每当他试图说明故乡，身体便失去一部分能够证明自己来自那里的痕迹。

“你已经在付了。”拉吉斯说。

这句话让许多人愤怒。痛苦不是货币，失去也不天然构成债权。若商人可以把一个人的伤当作价款，最贫困的人反而会成为最富有的货仓。

拉吉斯接受了指责。

“所以那不是付给我的。”他说，“那是这趟归程正在消耗的东西。若不先记下，等他到家时，我们会说一路没有成本。”

他拿出四张不同材质的契约。

第一张属于当前世界，写明船只、粮食、停留时间与失败后的赔偿。

第二张没有纸面，必须由瑟缇和持标者共同维持一段可撤回的靠近。

第三张是一层骨片，记录旅人愿意在抵达前蜕下什么，又有什么绝不能被道路取走。

第四张仍是空白的。那是留给静星停顿之后的世界，因为我们尚不知道对方以什么确认一次约定。

“我卖的不是路。”拉吉斯再次说，“路的每一段都属于正在承受它的人。我只出售把这些分开的同意逐一凑齐，并在其中一段断裂时，不假装其余承诺仍然完整。
”

有人问价钱。

拉吉斯报出的数字低得出奇：一枚当前世界的铜币。

港口随即沸腾。等待者纷纷举起钱袋，投机者开始替尚未来到的人购买名额，四大阵营的商行更在一刻之内写出数百份转售契约。若一次跨界归程只值一枚铜币，那
么控制购买顺序就足以控制所有未来航路。

拉吉斯把唯一那枚铜币放在桌上。

“这不是航费。”他说，“是当前世界确认自己收过价款。其余每一段，另行偿付，而且不能换算。”

瑟缇故乡要求持标者在通过时维护一名陌生伤者与遗失影子之间的联系。骨纹世界要求他留下甲壳外层，让一条受损街道借其生长一个季节。静星的部分没有开价，
只在某次停顿中使他的掌纹停止变浅。

这些代价没有共同单位。

也正因不能换算，没有人能通过多付铜币买走别人的同意。

拉吉斯花了十一天拼出归程。泽尔克负责当前航段，司度逐界重问方向，斯菲尔在不同天空间搬运交接所需的星光。拉吉斯本人没有登船。他坐在潮底港，每完成一
段便撕去契约的一角，表示这一部分不再能被转卖。

第三天，第一段关系突然撤回。

第五天，骨纹桥提前蜕落。

第七天，静星漏过了一次原本预计的停顿。

每次中断，等候的人都要求拉吉斯调用备用路线。他拒绝了。备用路线意味着提前购买尚未发生的同意。于是持标者在界间多等了四日，带去的食物腐坏大半，当前
世界那张契约因此赔给他六枚铜币。

“你只收了一枚。”我提醒拉吉斯。

“做错估价的人该付钱。”他说，“不能让路替我赔。”

第十一天，持标者抵达静星之前。

他的灰衣已经拆成关系结、骨质包裹与一圈无热的蓝光。只有那枚归途标记仍保持完整。奘尘守着停顿，司度把最后一块空白路标平放在他脚边。

静星停顿。

甲壳中央的小门打开了。

门后那些共同抬着重物的人再次出现。这一次我们看清，他们抬的并不是物品，而是一段被折叠的道路。持标者只要跨进去，归程便会完成。

他却停在门槛外。

内层骨纹开始脱落，中央的影子也向门内伸去。按照契约，他必须留下甲壳外层帮助骨纹街道生长。但外壳剥离后，门的形状随之改变，门内的人忽然不再认得他。

“停止交接。”拉吉斯通过沿线传来的记录说。

所有人都知道，若此刻停下，十一天的代价将近乎白付。持标者也可能再也等不到完全相同的停顿。可契约中写得很清楚：归程的完成不能以抵达一个不再承认归者
的地方为准。

持标者伸手按住即将脱落的甲壳。

他重新与骨纹世界协商。那座受损街道最终只取走外壳的一半，余下一半保留门的辨认。作为交换，他答应在抵达后，若仍有能力回应，将把一个完整生长季的变化
传回来。

没有人保证他会履约。

风线也无法跨界追债。

拉吉斯仍然同意修改契约，因为另一种选择是让一纸正确的契约把旅人送错家。

下一次停顿到来时，持标者跨过门槛。门内的人放下折叠道路，将他围在中央。那枚影子先认出了位置，骨纹随后与地面相连，最后才是他已经模糊的掌纹。

门合拢前，一枚当前世界的铜币从里面滚了回来。

那是拉吉斯收下的价款。

持标者将它退还，或是他的故乡拒绝承认那场买卖，我们无法确定。

港口中的投机者立刻声称交易已经失败：没有价款，就没有购买；没有购买，就不应占用航路。拉吉斯捡起铜币，在契约最下方写了一句：

“归程已经发生，买卖尚未完成。”

他没有把铜币再次收进钱袋，而是嵌在潮底港的桌面上。此后每一个试图购买归程的人，都必须先看见它。

一次归程可以出售。

但出售不是将道路变成货物，也不是把抵达变成商人的功劳。它只是让一个承诺拥有可以追问的人：哪一段失约，谁来偿付；哪一种代价被隐藏，谁必须把它重新写
出来。

拉吉斯保留了那份没有完成的契约。

第二天，当他准备等待持标者传回一个生长季的回应时，第四张空白契约上自行出现了一道裂纹。

裂纹组成的不是文字，而是一个问题：

“买家是谁？”
