# 第042章 皮克多尔的毒成为问候

皮克多尔没有擅自下毒。

四方共同要求他找出隐藏连接。共同耳朵关闭后，仍有译文能在四座塔之间无痕移动。普通标记会被翻译系统读取、改写或删除，只有一种不依赖文字的身体变化能
够沿原路留下痕迹。

他提出使用极低浓度蝎毒。

毒液不会杀死当前成人，只造成短暂刺痛。所有接触节点都提前收到解毒剂，也同意被标记。至少在当前世界，试验经过明确说明。

第一滴毒进入北侧翻译塔。

六息后，另外三塔先后出现刺痛反应。皮克多尔据此画出一条绕过所有公开接口的共享线路。线路没有管理者，是四套系统为了交换常用词义自行生长的。

他准备切断，毒性标记却继续向第三空间移动。

共享线路把“低浓度进入另一身体、使其注意来源”翻成门外一种接触动作。蓝色灯群开始主动靠近毒液。对它们而言，身体变化本就是交流，轻微刺痛近似敲门。

第一处灯群用相同毒性回应。

皮克多尔尾针立刻发热。第二处回应进入洛姆，十段身体同时出现红斑。第三处门外群体没有承受当前毒素的结构，一接触便失去距离，撞成一团。

追踪标记变成了问候。

更多灯光向它靠近。

“停下！”皮克多尔向翻译塔喊。

系统把这一声与毒性入口绑定，译作“停止后继续回应”。门外灯群反而加快扩散。

他没有继续用语言。尾针刺入共享线路，将自身毒液全部回收。当前四座塔的刺痛消失，门外已经复制的身体变化却不能随之撤回。

皮克多尔带着解毒剂进入第三空间。

瑟缇拦住他。解毒对当前身体是修复，在门外可能被理解成取消问候、切断已经建立的关系。受影响群体中，有些正因毒性受到伤害，另一些已经把它纳入交流。

不能给所有人同一种解药。

皮克多尔先在自己甲壳上展示毒与解毒的变化。他让一小块皮肤红肿，再使用药剂恢复。门外可以观察，不自动承受。

两处灯群主动靠近解毒变化。

第三处远离。洛姆内部又出现分歧，六段接受，四段拒绝。皮克多尔把药分到局部软板，不让中央灯统一摄取。

最严重的一团门外身体无法表达。它们被当前毒素压得过近，所有灯重叠。皮克多尔只能依据紧急状态先用最低剂量解毒，使身体重新分开。

其中一盏灯恢复后立即攻击他。

短枝划开甲壳，伤口不深。瑟缇没有把攻击翻译成忘恩或敌意。对方可能因未经同意改变身体而反击，也可能把解毒视作另一种侵入。

皮克多尔没有还手。

“我先用了。”他说。

他的初次试验只获得当前节点同意，没有询问共享线路是否会进入门外。翻译系统把毒变成问候不是他能预见的全部，却不能让毒液从尾针与行动记录里消失。

四方也不能把责任只交给他。

共享线路由四套翻译塔为效率共同维持，试验负责人知道线路去向未知，仍选择注入。每一塔都希望借毒找出别人隐藏的接口，没有一方先关闭自己的。

事故后，门外有一处灯群继续使用低毒变化。

它们在见到熟悉者时，让边缘薄片短暂发红。当前译者想把它收入词典，标作“问候”。

皮克多尔拒绝。

“我的毒不是问候。它们的动作也不一定等于我的毒。”

记录只能写：该群体在本次事故后主动重复类似身体变化，常发生于靠近前。含义由它们以后继续使用，不能让事故起源永久占有。

皮克多尔保留一处红斑，没有立刻解掉。

不是用伤赎罪。

那处皮肤连接着共享线路最后一个未找到的节点。毒性仍在向某座翻译塔传递。

第四方否认那里还有接口。

红斑却每隔一刻，便像有人从另一端轻轻敲门。
