# 第一百一十九章　世界没有完成

无翼纸鸟越过门槛后，有人提议宣布一个新时代。

创世神离开创世位置，世界边缘被拆开，无翻译会面也第一次没有演变成战争。三幕历史似乎终于抵达足以命名的结点。

人们提出许多称呼。

万界时代。

相望时代。

无路纪。

还有人想沿用界外风，把一切归入同一场仍在继续的风。

我没有替他们选择。

时代名称可以由需要它的人使用，却不能因为潮底港看见一只纸鸟过门，便宣告无数地方同时进入我们的新纪元。

每个世界保留自己的今天。

这个世界也可以有许多互不相同的时代感受。

有人认为新生活已经开始。

有人仍活在断航那天。

正确世界门外每天都有人等待。阿尔法没有找到能询问门内所有人的方法，贝塔也没有再次敲击。门后的山河也许安稳，也许早已改变。关闭造成的伤害没有因宇宙
拒绝唯一便得到解决。

七名失散乘客仍无结论。

第三空间的白色手印已经脱落，不能证明获救，也不能证明死亡。洛姆留在当前世界的几段身体各自生活，有些仍想寻找其余部分，有些已经拒绝“完整”这个说法
。

瑟缇没有回到故乡。

她结束了那段长期维持的关系，不再每天等待。可某些夜晚，她仍会把第二只杯子放在桌上。留下成为现在，不等于归乡愿望从未存在。

火星陌生卵也没有孵化。

马力克仍守着接触面，拒绝让任何一方因纸鸟成功跨越便把卵切开。泽尔克仍分不清方向，只能沿不同绳结走过红色荒原。

百叶离开创世位置后，世界没有立刻学会自治。

望风山裂缝每年扩大，梦醒边缘也偶尔使人带回不属于自己的记忆。有人要求百叶重登神座，至少等秩序真正稳定再离开。

百叶每次都参与修补。

但不回到最终位置。

“你怎么知道什么时候算稳定？”千花问那些人。

没有人回答。

如果必须等世界完成，创世神便永远不能离开创世。

共同举起的基石也在腐朽。

当前木楔需要定期更换，陌生一侧的支撑有时数月不出现。风线随重量忽粗忽细，无法成为可靠联系。缇洛选择的称呼仍只在具体会面中有效，我们不知道下一次呼
唤是否还会得到回应。

无翼纸鸟或许已经被拆开。

也许被保存、遗忘，或从未以我们理解的方式抵达。

没有一个结局能够把这些空白变成圆满。

“那这三百六十章写了什么？”有人问我。

我的总卷已经放下，只剩个人笔记。

“写我看见世界没有按任何一次答案完成。”

创世试图让混沌完成为六道。

古神试图让力量完成为秩序。

人文时代的阵营试图让土地、信仰与制度完成各自的世界。未然潮让无数可能要求进入现在，第七秩序又让所有差异完成为唯一宇宙。

每一次完成都解决真实问题。

也都会把尚未被看见的地方压到边缘。

世界没有完成，不等于世界一直失败。

山河此刻能够承受人，孩子仍会出生，名字仍在具体关系中被呼唤。一碗饭可以吃完，一间屋可以修好，一段关系也可以真正结束。

未完成的是任何人对全部世界的最终版本。

潮底港仍在扩建。

不是围绕界外之门。百年后的人口需要新屋，渔船也需要更宽泊位。曾经的通航台一半成为市场，一半被海水冲走。孩子们在基石附近玩耍，被大人提醒不要触碰木
楔。

对他们而言，万界不是宏大使命。

只是某些雨日门边会出现一个叫缇洛的陌生存在，而有一块石头必须由两边共同支撑。

凛麦在市场种下一小片当前麦。

干枯异界麦穗仍不能发芽。她已经忘记更多，却把“这是我的遗忘”教给后来记录者。

谷沙重新能够辨认直线。

他没有把陌生箭杆修成武器，只用它支撑麦穗。箭曾切开什么、救过谁或伤过谁，仍无人知道。

雾禾偶尔敲响界外之钟。

次数不固定，也不追求回应。附近不愿听的人仍可提前离开，钟声先属于此地生活，再可能在某处边缘留下压力。

我也继续写。

个人笔记越来越厚，却始终没有重新装成总卷。每一页日期只属于潮底港，页边注明我不在火星、不在缇洛来处，也不在所有无名地方。

世界没有完成。

这句话不是结论。

只是一处给后来变化留下的位置。

当天傍晚，基石另一端传来轻微压力。缇洛没有显形，风线却使当前木楔向外移动半寸。

拉朵与几名港口居民一起把它推回。

没有史诗性的危险，也没有新的宇宙真理。只是一块长期承重的木头需要维护。

做完之后，他们回家吃饭。

风仍留在石缝里。

世界不必完成，才能继续。
