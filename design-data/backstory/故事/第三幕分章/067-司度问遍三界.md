# 第六十七章　司度问遍三界

静星的停顿被确认可以承载交接后，最先来到无海之城的不是使者，也不是军队，而是一群迷路的人。

他们从受伤的旧风线中跌出，衣物上同时带着三种世界的痕迹：当前世界的盐霜、瑟缇故乡的游离影子，以及骨纹世界尚未硬化的白色细屑。没有人知道他们原本从哪里出发。更麻烦的是，他们自己给出的答案也不相同。

其中一个老人指着东方，说家在那里。

一个肩部长着透明骨枝的年轻人说，家在他尚未偿还的三次照看之后。

还有一个被称为“孩子”的小小身影不断蜕下薄壳。每一层壳都指向不同方向，每一层都坚持自己才是要回去的人。

司度听完，背起路标出发了。

他的路标仍是当前世界常见的木牌，上面刻着距离、方向和地名。在我们的道路上，它们救过许多人。到了瑟缇的故乡，第一块木牌便惹出了麻烦。

司度在牌上写：“归途向前七里。”

瑟缇看见后立刻将它拔了出来。在她的世界里，“向前”不是空间方向，而是关系进一步靠近。一个与家人决裂的人沿着那块路牌走，只会离故乡越来越远；一个正被追捕的人甚至可能被迫靠近追捕者。

“那该怎么问？”司度说。

瑟缇没有给他一条新路，只教了他第一个问题：

“你想靠近谁，又允许谁靠近你？”

老人回答，他想靠近东边的屋舍，不想靠近屋里的人。

这在我们的地图上近乎自相矛盾，在瑟缇的关系道路上却十分清楚。她为老人找出一条只接近房屋、不接近居住者的狭窄路径。那条路绕过一段已经破裂的亲缘，远得无法用里数估量，却真的把老人送到了门前。

司度没有把木牌丢掉。他在背面刻下了这个问题。

来到骨纹世界，他又遇见另一种迷路。

肩生骨枝的年轻人知道自己所属的城市，也认得那座城当季的纹路，可城市已经蜕去两层旧壳，移动到了新的生长带。司度按照昴的星图确定方位，带他走了整整一天，最后抵达的却是一片被舍弃的街区。

骨纹世界的引路者问：“你愿意留下什么，才算抵达？”

年轻人摸着肩上的透明骨枝，说自己不愿蜕去它。那是他在接触战争中替别人承受的一季伤痕，也是三次照看的凭证。可他所属的城市已经进入不容旧枝穿过的新生层。若坚持保留，他便无法回到原来的生活里。

司度不能替他决定。

他们在废弃街区住了两夜。第三天，年轻人削下一小段骨枝，埋进旧城区，却留下了大半。他没有返回原来的家，而是在新旧生长层之间找到一处可以容纳残枝的空地。

“这算到了吗？”我问司度。

“他停下了。”司度说，“但不一定到了。”

他在第二块路标上刻下骨纹世界的问题：

“为了抵达，你愿意蜕下什么，又必须保留什么？”

最后一个孩子最难。

每当我们询问，它都会裂出一层新壳。旧壳说要回当前世界，新壳说要去骨纹世界，更内侧还未脱落的那一层则随静星的停顿一同起伏。我们起初以为它在恐惧中反复改变主意，直到奘尘指出，那些壳可能并不属于同一个“它”。

在静星的世界边缘，存在不是一条连续燃烧的火，而像许多停顿共同维持的节律。我们所谓的孩子，也许只是在风线受伤时暂时重叠的几段生命。把它送往任何一地，都可能救下一部分，同时抛弃其余部分。

司度坐在它面前，第一次不知道该问什么。

他试着询问方向。壳层散开。

他询问关系。外壳靠近老人，内壳远离。

他询问愿意舍弃什么。所有壳都紧紧闭合。

静星停顿时，最里面传来一次轻微震动。奘尘把十九枚石子排开，发现它的节律并不是回答，而是在校正问题。司度于是把三块路标全部平放在地上，不再让任何一块指向前方。

“哪一段路结束之后，”他问，“你仍愿意被我们认作出发时的你？”

孩子没有回答。最外层的壳却主动留在当前世界，中层的骨枝向无海之城生长，最内侧的震动沿静星的停顿返回风线。它们分开后都活着，却没有任何一个独占原先的名字。

我们无法判断这是不是归还，也无法判断它们是否仍是同一个人。司度只在三处分别留下一枚相同的空白路标。牌上没有写“此处是家”，而写着：

“你曾从这里作出一次不能被合并的选择。”

之后，司度又走遍已经接触的三界。他在当前世界问：“你要去哪里？”

在瑟缇的故乡问：“你要靠近谁？”

在骨纹世界问：“你愿以哪一季的自己抵达？”

面对静星，他什么也不问，只等待对方留下可以交接的停顿。

有人建议把这些问题汇成一张通用问路表，发给所有跨界者。司度拒绝了。他说一旦固定顺序，第一个问题便会暗中统治其余问题。若先问地点，我们便会把关系当作路线的附注；若先问关系，又可能把某个只想去往一座空屋的人强行绑回人群。

于是他只制定了一条极小的规矩：每进入一个世界，旧问题必须先放下，由当地仍在承受道路后果的人决定该问什么。

这条规矩慢得令人烦躁。

一支原本一天可以通过的队伍，常常要在交界处停留数周。有些人因等不及而离开，有些货物在询问中腐坏，也有人指责司度把简单的道路变成了无休止的犹豫。

司度没有辩解。他背着越来越多的空白路标，继续站在风线旁。

“快路会把走错的人更快送到错误的地方。”他说，“我至少要让他们知道，自己回答的是哪一个世界的问题。”

那天，我随他走完一段短短的归程。路程在当前世界只有二百步，在瑟缇的故乡却要绕开两段拒绝，在骨纹世界又必须等一层旧皮自然脱落。我们用了三天，最后只前进到静星的一次停顿之前。

司度没有说我们迷路了。

他把路标插在停顿之外，等另一边决定是否接过它。

那块牌子没有箭头。风从三界之间穿过，使它轻轻摇晃。

我忽然明白，真正的问路从来不只是向别人索取答案。它也在询问：我们是否愿意让目的地保留拒绝成为目的地的权利。
