# 第111章 忘记以后仍然负责

我先忘了闻砾的木杖。

名字还在，港口炮击也记得，却想不起他曾经如何拖着伤腿站到白线中央，叫廉戍看见海堤决口时留下的肩伤。翻阅索引后，我找到那段经过，字句都熟悉，读起来却像别人的记录。

镜屑从指尖向外移动了一寸。

它正把未然潮期间形成的连接带走。若任其离开，我或许不再因众人同时注视而分裂，也不会被共同记录拉入无主后果。代价是那些经历在我身体里留下的改变也会变成纸面知识。

我用布条绑住指根。

百叶说这无法阻止落潮，只会使镜屑撕开血肉。我仍然绑着。不是想永远留住异物，只是不愿让身体在我尚未决定时自动恢复成过去的样子。

类似的遗忘正在各处发生。

周重新升上最高天空。他记得灰港，也记得自己曾拒绝用自焚喂养“可接受牺牲”的火，却逐渐忘记当时为何愿意承认白昼不由一人承担。太阳比昨日更亮，新港所有屋顶同时起火。他仍以为只要再提高一点，黑暗便会彻底退去。

槐姐爬上钟楼，把烧焦的面包铲扔到他脚下。

“下来帮我灭火。”

周看着凡人泼水、拆瓦、把孩子从烟中送走。那些动作没有唤回完整记忆，却使他的身体再次学会降低光芒。他落到街面，第一次提水时把半桶洒在自己甲靴上，第二次才真正泼中火。

“我想不起你为什么用这个打过未来士兵。”他对槐姐说。

“那就先记得你今天不会灭火。”

周没有因遗忘过往教训便免于当前责任，也不必仅靠一段英雄史证明自己已经改变。习惯会退，选择仍可重做，只是每次重做都可能产生新的损失。

西尔西斯则重新架起全域监视。

他记得曾主动留下盲区，却忘记盲区为何值得承受。十三座塔合拢后，未然者不断消失，他相信只要看见所有位置，就能及时救下更多人。第一日，他确实找到七名被塔影拖走者；第二日，四方军队开始使用他的视野封锁迁移路线。

当居民要求关闭时，他指着七名获救者。

“没有视野，他们已经消失。”

其中一人名叫松回。老人走到监视镜前，要求西尔西斯删除自己的位置。

“你会失去保护。”西尔西斯说。

“我知道。”

“再次被拖走怎么办？”

“那是我的风险。救过我一次，不等于以后都可以看我。”

西尔西斯没有立刻同意。他与松回争吵很久，最终只关闭老人住所周围的一小片视野。当天夜里，松回确实失踪了三个时辰。众人找到他时，他只是在无监视区里替另一个将要退潮的人守门。

获救数字因此没有证明哪一方完全正确。

西尔西斯保留部分远距警戒，拆除能够追踪个体生活的镜面。比起第一次决定留下盲区，这次更不整齐，也更容易被人指责。

凛麦忘记了第四名旧战友。

她在仓房墙上看见自己写过的名字，却无法想起对应面容。有人建议让千花从梦里取回，千花只能找到一张军旗下的模糊侧脸。强行填补可能把别人的记忆放进凛麦身体。

凛麦没有接受。

她把名字重新读了三遍，在旁边写：“我已不记得，但曾由我亲手写下。”关系不能只靠当前情感证明，遗忘也不应使过去自动失效。

最危险的是百叶。

他开始重新相信六道能够封闭十三座塔。过去的错误、苇生被删去的村庄、六道外的风，全都逐渐变成他知道却不能切身理解的资料。力量仍在，迟疑却被落潮带走。

他抬手时，千花站进封印范围。

“你要连我一起封吗？”

“你会离开。”

“那也先问我。”

百叶的手停在半空。不是记忆恢复，而是眼前这个具体的妹妹仍在拒绝。熟悉的人不必用称号提醒他曾经成为谁，只要让今日的行动重新遇见边界。

我们开始把“学会过什么”从人物赞语改成可以重复的动作。

周每天跟居民灭一次普通炉火；西尔西斯关闭一处自己最想看见的房间；廉戍在发出警报前先叫目标名字；我每完成一页，便交给当事者指出一处不愿被我直接修改的地方。

这些动作不能保证品格。

它们只在记忆退去时，为下一次选择留下可踩的石头。

当夜，镜屑终于穿破绑带。

一滴带紫光的血落地，十三座塔同时打开门。门后不是未然大陆，而是未然潮到来以前的世界。

那里没有归钟号，没有现实之战，也没有任何人需要记住自己曾经如何改变。
