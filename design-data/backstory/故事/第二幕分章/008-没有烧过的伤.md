# 第八章 没有烧过的伤

战船靠岸以前，火已经先到了。

它没有烧帆，也没有烧木头，只附在船员的伤口上。那些人每走一步，焦黑皮肤下便亮起细小红线，仿佛一场大火仍在身体里寻找可以继续燃烧的东西。

齐草带着药箱上船。

军政守卫拦住她，说船员可能携带未然污染。

“会传染吗？”她问皮克多尔。

“不知道。”

“那就等他们烧死以后再确认？”

守卫仍不让路。

齐草把药箱从他头顶扔过去，自己翻过围栏。她不是第一次用这种方式解释医者的优先顺序。

我与皮克多尔随后登船。

船名已经烧毁，桅杆只剩一半。甲板上共有六十三人，二十一人仍能站立。伤口分布很奇怪：火焰避开衣物，从皮肤内部向外灼烧，许多人穿着完整军服，胸口却像
被熔铁穿过。

齐草剪开一名少年的袖口。

“什么时候烧的？”

“七个月前。”

“一直没愈合？”

“每天午夜重新烧。”

“谁放的火？”

少年抬起尚能睁开的眼睛，越过我看向岸上。

克鲁斯刚带人抵达。

“他。”

甲板上所有清醒者同时转头。

有人拔刀，有人发出野兽般的低吼。一个失去双腿的女人用手臂撑起身体，把烧变形的军徽扔向克鲁斯。

“灰港四万七千人。”她说，“你还记得吗？”

克鲁斯接住军徽。

那确实属于他的军队。

编号、铸纹与背面那道防伪缺口全部正确。军徽记载的部队却尚未成立，灰港也不是现世地名。

“我没有去过那里。”他说。

“你站在北墙下，下令封死三座城门。”

“没有。”

“你说火能阻断梦疫。”

“没有。”

“我女儿在门后。”

克鲁斯没有继续否认。

他将军徽放到甲板上，解下武器，交给身后的副官。岸上守卫因此骚动，认为他在敌对来客面前放弃自保。

“我不记得灰港。”他说，“也没有下过这道命令。”

女人死死盯着他。

“那我们的伤是谁造成的？”

“我不知道。”

“你只会说不知道？”

“如果我为了让你得到答案，承认一件没有做过的事，真正下令的人就会消失。”

这句话没有安慰任何人。

女人扑向他。

她失去双腿，动作仍快得惊人。齐草来不及阻止，皮克多尔的尾刺已经扬起。我抓住他的手臂。他若用毒，眼前便会变成“来自未然的袭击者被现实英雄制服”，所
有尚未回答的问题都会被暴力替我们结束。

克鲁斯没有躲。

女人把他撞倒在甲板，烧伤的手掐住他的喉咙。她身体里的火顺着两人接触处蔓延，在他颈侧烙出一圈红痕。

“叫他们开门。”她说。

“什么门？”

“灰港北门。”

“这里没有灰港。”

“那就造一座！”

她哭了出来。

不是为了复仇。

她仍困在七个月前的城门外。只要门还没有打开，女儿就仍可能在里面等她。她要的不是克鲁斯认罪，而是让那场未发生的火继续拥有一个可以被挽回的现场。

齐草慢慢蹲下。

“你女儿叫什么？”

“茸衣。”

“几岁？”

“六岁。”

“你最后看见她在哪里？”

女人的手开始发抖。

齐草没有说灰港不存在，也没有承诺找回孩子。她让女人讲出城门、街道、女儿穿的鞋和火烧来以前正在吃的东西。

那段叙述不能证明克鲁斯有罪。

却能让茸衣不只剩一项用来指控他的数字。

女人最终松开手。

克鲁斯颈侧的红痕仍在燃烧。

齐草检查后说，那不是普通烧伤。女人记忆中的因果通过接触转移了一部分：在她经历的历史里，克鲁斯下过命令，于是未然潮正试图让现世的他获得与命令相称的
伤痕。

“会继续吗？”我问。

“如果越来越多人认定他就是放火者，会。”

克鲁斯看向船上六十三人。

“他们全都记得我。”

“共同记得也不能替代这里的行动。”我说。

他没有因这句话轻松。

未然军徽上的战术编号确实出自他的体系。封闭城门阻断扩散，也是他在类似情况下可能选择的办法。他没有做过，却无法诚实地说“我绝不会做”。

“把灰港战况给我。”他说。

“你想证明不是你？”

“我想知道什么会让我下令。”

这是一条危险道路。

研究未来可能帮助他避免那场火，也可能把完整战术第一次交到现世。

我那封明日信要求“不要相信第一次赤月警报”。雾禾收到的画里，三天后赤月升起，钟铺燃烧。灰港幸存者则说，克鲁斯为阻断梦疫烧城。

这些碎片正在互相寻找。

我们把伤者转移到港口空仓。军政没有关押他们，克鲁斯也没有以受袭为由追责。作为交换，所有武器暂时留在船上。

处理到最后一名伤者时，齐草发现一件更糟的事。

他们的伤在接近新港以后开始愈合。

不是因为药。

每当他们讲述灰港，焦黑皮肤便长出一点新肉。与此同时，讲述中的细节开始出现在现世：仓库墙面浮出灰港路牌，港钟多了一段陌生警报，军政地图上出现一座本
不存在的北门。

疗愈他们，似乎正在让那场战争靠岸。

有人建议停止询问。

齐草把药盆摔在地上。

“那就让他们为了保护我们的现实，永远带着火？”

没人回答。

“伤可以治。”她说，“历史怎么长，找别的办法。”

夜里，克鲁斯独自来到空仓。

他把一份尚未启用的梦疫应急预案交给我。第七页明确写着：若传播越过三道隔离线，指挥官可封闭城门，以高温清除污染源。

签署栏是空的。

战船来以前，这份预案已经存在。

“我没有烧过灰港。”他说。

“我知道。”

“但我写过通向它的第一句话。”

他没有要求我销毁预案。

我们把它放在钟罩下，与雾禾那封明日信并排。

一幅画预示钟铺燃烧。

一份现世预案允许焚城。

一群伤者记得火已经发生。

三者之间尚没有完整因果，却已经足以让所有人开始害怕赤月。

午夜，港口第一次响起陌生警报。

声音与灰港幸存者描述的一模一样。

天空没有月亮。

可每一道尚未愈合的伤口里，都升起了一轮红色的光。
