# 第二十二章 星空之子失准

昴从不迷路。

他睁眼看见的不是屋顶与母亲，而是万千星宿托举星核旋转。土、木、金、水与火在他体内各有位置，只要一种元素被唤醒，群星便会给出下一步。

这一次，所有下一步都正确。

也因此全部错误。

第四艘未来粮船正在接近白庭。

浮空城仍有部分居民没有撤离。粮船若撞上城基，来自下一季的谷物会进入天界誓约，白庭可能获得足以避免坠落的新重量；北方田地却会因此失去更多收成。

昴被派去寻找粮船。

他先唤醒水星位。

波光指向西方。

金星位却在同一刻指向东面，表示船体金属位于相反方向。土星位落在头顶，木星位深入地下，火星位则沿他自己的影子不断延伸。

“星图坏了？”随行观星员问。

昴摇头。

每一个方向都有一艘粮船。

西方那艘正穿过现实海面。

东方那艘已经撞上白庭。

头顶那艘把谷物撒进浮空城。

地下那艘沉入第二脉。

他影子里的船则在某场战争中成为军粮运输舰。

未然潮没有让星辰失准。

它让所有可能位置同时获得坐标。

昴仍选择了西方。

那是肉眼唯一能看见的船。

他踏水追出百里，船影却始终在前方相同距离。每当昴借金元素震开海浪，东方的船便更接近白庭；当他用木光缠住西方桅杆，地下矿脉又传来粮仓生成的震动。

他的每一种力量都在一条未来里命中。

现世却没有一条完整结果。

昴开始急躁。

星辰从来告诉他“你不孤单”。如今万千星位仍在回应，却像许多人同时抓住手臂，把他拉向各自需要的方向。

他第一次同时唤醒五种元素。

土盾、木光、金震、水路与火尾在海面汇成一幅完整星图。五艘粮船的轨迹被强行叠在一起，远处船影终于停下。

白庭却剧烈下沉。

五种可能在同一坐标重合，重量全部落到浮空城基。

昴立即停止。

元素散开时，他从半空坠下，被斯菲尔用暗潮托住。

“我选错了。”昴说。

斯菲尔没有回应。

“你知道该选哪一个，对不对？”

斯菲尔身体里的光暗交替一次。

仍是否定。

昴从它背上站起来。

“你走过那么多世界。”

斯菲尔发出低沉节律。

观星员听不懂。

我从第一幕留下的星鼓契约里认出其中意思：

“走得远，不等于拥有别人的方向。”

昴看向自己的五色星点。

他一直把多样的力量视作宇宙陪伴。可陪伴不是替人选择。星辰能够告诉他不同元素会通向哪里，不能保证其中一条就是应当发生的明日。

“那怎么找现世的船？”他问。

斯菲尔把光全部熄灭。

海面只剩风、盐味与远处断续的木板声。

昴也闭上星图。

没有宇宙坐标以后，他听见一群海鸟。

鸟群正绕着西北方飞，却不肯落下。未来粮船没有真正的现世气味，鸟能看见谷物，身体却找不到可以停靠的甲板。

昴不再追星。

他追鸟。

我们在一片普通海雾后找到粮船。船体时隐时现，货舱已打开，一道由谷粒铺成的路正向白庭天空生长。

昴没有摧毁船。

他先用水流隔开谷物与海面，再以土盾托住已经获得重量的部分。木光只缠住现世绳索，金元素击断未然锚链，火则被他留在体内，没有向任何一条未来发射。

每次只使用一种力量。

每一步都确认正在接触什么。

这比同时点亮五种星位慢得多。

白庭又下降了十七尺。

城中有人因此受伤。

昴没有把“避免更大坠落”当作这十七尺不存在。他返回后逐户帮助修复，听那些选择留下的居民责怪他为什么来得这样晚。

“因为我先问了星星。”他说。

一个老人问：“星星怎么说？”

“每颗都说自己对。”

“那你以后问谁？”

昴看着老人屋里倾斜的桌面。

“先问脚下有没有地。”

未来粮船被拖到未然泊位，没有卸货。它在失去星位以后逐渐变淡，却留下半袋已经接触现实海水的谷物。

崧科前来检查。

他只看了一眼，便算出至少七种用途：

播种、救济、诱导粮船、校验第四星轨、制造军粮、偿还北方田地，或彻底销毁。

每一种用途都有概率。

四方同时要求他给出最优选择。

崧科合上计算本。

“不算。”
