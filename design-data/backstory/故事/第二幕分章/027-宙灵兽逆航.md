# 第二十七章 宙灵兽逆航

斯菲尔从来没有返航的概念。

它没有故乡，也没有族群。诞生它的古老恒星早已坍缩，与之共鸣的黑暗奇点也不再位于任何现世星图。别人沿星路往返，靠的是起点与归处；斯菲尔穿行宇宙，只区分继续靠近还是主动远离。

因此，它能进入一条没有出发、只有返程的航路。

我不能。

凡人的身体需要前后，需要知道一只脚落地以后另一只脚从哪里抬起。徐的投射矩阵可以把我送到斯菲尔身旁，却无法保证我仍按相同顺序经历时间。

折枝把关闭契印交给我。

“如果看见自己已经回来，不要跟。”

“为什么？”

“因为你会以为她知道路。”

这正是前一章先遣队犯过的错误。

我们总相信走过结果的人比尚未选择的人更了解方向。

矩阵启动。

斯菲尔先吞没周围光线，再释放一圈暗潮。正常星路由亮点连接坐标，这条逆航路却由缺失构成。哪里有一项行动本应发生却被取消，哪里便出现可供前进的黑点。

先遣队没有出发。

第一处黑点形成。

希尔芙拆下指挥旗。

第二处。

崧科拒绝给出单一概率。

第三处。

百叶没有封海，阳亨没有命令火熄灭，周没有燃尽自己。

每一次没有沿最容易理解的答案继续，未然结果背面便多出一个孔。

斯菲尔沿这些“未发生”逆向飞行。

我被徐的矩阵固定在它身后，看见许多已经完成的未来从两侧退过。灰港大火倒回预案，军粮重新变成麦穗，白庭从废墟升上天空，第二脉矿工回到尚未出现的地层。

这些画面不是历史。

我提醒自己。

看见一件事如何发生，不等于它已经发生。

航路尽头没有缄城。

只有一片星尘。

星尘中站着另一个斯菲尔。

它比现世的斯菲尔庞大许多，身体只剩黑暗。那条未然里，它在身份碎片沿旧宇宙路径扩散后，选择吞噬所有不稳定光能。星路因此恢复安静，无数世界也失去相互照见的可能。

黑暗斯菲尔向我们发出节律：

“归一，才能停止分裂。”

现世斯菲尔回应：

“停止，不等于平衡。”

两只宙灵兽同时靠近。

我担心它们会像两位栖岚一样交换记忆，甚至合并。斯菲尔却主动熄灭光能，让对方找不到可以吞噬的差异；随后又释放一小段暗潮，表明自己也不把黑暗视作敌人。

它拒绝成为对方。

也不靠否定对方证明自己。

黑暗斯菲尔让开航路。

后方出现未然结果真正的来源：

不是未来世界。

是一片由现世行动投下的阴影。

白庭每搬走一座高塔，阴影便长出坠落废墟。

工会每疏散一条井道，阴影便长出另一处塌方。

军政每绘制一条预案，阴影便学会一种战争。

商联每借来一袋未来粮，阴影便生成一块空田。

未然不是在前方等待我们的固定明日。

它从每个当下选择背后生长，把没有被承担的代价拼成能够返回的结果。

“苇生在哪里？”我问。

星尘中出现一声敲击。

三短，一长。

苇生不是从某条完整未来诞生的人。她由第二脉第三层未确认的求救、北坡村民的地声记忆与先遣队预案里需要的向导共同形成。未然行动开始以后，这些碎片获得连续，成为队伍第八人。

行动被取消，她却没有随结果一起消失。

她正在阴影最深处敲击。

我想靠近。

折枝的契印在手中发热。

若将苇生直接带回，所有由预案生成的人与事都可能沿同一条路取得现世入口。若切断，她又会成为被取消行动留在代价背面的人。

斯菲尔发出一段接近的节律。

不是打开整条航路。

只允许一次回应。

我对黑暗说：“苇生，你愿意我们继续找吗？”

敲击停了一瞬。

随后是一声。

允许一次。

霍克保留的声音沿矩阵传来。那是返回者记录中，苇生最后一句“别追敌人，看粮”。两段回应在星尘里相遇，形成一条极细的连续。

我们没有把她拉回来。

只让她知道，行动取消以后仍有人记得曾与她同行。

苇生又敲三短一长。

这次声音来自更远处。

她身边还有许多人。

他们都是各种预案、迁移与预测中短暂获得身份，结果改变后又被留在背面的存在。

所谓未明军团，至少一部分由他们组成。

不是因为天生敌对。

是因为只有成为预案里的敌人，他们才持续被现实记得。

黑暗斯菲尔开始关闭。

现世斯菲尔将一枚光暗各半的星核留在航路边，作为下一次接近坐标。它没有承诺必定回来，也没有让自己成为永久通道。

徐启动返程矩阵。

这次，我们先经历落地，才经历出发。

我回到军营时，手里多出一页从未拿过的纸。上面列着未明军团第一批姓名，包括苇生。

名单末尾写着一座城：

缄城。

城门状态：

尚未宣战。

正在备战。

同一天，阳亨收到一项请求。

一辆载有四十名北境儿童的撤离车将在山道坠毁。

人们要他用一句话，让所有人活着回来。
