# 第075章 未然大陆沉降

最先坠落的是影子。

未然大陆向当前世界沉降时，所有事物的影子都比本体早到一步。新港的街道上突然铺满陌生森林的枝桠，四方营地的帐篷里出现潮骨城倾斜的屋脊，火星巢穴的轮
廓则横在孪生锚塔上方。人们尚未看见大陆，便先被另一个地方的黑暗覆盖。

有人把那称为入侵。

锚塔周围的军队立即升起防护壁。箭矢与术式射向影子，没有伤到未然大陆上的生灵，却把当前世界的地面打得遍布裂孔。每一个孔都成为新的牵引点，使沉降速度
更快。

阳亨站到塔顶，高声说：“未然大陆不会落下。”

话语撑住天空一息。他随即吐出血来。《未实之言》在他腰间自行翻页，记下这次谎言转移的代价：大陆没有停止下落，只是把那一息积累成更猛烈的下一次沉降。

“别再替它说结果。”千花隔着风喊他。

阳亨擦去嘴角的血，改口道：“所有人，离开影子重叠的地方。”

这一次，话语没有命令大陆，只为正在行动的人指出眼前的危险。

我们从十三座未建之塔向各处传递选择。任何城市、森林和族群都可以决定靠近当前世界、留在未然层，或去往六道外的风暂时打开的方向。没有一张总表，也没有
一个最后时限，因为不同区域的时间早已不再一致。

混乱因此没有减少。

潮骨城留在维尔萨背上的半城选择上浮，另一半则愿意随未然大陆下沉。两部分在同一座桥上争夺承重索。维尔萨没有再次从中劈开城市，而是潜入桥底，用背脊暂
时托住两岸。居民必须亲手拆下共同铺设的桥板，一块归上浮者，一块归下沉者。最后一块桥板被取走时，两个相识多年的老人隔着海水互相咒骂，谁也没有说祝福
。

他们仍然松开了手。

红森林的根系已跨越三种地层。祖克无法同时留住全部树木，便把自己的空年轮打开，让愿意等待的根暂时穿过那段没有年份的木质。每容纳一株树，他便忘记一个
真实度过的春天。尼尼亚发现后，立刻斩断仍在向空年轮涌入的细根。

“我还能承受。”祖克说。

“森林不是因为你能承受，就可以把代价都长进你身体里。”

她让年轻树木自行结成浮动林筏，玛尔沙则把菌丝分割成许多局部网络。失去整体共享后，菌群不能再立刻知道每一片林地的损伤，却也不必让一棵树精承担全部季
节。拉朵带着那座缩小的遗迹登上其中一片林筏。她把自己从遗迹妖灵改称为遗迹的第一位居民。

塞立和帕加赶到孪生锚塔时，塔身已经陷入两重地面。

四方势力的工匠围在那里，没有人愿意率先拆除自己负责的部分。他们担心一旦别人的构件仍在，未然大陆最终便会落入对方控制。锚塔因此继续运转，不是因为众
人不知道危险，而是每一方都害怕自己先放手。

帕加举起锻锤，砸断了由他亲自设计的主轴。

“这部分最好。”他说，“所以先拆它。”

主轴崩裂，塔身向北倾斜。塞立将双手按入地面，没有托住整座塔，只让下方避难者脚边的土地维持到最后一人撤出。随后，希尔芙解除自动防卫机群的阵营识别，
让机械只执行搬运，不再守护任何一方的构件。拉吉斯公布锚塔的全部出资与债权，当场烧毁那些声称可以在沉降后获得土地的契约。

仍有人拒绝拆塔。

他们不是全然贪婪。有人已经在未然大陆找到另一个死去的孩子，有人看见一座没有饥荒的故乡，也有人相信只要塔继续运行，自己便能从所有可能中挑选一个较好
的明日。军队挡在最后三根副轴前，声称拆塔等于杀死那些尚未来得及靠岸的人。

砾芜从人群中走出，露出灰港大火留下的伤疤。

“别再拿我们当证明。”她说，“你们当初说点火是为了救未来的人，现在又说不拆塔是为了救未来的人。被你们放在理由里的，永远没有机会说够了。”

雾禾敲响从沉钟港带来的小钟。

钟声没有召来母亲，也没有替任何城市固定位置。每响一次，未然大陆便传回一个正在选择的声音。有人说“拉我过去”，有人说“不要碰我”，更多声音只说“再
等一会儿”。彼此矛盾的请求充满塔下，终于使“所有未然者都希望被锚定”的口号无法继续维持。

守军中第一个放下武器的人叫舟麦。她曾被孟离射伤，也曾在预言里被写成战争的第一名死者。她走到副轴前，用尚未完全恢复的手臂拆下一枚固定栓。

更多人随后加入。

塔倒下时，未然大陆已经压到当前世界上方。山脉与城市的实体从影子里显露，彼此相撞前只剩一段呼吸的距离。阿尔法计算出三千四百余种分离方案，却没有替我
们选出“损失最小”的一种。他只不断报告哪里即将接触，让当地的人自己回答愿意承受什么。

贝塔则关闭了试图自动修正结果的循环装置。

“这次不优化世界。”她说，“只把每个回答送到它该去的地方。”

斯菲尔失去了星路，无法辨认方向，便跟随地面上不同的灯火飞行。维尔萨以潮声分开正在接近的水域，司度的小田成为测量当前土地的基点。马力克通过孢子网络
传来一次猛烈的化学信号，红森林据此收拢通往火星的枝脉，避免两个生态在沉降中被强行重叠。穆拉姆仍包裹在透明茧膜内，却让现有巢群搬运那些彼此独立的惰
性卵匣，不允许任何一枚借灾难提前孵化。

百叶最后展开六道。

这一次，他没有用它们包围大陆。六道只落在明确选择进入当前世界的事物下方，成为临时的桥。千花则守在桥边，使每一个说出选择的人不被集体梦境淹没。六道
外的风从其余裂隙间通过，把不愿靠近的区域送往我们无法记录的方向。

未然大陆没有作为一块完整土地降临。

它分成了数百片彼此不再从属的地域。红森林的一部分落在新港外海，潮骨半城停在没有星光的高空，未建之塔散入不同重力，穆拉姆的卵匣则留在一段无人占有的
缓慢时间里。更多地方沉到现实之下，成为只有在特定关系、梦境或潮汐中才能抵达的层面。

还有一些区域随风而去。

我们不知道那里是否安全，也不知道离开者会不会后悔。没有结局替这个选择证明正确。

沉降结束时，孪生锚塔只剩半截地基。四方势力的旗帜都压在废墟下面，露出的颜色几乎无法区分。人们站在新出现的海岸上，望着那些终于进入当前世界的土地。

很快，第一个问题便被提出：

“这些地方归谁？”

紧接着是第二个：

“那些没有降临的资源，谁有权继续寻找？”

第三个问题来自一名抱着孩子的普通居民。她的丈夫去了未然大陆，在沉降时选择留在另一层。她没有要求军队替她夺回丈夫，只问以后是否还能获准去看他。

没有人回答她。

四方使者已经开始清点土地、道路、矿脉和能够通往未然层的入口。刚刚共同拆塔的手，又各自按上武器。未然大陆免于被选成唯一版本，却把许多真实的碎片留在
了我们之间。谁控制这些碎片，谁便可能比别人更接近想要的明日。

我在第075章末尾写下：“大陆沉降结束。”

墨迹未干，雾禾便摇了摇头。

“不是结束。”她说，“只是它终于重到能被人争夺了。”

远处，第一面界碑被钉进尚带着红色孢子的泥土。
