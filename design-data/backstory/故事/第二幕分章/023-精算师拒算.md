# 第二十三章 精算师拒算

崧科说“不算”以后，所有人先怀疑他已经算完。

商联认为结果不利于粮食流通。

军政认为某项风险高到不能公开。

天界怀疑第五条星轨干扰了判断。

地核工会则要求至少给出第二脉与谷物接触后的坍塌概率。

他们太熟悉崧科。

他能从肌肉轻微收缩算出敌人下一步，从风速、角度与地形中找出一支箭唯一应当抵达的位置。战场在他眼中很少混乱，只是变量尚未排列。

“不是不能算。”他说，“是不提供一个数。”

“没有数怎么决定？”

“谁告诉你们，有数就等于决定已经做完？”

崧科把半袋未来谷物分成七份。

他没有使用。

只在每一份旁边放上相应后果：北方农户的空麦穗、白庭下沉记录、灰港军粮订单、南湾粮价、第二脉地图、沉钟港潮标，以及迟风原那个孩子抓过的麦根。

“播种成功率多少？”拉吉斯问。

“看种在哪里。”

“北方平原。”

“看未然潮是否继续。”

“按继续算。”

“看白庭是否用它稳定城基。”

“不使用。”

“那白庭坠落以后，迁移人口会改变北方消耗。”

问题不断生出条件。

每个条件又会因公布的数字改变。

若崧科说战争概率六成，军政会增加防线，对岸也会备战；商联会储备军粮，粮价上升；天界可能加快迁移，北坡人口继续增加。六成不是写在世界外面的事实，它会成为行动理由。

“你以前也计算战场。”希尔芙说。

“箭射出以后，敌人会躲。”崧科回答，“所以我一直计算他的反应。现在你们要求我公布一个所有人都会根据它行动，却假装数字本身不会变化的结果。”

“总不能什么都不做。”

“我没有说不做。”

他带我们去北坡。

工人村的裂缝已经穿过三条街。居民需要决定继续加固还是整体迁离。崧科没有给出坍塌百分比，而在地面钉下不同颜色的箭。

白箭表示现有事实：裂缝宽度、房屋重量、地下空洞。

黄箭表示一旦采取行动便会改变的条件：撤离人数、重架位置、第二脉救援。

红箭表示无法确认来源的未然信息。

居民可以看见所有箭，也能要求他解释计算。

一名母亲指着自己家门口。

“你就告诉我，今晚会不会塌。”

崧科看着她怀里的孩子。

“如果不下雨，不再有重车经过，第二脉不继续上移，今晚大概率不塌。”

“多大？”

“我不说。”

“你怕说错？”

“怕你把孩子留在里面，只因为我说了一个听起来安全的数。”

“那我搬不搬？”

“你能搬去哪里？”

“北营。”

“那里离白庭坠落区更近。”

母亲骂了他。

崧科没有反驳。

最后，她把孩子送去亲戚家，自己留下搬家具。她没有把一个概率替代成全部选择，也没有因不确定便什么都不做。

村民陆续作出不同决定。

有人连夜搬离，有人只转移老人，有人加固房屋后继续住。崧科的箭没有给出统一答案，却使每个人知道自己正在承担哪些条件。

当晚，村庄没有塌。

第二天也没有。

第三天，一处此前标为白色事实的旧井壁突然破裂，压坏两间空屋。

有人说崧科证明了自己的谨慎。

他把这句话划掉。

“房子没住人，是居民搬走的结果，不是我拒绝给数字的功劳。”

四方仍需要公开预测。

崧科不肯提供单一比例，另一套简化算法便迅速流行。它把四份明日各自的危险相加，得出：

北境战争发生概率，八十三。

没有人知道八十三之后是否应有一个百分号。

数字仍被写满城墙。

军政采购以八十三为理由增加军粮。

商联以八十三调整保险。

北境聚落以八十三招募守卫。

白庭居民则认为战争会使低地更危险，开始停止迁移。

一个来源粗糙的数字，因为足够明确，比崧科所有条件箭传播得更快。

拉吉斯问他是否后悔。

“如果你给一个更可靠的数，至少不会是八十三。”

崧科抬头看向高墙。

“我若给七十一，他们会争论的是哪个数更像真理，不是这些数怎样改变了他们。”

“那就任由它传播？”

“不。”

崧科跃上墙头。

他没有涂掉八十三，而在每一个数字后面加了一句话：

“包括你看见它以后的行动。”

句子太长，传播得很慢。

有些墙面只抄了前半句。

数字继续扩散。

到第七日，北境双方都完成第一轮动员。没有人宣战，也没有军队越界。可越来越多武器、粮食与人口已经沿未然行军图移动。

希尔芙拆除的指挥旗被锁在军工场。

午夜，所有金属旗杆同时发热。

灰港预案第七页自行翻开。

“可接受牺牲区”一栏，出现了迟风原、北坡与新港三个名字。

随后，纸页燃烧起来。
