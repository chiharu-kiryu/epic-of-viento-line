# 第084章 没有后方

军旗覆盖新港后的第二天，厨房也成了前线。

观测塔把粮食、炉火、药品和睡眠都纳入战争。谁多烤一块面包，便可能被解释成储备军粮；谁熄灯早睡，又可能被视作隐藏行动。居民为了证明自己没有支援敌方
，只能公开每一顿饭、每一次出门和每一封家信。

越是公开，塔便得到越多能够用于推演战争的细节。

面包房店主名叫槐姐。她不识字，却能凭手感把每日剩余的面粉分到次晨。塔影覆盖烤炉后，面团开始显出食用者未来的身份。给孩子的那一块浮现军医徽记，给老
人留下的面包则写着“后方动员者”。槐姐一气之下把所有面团揉成一大团，谁来便撕一块。

观测塔随即将整间面包房标成军需中心。

当夜，一队披着未来军旗的身影前来夺粮。他们尚未完全拥有身体，脚步经过石板时没有声音。槐姐拿着擀面杖守在门口，周站在屋顶，却迟迟没有点亮太阳。

“你不照，他们看不见路。”有人催促。

“塔也会看见。”

周过去把光视为天然的公正。灰港之后，他已经知道照亮并不等于拯救。如今观测塔正借他的日光区分目标，越明亮的地方，越容易被纳入战场。

他从炉膛里取出一小块炭，捏碎后抹在自己的金色甲胄上。随后，他用最微弱的光照亮门槛，只够每个走近的人看见自己的手。

第一名未来士兵踏入光中，手里没有武器，只有一只空碗。

第二个人握着刀。槐姐没有立刻把他归作敌人，只问：“拿刀做什么？”

“奉命征粮。”

“给谁吃？”

那人答不上来。他来自一支不断回到战争起点的军队，记得征收、运输和配给，却从未真正见过吃下粮食的人。

槐姐把一块生面塞进他碗里。

“坐那边等熟。”

他下意识服从，坐到墙根。更多未来士兵来到门前，有人愿意放下武器换一顿饭，有人坚持带走全部粮食。周只照亮他们伸出的手，不照旗帜和盔甲。手掌上的茧、
伤口与颤抖无法直接证明善恶，却足以让“军队”重新分成不同的人。

冲突仍然发生。

一名士兵抢夺烤盘，槐姐用擀面杖打断他的手腕；另一人从后窗投进燃烧瓶，火焰烧毁半袋面粉。没有人因被具体看见便自动变善。不同之处只在于，他们的行为不
再由军旗替其完成。

城中其他地方也开始采用微光。

医者遮住诊所窗户，只在病床边点一盏灯；居民拆散大钟，用小铜片逐户敲响警报；徐和霍克不再绘制整座城市的防线，只口头告诉每条街眼前能看见的危险。观测
塔失去全景，新港也失去统一调度。救援变慢，几处本可及时扑灭的火蔓延到屋顶。

“没有全局不等于没有代价。”西尔西斯说。

他曾因拆除全域监视而留下盲区，如今主动进入其中一处。他不重新架起看遍城市的眼睛，只站上最高水塔，用旗语传递自己亲眼确认的消息。每一次转身，背后的
街区便从他视野中消失。他必须相信那里的人会自行行动。

观测塔抓住了这些盲区。

未来军旗从地下水道、废弃仓库与无人屋舍中涌出。它们不再试图占领城墙，而是切断居民彼此验证消息的路线。很快，东街听说西街已经投降，西街则收到东街屠
杀未来降兵的消息。两边都开始封门。

凛麦带着七十一名同伴走入街道。

他们最熟悉未来军队制造的假消息，也最不被当前居民信任。凛麦没有要求任何人相信她，只把自己未来军服的袖章钉在每一个确认安全的路口。袖章不是保证，只
表示她本人走过那里，并愿意为错误回来承担。

第七个路口，她遭到箭击。

箭来自一户害怕未来士兵入侵的居民。凛麦没有还击，拔箭后仍继续前进。第十二个路口，一名同伴受不了辱骂，重新举枪威胁居民。凛麦亲手卸下他的枪，让他退
出队伍。

他们不是一支天然正确的新军。只是一些正在学习不让旧命令替自己行动的人。

傍晚，白线抵达城中所有水井。塔影宣布，向任意一口井投毒便能摧毁敌方后方。四方同时派兵护井，也同时怀疑另外三方会先下手。皮克多尔检查水源后发现，井
里确实有蝎毒。

毒属于他。

不是未来样本，也不是旧日残留。毒液刚从他尾针取出不久，气味新鲜。他查看自己的装备，发现随身毒囊仍然完整。

“塔里有另一个我？”他问。

阿尔法摇头。

观测塔没有复制皮克多尔，只把“他可能投毒”的结果提前放进井中。若任何一口井因此死人，现实便会倒过来要求一个投毒者存在。皮克多尔将成为最合适的人选
。

“那我更该进塔看看。”他说。

他当着众人的面封住尾针，把毒囊交给槐姐保管，随后在井边钻入地下。

观测塔能够看见所有可能抵达它的道路。

皮克多尔选择不把塔当作目的地。他只沿着井水流动的方向前进，去寻找那一滴尚未决定由谁投下的毒。
