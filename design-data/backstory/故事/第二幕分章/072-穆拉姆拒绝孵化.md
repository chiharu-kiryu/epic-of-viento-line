# 第072章 穆拉姆拒绝孵化

穆拉姆曾告诉我，虫母并不会逐一辨认自己的卵。

她辨认温度、气味、壳膜的振动，辨认巢穴是否安全，辨认幼体第一次撞击外壳的力度。名字要等出生之后才有，亲缘却在名字之前便已形成。那不是一种需要思考的爱，而是身体先于意志作出的回答。

第七颗星利用的正是这个回答。

卵影出现后的第三个时辰，穆拉姆腹部的旧产痕重新裂开。没有血流出来，伤口里只有暗淡星光。每一次呼吸，她体内便多出一枚从未孕育过的卵；每一次心跳，卵壳便完整一分。它们来自不同道路，有些孕育着会覆盖大陆的巨虫，有些是从不争斗、也没有独立意志的温顺族群，还有些连躯体都没有，只是一群借母体共享思想的声音。

最先赶到的医者建议她离开未然大陆。阿尔法计算后却告诉我们，无论她去往何处，那些卵都会将那里变成孵化场。锚塔已经把她识别为“所有未选古神生命的共同母体”。只要这个定义仍然成立，距离便没有意义。

“可以切断吗？”我问。

阿尔法的目光掠过不断变化的数列。

“可以切断她。”

他说完便主动关闭了那组推演。

没有人再提这个方案。

穆拉姆蜷伏在一座废弃蜂巢里。科尔托让蜂群搬空巢室，又用蜂蜡封住入口，只留一道供空气流动的窄缝。暗星仍透过蜡层照在她身上。巢外很快聚满了声音。

“母亲，让我出生。”

“母亲，我会成为你最强壮的孩子。”

“母亲，你曾在另一个世界答应过我。”

“母亲，只要孵化我们，你现有的族群就再也不会灭绝。”

最后一句令她的足肢猛然收紧。穆拉姆的族群曾数次濒临断绝，她比任何人都知道，一个母体会为延续后代付出什么。那条未选道路没有欺骗她。若所有卵都能出生，她的种群确实可能再也不必畏惧灭亡。只是“她的种群”将被扩展到吞没所有其他生命，“母亲”也会从关系变成一种没有边界的职能。

我隔着蜂蜡问她，需要我们做什么。

“别替我回答。”她说。

这是她封巢后的第一句话。

黄昏时，一只尚未完成蜕壳的幼虫爬到入口。它就是在缄城之战前梦见未来、后来选择延迟孵化的那只幼体。它还没有正式的名字，巢群依靠气味唤它。它将腹足贴在蜂蜡上，发出断断续续的振动。

“慢。”

这是它学会的第一个通用语音。

巢内的卵影顿时骚动。许多声音斥责它懦弱，另一些则模仿它，用更柔软的腔调请求穆拉姆把“慢”也交给它们。幼虫没有解释，只是又撞了一次蜂蜡。

“我的慢。”

穆拉姆在里面笑了。笑声低沉，像岩层轻微移动。

她终于开始回答那些卵。

“你说你是我的孩子。你记得我为你筑过巢，可那不是我的手。”

“你说你能救我的族群。可你要求它们先失去拒绝你的能力。”

“你说你没有别的母亲。这能证明你的孤独，不能证明我的身体属于你。”

每说一句，她腹中的星光便暗下一分，却没有任何卵因此消失。拒绝不能把它们从可能中抹去，只能阻止它们把她的本能当作入口。

到了夜半，蜂巢突然裂开。穆拉姆撑破蜡层爬出，腹部已膨大到无法站立。千万枚卵的轮廓沿着甲壳来回游动，寻找可以破出的薄弱处。

第七颗星降到山顶。暗光中显出另一个穆拉姆。

她比现在的虫母庞大数百倍，腹下连接着整片大陆。森林是她的绒毛，河流是她的血管，城镇则像附着在甲壳上的卵囊。每一条街道都在孵化，每一座房屋里的人都用同一个声音呼吸。

“你拒绝的不是侵占。”巨大的虫母说，“是生命。”

穆拉姆艰难地抬起前足，将尖端抵住自己裂开的产痕。

我们以为她要杀死所有卵。那只幼虫却忽然挡在她足尖前，再次发出“慢”的振动。

穆拉姆停住了。

她没有刺下去，而是分泌出一层透明的硬质茧膜，将自己的腹部完全包裹。茧膜不会摧毁卵，也不能帮助它们成熟，只会隔绝暗星施加的共同孵化节律。代价是她自己的产育能力也会一并休眠，或许一年，或许百年，谁也不能保证它何时恢复。

“我没有拒绝生命。”她对星下的自己说，“我拒绝替所有可能作出出生的决定。”

巨虫母伸出覆盖山谷的足肢，试图撕开茧膜。科尔托的蜂群率先撞向那道影子。随后，来自红森林的孢子附上暗光，祖克让根系围住蜂巢，尼尼亚则带走不能承受虫鸣的伤员。没有人替穆拉姆说“同意”或“拒绝”，他们只是守住她已经说出口的边界。

天亮前，暗星终于升高。

穆拉姆腹部的卵影仍然存在，但彼此分离了。它们不再共享一个母亲，也不再同时发出哭声。阿尔法制作了许多不与任何身体相连的惰性卵匣，将能够离体的影子分别安置进去。它们或许会在别处找到愿意承接的关系，或许永远停留于未然。穆拉姆不再负责保证它们的结局。

那只学会说“慢”的幼虫爬到她肩上。

“母亲？”它试着问。

穆拉姆用触须触碰它的额部。

“这个可以。”她说，“因为你也可以有一天不这样叫我。”

第七颗星没有消失，却第一次被云遮住。云层之后，斯菲尔发出一声长鸣。

他告诉我们，七颗星并非七个源头。它们只是同一条星路的七个出口。只要那条道路仍在照耀未然大陆，古神未选的形态便会不断寻找身体。

而那条路的另一端，连接着斯菲尔自己。
