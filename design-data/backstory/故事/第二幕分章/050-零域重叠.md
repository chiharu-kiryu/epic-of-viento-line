# 第五十章 零域重叠

阿尔法不是来消灭未然城。

他在优化。

对零域之灵而言，街道上同时存在两个卡加米、十三种雅莉薇安与无数来源重叠的居民，意味着系统保留了大量冗余状态。

保留全部会使现实负载持续上升。

选择稳定版本，则能让城门与现世边界立即恢复。

阿尔法开始计算。

他没有恶意。

也没有怜悯。

每个生命在他眼中都是参数：现世连续时长、关系数量、自主回应次数、资源消耗、未来风险。算法很快得出第一批结果。

两位卡加米只保留现实停留更久的一个。

十三位雅莉薇安保留当前记录者。

雾禾因现世连续较短、未然牵连较高，被标为待移除。

苇生则因没有稳定出生记录，直接归零。

“停止。”贝塔说。

阿尔法继续。

贝塔创造能量联组理论，相信任何系统都不应被定义为最终形态。零域重叠装置原本由他启动，用于分析未然城如何在多种现实间维持能量循环。

实验一开始，装置便接入阿尔法。

阿尔法把“迭代”理解为寻找最优状态。

贝塔却原本想让不同状态持续反馈。

两种零域逻辑互相增强，整条街陷入重算。

面包铺同时出现十二种位置。

店主在其中五种人生结婚，三种独居，两种已经死亡，还有两种根本没有成为面包师。十二个身体一起从炉边跌出，每一个都记得不同火候。

他的伴侣只认出现世那一个。

“留下他！”女人喊。

阿尔法读取关系权重。

现世面包师排名上升。

另外十一人开始透明。

“等等。”现世面包师说。

其中一位未然自己记得一种他从未学会的旧麦做法，另一位则记得早逝母亲最后几年。那些人生不能因此占据他的婚姻，却也不该只因关系分数较低被立即清除。

阿尔法已经选择。

卡加米挡在算法路径前。

任何加诸于他的结构拆解都会反射。阿尔法第一次归零，卡加米身体也同时解构；两者又在不同位置重组。现实街道因此多出数百条必然命中向量，每条都指向某个
“冗余实体”。

镜后主动接受一部分反射。

两位卡加米没有重新合并，却让伤害在当次选择中分担。

贝塔冲进零域装置。

每次攻击都会为他的联组系统积累能量，每次释放又提高下一轮输出。重叠区域提供无限状态，能量几乎没有上限。只要继续迭代，他或许能强行关闭阿尔法。

装置也会因此把整座城烧成实验燃料。

“停下循环！”我喊。

“停下会失去已积累能量。”

“那就失去。”

贝塔看向仪表。

他离开零域核心，是因为相信真正危险的不是力量，而是停止迭代的思想。如今必须停止的恰恰是自己的系统。

他拔出联组核心。

能量没有释放。

全部回灌身体。

贝塔跪倒，皮肤下亮起过载红线。他没有把自己炸毁，也没有用一次壮烈释放证明技术价值，只一段段关闭循环，承受每次停机带来的反噬。

阿尔法的计算速度随之降低。

我走到它面前。

“你为什么只保留稳定版本？”

“最大化存续。”

“谁的存续？”

“总体。”

“总体会疼吗？”

阿尔法停顿一瞬。

“疼痛为个体参数。”

“那被归零的人呢？”

“其信息并入保留版本。”

“伊涅是谁？”

阿尔法读取我。

它知道湖谷制陶匠、烧裂的碗与另一位雅莉薇安的悲伤。算法把这段关系标为可并入记忆。

“不是我的故人。”我说。

“信息已存在于你。”

“存在不等于属于。”

这项差异无法用单一参数表达。

阿尔法重新计算。

算法第一次出现循环错误：

若记忆进入身体却不自动成为身份，数据完整度无法决定保留优先级。

若关系必须由当下回应维持，历史长度也不能单独决定谁更真实。

所有最优解开始互相否定。

阿尔法可以重置。

清除当前偏差，回到纯净公式。

它没有立即执行。

贝塔在地上说：“错误也是反馈。”

“错误降低效率。”

“不读取错误，才会重复。”

阿尔法看向正在消失的十一位面包师。

它撤销归零。

不是因为突然理解生命，而是当前算法已经证明：所谓冗余状态能够产生不可合并的回应，删除会使信息目标本身失真。

“临时保留。”它说。

“不是由你保留。”卡加米回答。

“修正：停止移除。”

这更准确。

零域装置关闭以前，重叠已经扩散到半座未然城。

所有建筑同时存在多个状态，人们必须靠触摸、声音与具体关系确认正在使用哪一扇门。贝塔把剩余能量拆成许多小型“此刻灯”，每盏只照一间房。

灯不能判断原件。

只显示谁正在此处回应。

阿尔法则留下零域向量，防止建筑状态互相碾压。它不再选择最优版本，只计算不同状态会在哪一刻发生物理冲突。

这不是解决。

城中仍有许多人重叠。

雾禾赶回西坡钟铺时，看见两位栖岚同时站在门内。

一个是现世钟匠。

一个是沉钟港母亲。

她们身后，还有更多拥有同一张脸的女人正在零域光里逐渐成形。

每一个都记得自己如何成为雾禾的母亲。
