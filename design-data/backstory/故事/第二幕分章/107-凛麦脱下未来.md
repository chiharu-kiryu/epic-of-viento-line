# 第107章 凛麦脱下未来

凛麦的军服先于身体消失。

袖口、领章和沾过观测塔灰尘的下摆逐日变淡，只剩夺塔时中箭留下的伤口仍清晰。到了第五天，她站在阳光下，身上仿佛只披着一层透明的旧记忆。

槐姐给她一件粗布短衣。

“先穿，别冻死。”

凛麦没有立刻接。她担心脱下未来军服以后，自己会忘记那支军队。七十二名放下武器的人中，已经有人叫不出旧战友姓名，也有人醒来后坚称自己本来就是新港居
民。未然潮不仅带走道路，也带走只能由那条未来支持的记忆。

“忘了战争不是好事吗？”有人问。

凛麦回答：“如果只剩我后来放下枪的样子，我也会变成一个很好用的英雄。”

她最终穿上短衣，把透明军服叠好，放到未来降兵共同居住的仓房中央。七十二人依次写下仍能记得的名字，不按军衔，也不只记录死者。有人写炊事员，有人写曾
经欺负自己的同伴，还有人写一名自己亲手处决的逃兵。

伏岚没有写。

他就是曾在面包房重新举枪、未进入优先留存名单的人。军服消失后，他的身体也开始透明。当前世界只记得他的一次威胁，未来战争却保存了他二十余年生活。若
留下，他可能只剩一个犯过错又被凛麦解除武装的人。

“我想回去。”他说。

凛麦提醒他，原来的未来正在退潮。那支军队未必仍然存在，返回也可能只是与十三座塔一起进入一个完整却静止的版本。

“至少那里有人知道我小时候怕水。”

“我可以记。”

“你是到后来才知道。”

凛麦没有再劝。

七十二人中，二十一人决定寻找返回未来军营的道路。他们不是忠于战争，也不是拒绝当前世界。有些人的孩子、爱人与完整生活都在那里。当前关系不能因为发生
得较晚，便自动胜过来处。

三十七人选择尝试留下。

其余人无法决定。

落潮名单要求每个人在塔影覆盖前作答。凛麦撕掉仓房门口的期限，告诉大家不确定本身也是当前状态。她无法保证塔会等待，却不肯把恐惧伪装成自愿选择。

十三座塔中的第六座在此时降下阶梯。

阶梯通往未来军营。旗帜已经放下，营中没有战斗，所有失去的战友都停留在凛麦记忆最完整的年纪。有人站在营门喊她名字，连语气都没有错。

伏岚第一个踏上阶梯。

凛麦问他，这是不是他想回去的地方。

“不知道。”他说，“但我要靠近看。”

他走到第十级时回头，身体已有一半恢复成未来军服的形状。凛麦没有追赶，只把一件粗布短衣扔给他。伏岚接住，笑说那里未必用得上，仍把衣服系在腰间。

另外二十人陆续登塔。

第七个人抵达营门后突然逃回。他说里面的妻子只记得他出征前的模样，不知道他曾放下武器，更不知道面包房那次威胁。塔提供的是完整未来，却要剪掉他进入当
前世界后的选择。

“那不是回家。”他说，“是让我回到还没成为现在这个人的位置。”

伏岚听见后仍然前行。

“我先去问他们愿不愿意认识后来的我。”

他跨进营门，没有立刻消失。粗布衣的一角留在阶梯外，随着风轻轻摆动。凛麦把那一刻记下，没有写他选择了正确或错误的归处。

塔开始收回阶梯。

仍在犹豫的人慌乱奔跑，有人临时冲向未来，有人抓住仓门不放。凛麦站在两边之间，既没有召回，也没有推送。

她自己的身体忽然向阶梯移动。

落潮名单把她列为高价值留存者，十三座塔却认定她是未来军队最重要的叛离节点。只要把她带回，军旗便可能恢复完整。当前世界与未来同时拉扯，凛麦胸前的箭
伤重新裂开。

蕾贝尔没有用血印命令她留下。

她将自己的披风铺在当前地面，说：“这里有你做过的事。不是命令。”

槐姐也举起那块被烧穿的面包铲。廉戍拿来夺塔记录，受她救出的伤者则带来一小片未来军服。他们没有证明凛麦比别人更有价值，只把与她共同承担的当前后果放
在地上。

凛麦自己伸手，抓住粗布短衣的衣领。

阶梯从她脚下退去。

未来军服完全消失。她同时忘记三名旧战友的脸，只保留名字和一段无法再复原的悲伤。

“我留下不是因为他们批准。”她在落潮名单上写，“也不是因为我救过谁。”

她看向伏岚消失的塔门。

“我只是在今天，选择继续承担这里已经与我有关的事。”
