# 第104章 我不替他们作结

我重新被看见时，众人正望向不同方向。

千花看着梦，雾禾看着钟，砾芜闭着眼，百叶的手仍按在黑色地基上。没有任何一双目光单独把我拉回，也没有所有人共同期待的雅莉薇安等在原位。

所以我只有一个身体。

镜屑仍在血里。有人转头看我，我的肩膀便短暂变成他记忆中的形状；第二个人也看过来时，两个形状互相拉扯。我请他们不要同时围上来。

这句话伤到了一些人。

他们为找我走过紫路，承担风险，也在没有中心记录的日子里学习自行书写。如今我回来，第一件事却像是在拒绝他们。我不能用镜屑解释掉这种伤害，只能说明身
体正在发生什么，并让每个人决定是否暂时退后。

千花最后一个转身。

她没有抱我，先问：“现在可以看你吗？”

“可以。”

她看了一会儿，说我瘦了。我告诉她在无主后果里没有统一的用餐时间。她笑了一下，眼泪随后才落下来。

我没有立刻取回笔记。

雾禾先讲东仓的楼梯。她失去了母亲呼唤名字的声音，荻秋则带回两段不同长度的生活。我不知道该把获救人数写成十、十一，还是“十人、十一种连续记忆”。过
去的我会选择一种尽可能准确的表述。

这次我在她的记录后只署名：“我听过。”

砾芜递来被撕毁的英雄公告。她写下自己僵住的三十息，也保留凛麦救人、追错与撞倒粮架的复杂结果。我想修改一个容易被误解的句子，手伸到纸边又停下。

“你可以提。”砾芜说，“不能直接改。”

我指出那一处。她听完，决定保留原文，并在旁边注明我的担忧。两个版本都没有取得最后一句的权力。

廉戍把开炮后的第三十一息交给我。

我曾以为自己的记录使炮击进入共享现实，后来才知道，持续汇总也让人们把看见后果的责任寄存在我这里。廉戍必须亲自打开塔门，四十三个人也必须自己走到炮
响之后。记录能使逃避更困难，不能替行动者完成面对。

泽尔克谈到被取消的空袭时，我第一次感到镜屑发热。

许多人正在远处等待我裁定四方责任。只要我写下谁是主要行动者，空袭便会获得清晰政治方向，弹坑中的受害者也可能更容易获得赔偿。拒绝作结同样会让具体的
人继续等待。

我没有把“不裁定”当成美德。

我把能够确认的行动链重新抄写：谁建立目标模型，谁提供坐标，谁准备弹药，谁提出异议，谁取消任务，哪些未执行部分最终拼成无主飞机。至于这些行为应承担
何种责任，我请每一个受影响者与行动者继续在当前关系中追问，而不是由记录本一次分配完毕。

这仍然不够快，也可能不够公正。

但它不再假装我的一句话能把所有后果正确归位。

那个自称“我”的孩子带来无翼纸鸟。纸鸟踩在我的手背上，纸角很硬，留下两个小红点。

“你还要叫‘我’吗？”我问孩子。

“今天要。”

“明天呢？”

“明天再说。”

我点头。梦中诞生的淡紫色光也跟着千花来到无主城边缘。她不想替我回来，还没有找到自己愿意成为什么。我们第一次见面时，她躲到千花身后。

我没有叫她另一个雅莉薇安。

她也没有叫我原本的自己。

“你会拿走那些记录吗？”她问。

“不会。”

“你会继续写吗？”

“会写我看见的。”

“别人写错呢？”

“我会指出。但我不能因为害怕错误，就让所有人只留下我的字。”

她似乎不满意这个答案。一个从众人对完美记录者的期待中出生的存在，比任何人都清楚分散叙述会有多少漏洞。她没有因此回到书架，只把自己的第一句“不想代
笔”重新读了一遍。

离开无主城时，我回头看那根屋梁。

若众人再次把事故写成自行发生，梁仍会压下。我们没有永久解决它，只建立了一些能够被追问的支点。

我在第104章末尾没有写“记录者归来”。

我写：

“今日，我重新进入他们能够看见的地方。所见仍不相同。”

这一句只属于我。
