# 第116章 潮底没有统一方向

潮声吞没回答时，我仍抓着那只手。

如果松开，它会立刻沉入完整之塔崩裂后的深渊；如果拉近，又可能把一个拒绝当前世界的生命强行带回来。过去发生的一切没有给我一条永远正确的规则。

我最终把它拉上身旁的断墙。

“这里不是当前世界。”我朝潮水里喊，“也不要求你留下。能听见以后，仍可以走。”

对方没有回应。

我不能说它同意获救，只能说在无法确认、且死亡迫近时，我先把选择延后。若它醒来后责怪我，这份责怪也应当被保留。

断墙随海啸下沉。

维尔萨从潮底冲出，用背脊托住我们。她本就驮着潮骨半城，沉降与落潮使城市只剩七条街。居民从屋顶抛下绳索，将附近能够抓住的形体拖上去。每一根绳端都系
着不同标记：愿意靠近当前世界，愿意随潮离开，暂时不确定，以及“没有收到回答”。

最后一种最多。

有人昏迷，有人没有身体语言，还有些生命的选择表现为颜色、温度或群体节律，我们根本无法理解。玛尔沙的菌网只能翻译其中一部分。阿尔法不断报告可能含义
，却不再把最高概率直接当作答案。

百叶的六道在海啸中展开，形成六处暂时落脚地。

他没有封闭边缘。六道外的风从缝隙穿过，把明确选择离去者送往别的方向。风也带走了一些未确认者。我们无法判断那是它们自己的移动，还是救援失败。

每一次失去都有人想追。

千花拦住的不是追赶，而是追赶者把自己的不舍当成对方愿望。她让梦短暂连接，若只能听见哭声，就记录哭声，不能把哭声自动翻译成“请救我”或“让我走”。

穆拉姆的惰性卵匣在潮底四散。

部分卵明确朝她移动，壳膜不断敲击母体节律；另一些逃向暗处，还有数百枚已经没有反应。她只收拢主动靠近者和即将被塔石压碎者。那只学会说“慢”的幼虫则
带着空卵匣游在外围，为尚未决定的卵挡开碎石。

“母亲，慢。”它在浪里喊。

“潮不会慢。”

“我们慢。”

穆拉姆没有让时间停止。她只是不用海啸的速度替所有卵完成孵化。

十三座塔裂出的房间彼此碰撞。纯净现实的一扇门也被卷入潮底，门后居民伸手救起当前未然者。有人进入后立即被改写成完整版本，也有人在门槛前拒绝。谷沙守
在那里，把每一种变化记录给将要跨门的人。

陈珀没有跟他去。

肩骨断裂后，他留在当前一侧搬运塔石。恢复的杀人记忆使他数次想走进纯净现实，回到没有射箭的自己。活着的谷沙没有阻止，只要求他不能把另一边的无罪带回
来覆盖这里的行为。

海啸持续七个时辰。

我们不可能救下九万余个形体。许多生命随潮远去，许多在塔基断裂时失去连续，还有一些进入我们无法观察的方向。最终统计只能写成区间，每个数字下都有大段
“未确认”。

这不是为了逃避失败。

当晚确有无数人未能回来。名字能找到的逐一记录；没有名字的，留下最后被看见的形态、位置与可能方向。不能因为总数不清，便把失去写成自然退潮。

海水最低时，维尔萨把七条街放到一块由塔房、断桥和红森林根系缠成的礁石上。塞立稳住地层，帕加只加固已经确定会压人的部分，没有把所有结构锻成同一种形
状。

那里不属于当前世界，也不属于纯净现实。

它位于潮底，只有落潮时显露。愿意留下者可以等待通往当前的路，选择离去者能够从六道外的风口继续前行，尚未回答者则暂时不会被任何一方登记。

有人提议给它命名。

潮骨城居民称它为下港，沉钟港迁入者说应叫无钟岸，未来降兵则习惯称作中立区。那个自称“我”的孩子只说“这里”。

我们没有选出统一名称。

地图上暂时留下一块有许多别称的空地。

我救起的那只手终于有了形体。它属于一名浑身覆盖细鳞的人，没有当前语言。醒来后，它立刻挣脱我，朝退潮方向爬去。

我没有拦。

它爬出十几步，又回头将一片鳞放在断墙上。那可能是感谢、指责、路标，或只是一片自然脱落的甲片。

我在记录里写：

“对方离开。留下鳞片。含义未知。”

潮底没有统一方向。

至少因此，每一个离开当前世界的人，不必都被写成消失。
