# b.4.0 发布记录

2026-09-24。本版由 b.3.9 按既定进位规则更新为 **b.4.0**，内部安装版本为 **0.4.0**；下一版为 b.4.1。收录第三十四至三十六轮 **N104–N106** 导出修复，以及本地素材缓存优化。

## 本次改动

- 完整项目包把“原本不存在”的可选目录与清单也纳入快照。导出过程中首次出现素材、模板或清单时明确要求重试，避免成功包静默遗漏新增内容。
- 导出取消或写入失败时，等待仍在进行的文件打开、读取与实际关闭全部收尾，再清理临时包或释放任务。成功导出同样等待文件关闭，保留首次失败原因。
- 取消信号贯穿元数据读取、素材目录扫描、正文读取和最终复查。取消后停止后续扫描，迟到的坏正文不会覆盖取消结果；已经取消的请求也不会先回收旧导出包。
- 本地图片、视频、音频等素材响应增加 `no-store`，避免网页缓存重复存放原文件。内置与外置素材、稳定 ID 与旧路径入口行为一致，保留分段读取和条件请求。

详见[缺失路径快照](EXPORT_SNAPSHOT_BUGFIX_b.3.9.md)、[导出读取与关闭](EXPORT_STREAMS_BUGFIX_b.3.9.md)、[准备与最终复查取消](EXPORT_PREPARATION_BUGFIX_b.3.9.md)。这些报告保留排查时的 b.3.9 标记。

此前的[本机磁盘清理](DISK_OPTIMIZATION_2026-09-24.md)实际回收约 624 MiB，并核验作品、素材、备份、未提交修改及完整 Git 对象均保留。清理属于本机维护，发布不会自动删除使用者的应用数据。

归档格式、作品清单、元数据和原始素材继续兼容。版本清单、锁文件、编辑器和作品库界面已同步；功能图更新为修订 51，保留三十六轮修复与本次缓存优化证据。

## 验证

- 完整应用检查 **490 项全部通过，零失败、零跳过**，包含实际 Node/Rust 归档往返与登记一致性检查；135 份 JavaScript 语法、版本及 API 契约检查通过。本版新增 50 个执行场景。
- 重新编译生产归档模块和官方 CLI：Rust 归档测试 **13 通过、0 失败、1 忽略**；忽略项依赖真实大体积作品。61 份解析后的依赖版本与校验和匹配项目锁文件。
- 完整 Tauri 库沿用此前 **22 通过、1 忽略**的实测证据，并重新核对对应源码指纹。本次没有重编完整宿主或重跑原生窗口、媒体解码和独立集成测试。
- 核验离线 Cargo 依赖解析、全部 121 份 glib 修复副本文件，以及源码归档中每个文件的字节、权限和解包后的依赖解析。临时编译与验证包完成后清理。

原生模块首次临时编译缺少编译期引用的项目默认定义，修正临时目录布局后通过；未因此修改生产 Rust 源码，初次记录一并保留。完整证据见[发布验证记录](test-results/release-b.4.0/results.json)。测试使用临时作品，日常作品未修改。

本次提交和推送源码版本，未构建或替换桌面发行包；已安装程序须安装后续包含本版的构建，才会应用这些修复。
