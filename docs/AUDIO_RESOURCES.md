# 音频资源引用

桌面版与本地浏览器编辑服务支持以下操作。Android 预览版的项目包保留音频字节与引用，但素材访问、插入和播放尚未接入。

配音、音乐和音效与图片、视频使用同一套素材登记与引用流程，适用于任何项目类型。

## 编辑与播放

进入编辑状态，点击 **插入素材 → 从电脑导入**，或把音频文件拖入编辑区。素材窗口可按“音频”筛选、搜索并复用已有文件。支持 MP3、WAV、OGG / OGA、Opus、FLAC、M4A 和 AAC，单个文件最多 256 MB。

文本与 Markdown 在光标处插入引用；JSON / YAML 在媒体列表中追加对象，保留原有内容、注释和换行。源码、区块与 [字段模式](FIELD_EDITING.md)均可编辑，草稿里立即显示播放器，保存后在正文对应位置显示。

播放器提供播放、暂停、进度拖动和原音频下载，不自动播放。文件保留原始编码，实际播放取决于浏览器或系统解码器；离线、缺失或编码不支持时显示提示，并保留原文件入口。

音频采用正常缓冲，避免 Linux WebKit 在仅加载元信息时把短 OGG 的时长算错、跳转回开头。缓冲不触发自动播放；退出编辑或替换草稿预览时，会暂停旧播放器。

## 文件与引用

新音频位于当前作品素材存储的 `media/audio/<UUID>.<扩展名>`，登记保存在 `metadata/assets/<UUID>.json`，类型为 `audio`。已有音频保持原目录和标识；若作品绑定外置素材目录，导入会写入该目录。素材不会写入程序目录。

文本与 Markdown 使用音频扩展语法：

```md
!audio[角色配音](asset:00000000-0000-0000-0000-000000000001)
```

JSON / YAML 使用媒体对象，例如：

```yaml
配音:
  type: audio
  src: asset:00000000-0000-0000-0000-000000000001
  caption: 角色配音
```

可将对象放入任意字段或列表，无需角色专用字段。代码围栏中的引用示例保持代码显示。旧的 `assets/...` 路径仍可解析，新插入的引用使用稳定 ID。

同一音频再次导入时复用内容一致且完整的原文件。导入完成后取消文档编辑，会保留已登记音频，便于下次使用；格式不符、超限或上传中断则清理本次未完成的临时文件。

## 导出与迁移

- 离线网页分享包携带实际引用或明确绑定的音频，在网页中显示播放器及下载入口。
- Markdown 分享包携带原始音频，并生成相对文件链接；`sources/` 保留原始引用语法。
- 完整项目包保留全部音频、元数据与正文，并逐文件校验。恢复到其他目录后仍通过稳定 ID 访问，外置素材在迁移包内归入 `assets/`。

回归测试覆盖格式识别、旧素材复用、源码保留、分段读取、保存重建、导出及迁移。原生桌面流程还检查常用音频编码的播放、暂停、进度跳转，以及筛选、拖入和重新打开后的引用。
