# b.3.4 发布记录

2026-09-23。本补丁收录第十九、二十轮功能链路检查中的 **N70–N75 共 6 处修复**，版本由 b.3.3 更新为 **b.3.4**，内部安装版本为 **0.3.4**。

## 本次修复

- 取消后的旧模板请求不会覆盖新缓存或错误记录，避免后续新建使用旧内容或误报空模板失败。
- 旧新建请求结束时停止后续收尾，保留新草稿的光标、滚动位置、正文和未保存状态。
- 手动修改新建文件扩展名会刷新素材预览，使用当前路径与类型解析，旧响应不能恢复过时预览。
- 未授权或权限不足时正常显示错误与请求 ID，避免错误提示自身崩溃；保存失败保留原版本与源码、区块草稿，修改后可以重试。
- 新建保存自动补后缀后同步草稿、界面及预览路径；创建失败后状态仍然一致，换名重试保留正文和选定类型。
- 对补完后缀的文件名再次校验长度，超长时在提交之前提示，缩短名称后可继续保存。

功能图更新为修订 28，保留此前二十轮复现和验证证据。详细记录见 [新建模板加载与路径切换修复](TEMPLATE_LOADING_BUGFIX_b.3.3.md) 和 [保存失败与重试修复](SAVE_RECOVERY_BUGFIX_b.3.3.md)，两份报告保留排查时的 b.3.3 标记。

正文、文档与素材 ID、归属关系及迁移包格式保持兼容，无需手工迁移作品。版本编号继续遵循 [既定进位规则](RELEASE_b.2.9.md#版本规则)。

## 验证

b.3.4 完整应用检查 **268 项：267 通过、0 失败、1 跳过**；120 份 JavaScript 语法、版本一致性及 API 契约检查通过。跳过项需要额外的原生归档互通工具，本轮原生归档代码未变。

本次新增 10 个执行场景，覆盖取消后重开、模板响应顺序、空模板、光标与滚动保护、路径和预览衔接、授权失败、超长文件名及重试。临时 HTTP 项目核对重名保护、换名创建、所选类型、再次保存及 BOM、CRLF；源码保存成功后的重建失败仍保留干净基线。控制器测试模拟网络和播放，不代表真实媒体解码或原生窗口交互。

发布验证核对 Cargo 清单和锁文件、全部 121 份 glib 修复副本文件、功能图源码引用、源码包逐文件内容及解包后的依赖解析。证据见 [发布验证记录](test-results/release-b.3.4/results.json)。本轮未重跑 Rust、原生窗口或编解码测试，未构建和安装桌面包。测试使用临时作品；验证用源码包检查后清理。
