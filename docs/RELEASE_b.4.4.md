# b.4.4 发布记录

2026-09-24。本版由 b.4.3 更新为 **b.4.4**，内部安装版本 **0.4.4**；下一版为 b.4.5。收录字段内编辑、中英日翻译与编辑体验优化。

## 新增与改进

- **字段内编辑**：以分组属性表修改文字、数值和开关，支持筛选、只看已修改、恢复单项值及插入图片、视频、音频引用。Markdown / TXT 使用项目解析规则，JSON / YAML 展开对象与列表；与源码、分段编辑共享草稿和保存流程。仅替换改动的值，保留其他正文、注释、空格与换行。
- **中英日界面**：设置内即时切换简体中文、English 和日本語，覆盖作品库、编辑器、导出、原生关闭确认和应用提供的文件窗口标题。英日词典各 626 条；分享包使用开始导出时的语言。作者的正文、标题、名称和路径保持原文。
- **错误与提示翻译**：模板、字段、素材和导出错误保留可翻译的具体原因，切换语言后同步更新。自动生成的章节标题按语言显示，作者写的同名标题保持原样。底层未知诊断仍显示原文。
- **编辑体验**：输入法确认候选字不再触发保存或冲突操作，组词结束后更新搜索；重复快捷键不会重复提交。小窗口工具栏换行，长译文与封面不会挤压正文和操作。

使用及开发阶段验证见[字段编辑](FIELD_EDITING_b.4.3.md)、[三语支持](TRILINGUAL_SUPPORT_b.4.3.md)、[实际使用优化](USABILITY_INPUT_b.4.3.md)和[翻译完善](TRANSLATION_REFINEMENT_b.4.3.md)。这些报告保留执行时的 b.4.3 版本与原始指纹。功能网络图仍保留 b.4.3 快照，本版新增字段和翻译链路见上述说明。

版本文件、依赖锁文件、编辑器与作品库版本标签已同步。项目及迁移包结构兼容，语言偏好不写入作品；已有索引需重建后才能区分自动生成与作者书写的同名章节标题。
