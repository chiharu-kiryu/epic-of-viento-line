# 字段编辑

2026-09-24，基于 `38c7f61d` 的 b.4.3 工作区，接续中英日翻译与编辑体验优化。本轮增加类似对象编辑器的分组属性表。版本保持不变，未提交、推送、打包或替换已安装程序。

## 使用

1. 打开文档，点击 **开始编辑 → 字段编辑**；新建文档时也可在加载模板后切换到字段编辑。
2. 左侧显示字段名称，右侧直接修改值。文字支持多行，数值有格式校验，布尔值使用“是 / 否”选择。
3. 搜索字段名称或值，按需折叠分组；打开 **只看已修改** 可集中检查本次改动。每行的 **恢复** 回到进入该模式时或最近一次成功保存的值。
4. 点击 **保存修改**，或按 `Ctrl/Cmd+S`。在字段值内也可用 `Ctrl/Cmd+Enter`；输入法确认候选字不会触发保存。

字段编辑与源码、分段编辑使用同一份草稿，可以来回切换；保存沿用现有版本冲突检查、写入和索引重建流程。切换界面语言会保留未保存的值、控件焦点和选择位置。作者的字段名称、分组标题与正文保持原文。

在文字字段中定位光标后，**插入素材** 会将图片、视频或音频标记放入该字段。JSON / YAML 中声明为 `image`、`video`、`audio` 的素材对象，其 `src` 字段可直接选择一份同类型素材并替换为稳定引用；不会额外生成一组根级素材。

## 通用解析与内容保护

| 文件 | 可编辑内容 |
| --- | --- |
| Markdown / TXT | 项目解析器识别的“字段名：值”；优先使用项目字段分组，其次按章节分组 |
| 多行属性加成 | 与阅读器一致，拆开纯数值加成或命名条目，例如“+350 魔法上限”可单独修改 |
| JSON / YAML | 递归列出文字、数字和布尔值；嵌套对象和数组显示字段路径 |

这里使用项目自己的类型、解析规则和分组，未写死英雄、技能或其他作品的专用字段。故事类型的允许字段列表仍然生效，人物对白不会被额外猜成属性。

保存只替换实际修改的值所在片段。未改动的故事正文、字段名、重复键、空格、注释、BOM 与换行保持原样；大整数不会经过浮点数转换。修改 YAML 多行文本时会写成带转义的引号字符串，保留文本值并确保后面的字段独立成行。

本轮支持修改已有字段的值。增加或删除字段、改变字段类型和层级，请使用源码编辑。YAML 锚点、别名、自定义标签、空值与空集合保留在原文中，界面提示使用源码编辑；不会自动展开或转换。无效数值会标记对应行并阻止字段模式保存；JSON / YAML 语法尚未完整时保留当前草稿，提示先修正语法。

## 实现链路

`当前草稿 → POST /api/doc/fields → 项目类型与解析器 → 源文值片段 → 字段控件 → 按片段回写草稿 → 既有保存与重建`

字段接口仅解析请求中的草稿，不写作品文件、登记表或其他元数据；仍受现有编辑接口鉴权、来源检查、请求大小和速率限制保护。加载可取消，过期响应不会重新打开已经关闭的编辑会话。字段数量和嵌套深度有上限，超出时提示使用源码编辑。
