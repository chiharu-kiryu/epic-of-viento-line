## N87：取消后仍登记已完成的导出包

ZIP 写入完成时，写入器会移除取消监听；导出服务随后异步读取 ZIP 大小，再将结果登记为可下载任务。如果用户在这次读取期间取消，或导出 HTTP 连接断开，原代码仍返回成功并保留 ZIP。界面已放弃结果，因而无法释放这个未领取的包；它占用磁盘和最多 3 个任务中的一个名额，直至默认的 15 分钟空闲过期。

现在在最后一次异步读取之后、登记任务之前再次检查取消状态。取消会进入已有清理分支，删除本次暂存目录并解除生成锁；原文和其他已准备的任务保留。普通完成、下载和释放行为不变。
