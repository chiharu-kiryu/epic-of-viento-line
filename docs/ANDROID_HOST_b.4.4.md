# Android 宿主与本机存储（b.4.4 开发记录）

本轮接续 [引擎拆分](ANDROID_FOUNDATION_b.4.4.md)，接入 Android 应用入口和原生作品存储。保持版本 b.4.4 / 0.4.4，未执行提交、推送或替换已安装的桌面程序。

## 已接入

- `src-tauri/src/lib.rs` 分派桌面与移动端入口；桌面实现移动到 `desktop_host.rs`，桌面专用依赖限制在非移动目标。
- Android 使用静态离线页面和 Tauri IPC，不启动 Node 或 HTTP 服务，也不随应用分发作品。
- 本机作品库可创建、打开 v3 作品，复用原有项目默认类型和模板。路径、UUID 登记与桌面格式一致。
- 现有编辑器可创建文档、修改源码/分段/字段、保存和重新打开。索引由通用引擎即时生成，保留文档归属关系。
- 原生层限制私有目录和文本大小，拒绝符号链接、路径穿越、冲突文件名，并执行原子写入和修订检查。
- 新建文档通过 `.viento/mobile-create/` 写入持久化意图；若进程在正文和登记发布之间终止，下次打开完成同一份创建。冲突文件不会被覆盖，已提交但丢失回执的草稿直接重开为已保存。
- 按作品保留恢复草稿，保留源文本、换行及旧修订号；恢复不会静默覆盖较新文件。保存失败、草稿存储配额不足、未完成的文件名都有对应保留逻辑。
- 中英日设置可即时切换并记住语言；未接通的素材、导出和模板配置入口在移动宿主中关闭。
- Android 工程、图标、源码打包和生成目录清理已纳入仓库结构。启动图标沿用 `desktop/icon.svg` 中的 Viento 标识。

## 本轮验证

| 检查 | 结果 |
| --- | --- |
| 程序检查 | 190 个 JavaScript 文件语法通过；API 契约预检通过 |
| JavaScript 与原生联调测试 | 启用移动存储与归档桥后，643 项全部通过，无跳过 |
| Rust 单元测试 | 29 通过，1 个既有优化构建专项测试忽略 |
| 真实 Rust 存储联调 | 私有作品创建、模板读取、索引、字段修改、保存、重开、旧版本拒绝、路径越界与作品隔离通过 |
| 中断创建恢复 | 分别模拟仅写入意图、只发布登记、已发布正文；重开恢复正文与同一 ID；遇到不同正文拒绝覆盖 |
| 丢失保存回执 | 浏览器在原生创建完成后收不到回执；关闭重开后显示已保存，登记数量仍为 2，没有重复文档 |
| 原文字节 | 含 BOM、CRLF 的角色档案仅修改 `100 → 175`，正文及登记 ID 保持不变 |
| 390 × 844 浏览器联调 | 创建作品 → 角色文档 → 字段 `100 → 175` → 保存；未保存的 `222` 在关闭页面重开后恢复，保存重开仍为 `222`，故事正文不变 |
| 语言与入口 | 中英日切换正常，日语从编辑器保留到作品库，英语字段界面正常；无未接通的模板设置快捷入口 |
| 离线依赖 | 137 个前端文件，约 3.55 MiB；366 条模块引用全部存在且为本地依赖 |
| 桌面归档兼容 | 将移动存储创建的作品交给桌面归档工具导出并恢复，9 个源文件逐字节一致，文档 ID 保持不变 |

浏览器联调替代了 Tauri IPC 传输，实际读写使用同一份 Rust 移动存储代码及独立临时作品目录。它不能替代 Android 真机上的 WebView、软键盘、系统返回和进程回收测试。

已构建 ARM64 调试 APK：`dist/android-preview/Viento-Studio_b.4.4_android-arm64-debug.apk`（47.18 MiB）。签名验证通过，应用 ID `io.viento.studio`，版本 `0.4.4` / `4004`，最低 Android 8.0（API 26）、目标 API 36。APK 内原生库与最终编译结果逐字节一致，包含创建中断恢复逻辑，不含 Node sidecar 或作品文件。未安装到设备，未进行真机验证。

验证记录位于 [test-results/android-host-b.4.4/](test-results/android-host-b.4.4/)，包括测试日志、手机尺寸截图、接口与资源检查结果。构建、签名、原生库一致性与归档兼容性结果也已归档。
