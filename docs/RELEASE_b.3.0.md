# b.3.0 发布记录

2026-09-23。本补丁修复保存冲突和失败重试中的误覆盖问题。按既定编号规则，`b.2.9` 进位为 **b.3.0**，内部安装版本为 **0.3.0**。

## 本次修复

- 强制保存失败后保留原来的草稿版本，下一次普通保存仍会提示冲突；只有保存或读取最新正文成功后才更新基线。
- 读取最新正文失败时显示具体原因，保留区块草稿和编辑状态，支持重试。
- 保存条件改用正文内容指纹，外部工具修改正文但保留文件时间时，也能识别冲突。
- 功能图更新到修订 16，保留 N47–N49 的复现证据和源码指纹；继续包含此前的 glib 安全修复。

详细触发条件、接口说明和修复前后结果见 [保存冲突修复记录](SAVE_CONFLICT_BUGFIX_b.2.9.md)。文档接口调用方应原样传回读取到的 `version`，不能再把它作为文件时间计算；历史字段 `expectedLastModified` 同样接受内容版本。仅携带旧时间戳的普通保存返回冲突，需要重新读取正文。

正文、模板、登记和素材的保存格式不变，无需迁移作品数据。新版本编号遵循 [既定进位规则](RELEASE_b.2.9.md#版本规则)。

## 验证

应用检查 **203 项：202 通过、0 失败、1 跳过**；版本一致性、117 份 JavaScript 语法和 API 契约预检通过。跳过项为需要额外原生测试工具的 Node/Rust 归档互通，本补丁未修改原生归档实现。

发布检查另验证 Cargo 清单与锁文件、功能图引用和 391 份文件的源码包；解压后仍使用包内的 glib 修复副本。结果见 [发布验证记录](test-results/release-b.3.0/results.json)。此前在 b.2.9 排查阶段完成的 35 项保存专项结果保持原版本标记。本次未重跑 Rust 或原生窗口交互，未构建、安装桌面包；日常作品数据未改动。
