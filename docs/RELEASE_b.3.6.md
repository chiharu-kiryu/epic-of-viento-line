# b.3.6 发布记录

2026-09-23。本补丁收录第二十三至二十五轮功能链路检查中的 **N81–N87 共 7 处修复**，版本由 b.3.5 更新为 **b.3.6**，内部安装版本为 **0.3.6**。

## 本次修复

- 搜索或分类筛选期间保留当前编辑、新建及原文读取会话。保存后正文不再匹配搜索时，也能继续编辑同一文件；明确点击其他文档仍正常确认是否放弃草稿。
- 筛选无结果时，当前文档仍使用重建后的目录条目刷新显示。窄窗口搜索保留侧栏，明确选择文档时再收起。
- 切换语言时保留目录加载、失败原因及重试提示，保持保存中和只读后端的按钮禁用状态。新建类型的内置名称同步翻译，自定义名称保持原文。
- ZIP 已完成、任务尚未登记时取消导出或断开连接，会立即清理本次暂存包并解除生成锁，不再遗留文件或占用导出名额；随后可正常重新导出。

功能图更新为修订 35，保留二十五轮复现与验证证据。详细记录见 [筛选与目录刷新](EDITOR_FILTERING_BUGFIX_b.3.5.md)、[语言切换](EDITOR_LANGUAGE_BUGFIX_b.3.5.md) 和 [导出取消](EXPORT_CANCELLATION_BUGFIX_b.3.5.md)，三份报告保留排查时的 b.3.5 标记。

正文、元数据、素材和迁移包格式保持兼容，无需手工迁移作品。版本编号继续遵循 [既定进位规则](RELEASE_b.2.9.md#版本规则)。

## 验证

发布验证核对 Cargo 清单和锁文件、全部 121 份 glib 修复副本文件、功能图源码引用、源码包逐文件内容及解包后的依赖解析。证据见 [发布验证记录](test-results/release-b.3.6/results.json)。本轮未重跑 Rust、原生窗口或编解码测试，未构建和安装桌面包。未修改日常作品；验证用源码包检查后清理。
