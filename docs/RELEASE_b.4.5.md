# b.4.5 发布记录

2026-09-25。本版由 b.4.4 更新为 **b.4.5**，内部安装版本 **0.4.5**；下一版为 b.4.6。收录可移植引擎与 Android 预览宿主，项目格式和稳定 ID 继续与桌面版兼容。

## 新增与改进

- **通用引擎拆分**：解析、布局、字段修改、素材引用和文档保存流程集中到 `engine/`，不依赖 Node、HTTP 服务或本机目录。桌面服务使用实际文件适配器，Android 通过原生存储适配；旧调用入口保留兼容转发。
- **Android 本机编辑**：应用离线启动，提供私有作品库、新建作品及文档、源码/分段/字段编辑、保存和重开。复用项目类型、模板和文档归属规则，不启动桌面 Node 子进程，也不把作品打入安装包。
- **草稿与中断恢复**：按作品保留编辑草稿和原始修订号；恢复时仍检查保存冲突。新建文档使用持久化创建意图，恢复原正文及同一文档身份；保存成功但丢失回执时不会重复创建。
- **完整项目迁移**：作品库通过 Android 系统文件选择器导入、导出 v2 / v3 项目包，保留正文、模板、元数据、故事归属和图片/视频/音频文件。导入在隔离目录校验后发布，同一作品已存在时拒绝覆盖，未登记正文和超限数据会明确提示。
- **三语与触屏布局**：移动界面支持简体中文、English、日本語即时切换，补齐迁移状态、重试和错误提示；暂未接通的操作入口隐藏。
- **构建与数据分离**：纳入 Android 源工程、图标及构建入口，桌面依赖限制在桌面目标。桌面资源和源码包包含共享引擎，清理规则覆盖移动构建缓存，排除密钥、设备配置及作品数据。

开发阶段的操作流程及字节核对见[引擎拆分](ANDROID_FOUNDATION_b.4.4.md)、[本机编辑](ANDROID_HOST_b.4.4.md)和[项目包迁移](ANDROID_TRANSFER_b.4.4.md)。这些历史报告保留执行时的 b.4.4 版本与指纹；功能网络图保留原有 b.4.3 快照，新移动端链路以本版说明和[移动端开发文档](../mobile/README.md)为准。

## 发布验证

本次版本文件、依赖锁、编辑器及作品库版本标签同步到 b.4.5 / 0.4.5。发布检查使用临时作品，汇总记录位于 [test-results/release-b.4.5/results.json](test-results/release-b.4.5/results.json)。

- 使用打包的 Node 24.20.0 检查 191 份 JavaScript 文件，646 项程序测试全部通过，无跳过；测试接通原生项目包与移动存储桥接。
- 原生测试在锁定依赖、离线模式下通过 42 项；1 项依赖指定完整作品目录的迁移测试按条件忽略，没有使用日常作品。
- 桌面打包的 136 份运行文件逐字节匹配源码，翻译副本一致；移动静态包包含 137 份文件，365 处静态模块引用均可解析。安装资源中没有作品数据。
- 重新构建 b.4.5 Android 预览 APK，核验内部版本 0.4.5、版本码 4005 和调试签名；原生库与本次编译结果一致，文件选择器插件已打包，未申请广泛存储权限。此项为构建验证，尚未在设备上实测。

## 移动预览范围

本版 Android 构建为 ARM64 调试 APK，最低 Android 8.0（API 26），目标 API 36。尚未进行真机/模拟器完整工作流验证，未配置正式发布签名。素材文件可随项目包迁移，但移动端的素材访问与插入、项目类型和模板配置仍待接入；文档分享导出暂未开放。外部目录持续编辑及 iOS 宿主不在本版范围内。

当前移动导入限制：ZIP 最大 1 GiB、展开后最大 4 GiB、最多 50,000 个归档条目；单份正文/元数据文件最大 1 MiB，正文和元数据合计分别最大 32 MiB，登记文档最多 20,000 份。编辑草稿须先保存再导出；清除应用数据或卸载前，应先导出项目包。

开发阶段曾出现一项既有桌面下载测试偶发返回 409；单独复测和最终全量回归通过，详见迁移报告。本版没有将该问题列为已修复。

本次提交和推送源码版本。Android 预览产物在本地 `dist/android-preview/`，不会随 Git 提交；已有安装程序需安装包含本版的构建才会更新。
