# 字段编辑

字段表适合逐项调整档案属性，与源码、分段编辑共用当前草稿。桌面、浏览器和 Android 预览版均已接入；素材选择目前仅在桌面 / 浏览器提供。

## 使用

1. 打开文档，选择 **开始编辑 → 字段编辑**。新建文档也可在加载模板后进入字段表。
2. 左侧为字段名，右侧直接修改值：文字支持多行，数值有格式检查，布尔值使用“是 / 否”选择。
3. 搜索名称或值，折叠分组，或用 **只看已修改** 检查本次修改。每行的 **恢复** 返回该轮字段草稿的基准值；成功保存后使用新的保存值。
4. 点击 **保存修改**。桌面 / 浏览器还可按 `Ctrl/Cmd+S`，字段内可用 `Ctrl/Cmd+Enter`；输入法确认候选字不会触发保存。

切换模式使用同一份草稿。切换界面语言保留字段输入、焦点和选择位置；作者的字段名、分组标题和正文保持原文。模板配置的字段分组优先于章节分组。

## 格式与边界

| 格式 | 字段表内容 |
| --- | --- |
| Markdown / TXT | 项目解析器识别的“字段名：值”；按项目分组或章节展示 |
| 多行属性条目 | 与阅读布局一致，纯数值加成或命名条目可以单独修改 |
| JSON / YAML | 递归列出文字、数字和布尔值，对象和数组用字段路径定位 |

故事类型的允许字段列表仍然生效，人物对白不会额外猜成属性。字段表修改已有值；增加或删除字段、改变类型和层级时使用源码模式。新文档的分段编辑在首次保存后可用，首次创建可使用源码或字段表。

只改写实际修改的值片段；未改动正文、字段名、空格、注释、BOM 和换行保持原样。大整数避免浮点转换。修改 YAML 多行文本时会使用带转义的引号字符串，保留文本值及相邻字段的边界。

YAML 锚点、别名、自定义标签、空值和空集合保留在源码中，并提示使用源码模式。无效数值会标记对应行并阻止字段保存；JSON / YAML 语法不完整、字段或嵌套超限时保留草稿并提示修正或使用源码。

## 素材与保存

桌面 / 浏览器可在文字字段中定位光标，再用 **插入素材** 放入图片、视频或音频标记。结构化素材对象的 `src` 字段可选择同类型素材并替换为稳定引用，避免另生成根级素材。Android 当前保留这些引用和包内文件，但未接入素材选择、访问和播放。

保存继续使用原有版本冲突检查。冲突时保留当前草稿，按提示处理最新内容；不要通过重复点击保存来强制覆盖。索引刷新失败与正文写入失败分别提示。Android 会另外保留按作品隔离的恢复草稿；桌面关闭仍应先保存或明确丢弃。

原理见 [引擎接口](../engine/README.md)，验证状态见 [测试指南](TESTING.md)。首次实现的详细浏览器记录保存在 [b.4.3 字段编辑报告](FIELD_EDITING_b.4.3.md)，后续 Linux 与 Android 原生验证见 [链路补测](WORKFLOW_VERIFICATION_b.4.5.md)。
