# b.2.8.1 发布记录

2026-09-12。本次在 b.2.8 上增加补丁号，统一收录导出、多语言和通用项目模板引擎。

## 本次更新

- 编辑器支持导出离线 HTML / Markdown 文档包，以及可恢复的完整项目包；文档包包含关联素材和附属故事，完整包保留项目清单、模板、元数据及素材。见 [作品导出](EXPORT.md)。
- 作品库和编辑器可在设置中即时切换简体中文与 English，记住选择并保留未保存草稿，正文与项目字段保持原文。见 [多语言支持](LANGUAGES.md)。
- 项目类型与模板可在编辑器中新增和修改，支持预览解析、指定标题字段、长文本规则和字段分组；新建、索引、素材预览与导出使用同一套项目定义。见 [项目工作流](PROJECT_WORKFLOW.md)。
- 原作品 Epic of Viento Line 作为独立官方示范，其特有规则放在项目定义中，角色背景保持所属关系；正文与素材继续保存在外部作品库。见 [官方示范](examples/README.md)。

## 版本规则

根目录 [VERSION](../VERSION) 是发布编号来源。本次对外版本为 **b.2.8.1**，Tauri、Cargo、npm 与安装器的内部版本为 **2.8.1**。

发布编号使用 `字母.主号.次号.补丁号`，内部版本使用 `主号.次号.补丁号`。仍兼容省略补丁号的旧格式，例如 `b.2.8` 对应 `2.8.0`。数字不使用前导零，字母沿用原项目命名。

更新时同步 `VERSION`、`package.json`、`package-lock.json` 的根包、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 的应用包、`src-tauri/tauri.conf.json`，以及编辑器和作品库首页的版本标识。`npm run check -- --app-only` 和桌面构建准备会检查一致性。

桌面构建脚本与源码归档脚本均支持补丁号，输出名称例如 `Viento-Studio_b.2.8.1_amd64.AppImage` 和 `Viento-Studio_b.2.8.1_source.tar.gz`。版本更新不会自动替换已经安装的程序；安装包需从对应提交重新构建。
