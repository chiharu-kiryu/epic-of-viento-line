# b.3.3 发布记录

2026-09-23。本补丁收录第十七、十八轮功能链路检查中的 **N64–N69 共 6 处修复**，版本由 b.3.2 更新为 **b.3.3**，内部安装版本为 **0.3.3**。

## 本次修复

- YAML 素材列表按实际缩进追加，支持连续插入，保留既有值、注释、BOM 和换行格式。
- 带指令、注释及文档标记的空 YAML 可以插入第一份素材；显式数值、标签和锚点不会被覆盖。
- 最新原文读取完成后刷新素材预览，无需再输入或切换编辑方式。
- 切回浏览模式时暂停编辑器里的音视频，隐藏预览并使旧响应失效。
- 空项目退出首份新建草稿时清理编辑状态；取消丢弃确认仍保留草稿。
- 切换模板等待新正文时，按路径和类型立即清除旧预览；媒体未改变的源码/区块切换及保存继续复用播放器。

功能图更新为修订 25，保留此前十八轮复现和验证证据。详细记录见 [结构化素材插入修复](MEDIA_INSERTION_BUGFIX_b.3.2.md) 和 [素材预览与编辑切换修复](MEDIA_PREVIEW_BUGFIX_b.3.2.md)，两份报告保留排查时的 b.3.2 标记。

正文、文档与素材 ID、归属关系及迁移包格式保持兼容，无需手工迁移作品。版本编号继续遵循 [既定进位规则](RELEASE_b.2.9.md#版本规则)。

## 验证

b.3.3 完整应用检查 **258 项：257 通过、0 失败、1 跳过**；120 份 JavaScript 语法、版本一致性及 API 契约检查通过。跳过项需要额外的原生归档互通工具，本轮原生归档代码未变。

本次新增的 15 个场景覆盖 YAML 插入、真实 HTTP 素材复用/保存/重读/索引/导出，以及编辑器与素材控制器的状态衔接。控制器测试模拟网络和播放，不代表真实媒体解码或原生交互测试。

发布验证核对 Cargo 清单和锁文件、全部 121 份 glib 修复副本文件、功能图源码引用、源码包逐文件内容及解包后的依赖解析。证据见 [发布验证记录](test-results/release-b.3.3/results.json)。本轮未重跑 Rust、原生窗口或编解码测试，未构建和安装桌面包。测试使用临时作品；验证用源码包检查后清理。
