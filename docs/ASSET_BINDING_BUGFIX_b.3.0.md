## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N50 | `bind-assets` 绕过登记锁，其他进程正在登记时仍可切换目录；整份重写本机配置也会丢失已有扩展字段。 | 通过共享登记锁更新主素材路径，保留其他有效字段；占用、目标不存在或不是目录时保留原配置。 |
| N51 | `.viento` 是目录链接时，绑定命令会把配置写到作品外；本机配置文件本身是链接时也会直接替换链接。 | 写入前检查配置及每层父路径，拒绝链接；作品外文件和原链接均保留。所选素材根的目录别名仍可解析为实际目录。 |
| N52 | 核验跟随素材链接，只检查正文路径是否存在；同目录素材链接、默认素材根链接、正文链接或替代正文的目录可能报告通过。 | 复用路径包含检查，拒绝数据根内的链接并要求登记对象为实际文件；报告具体记录，不修改正文或登记。 |
| N53 | 核验以字符串 `..` 前缀判断越界，使 `..portrait.png`、`..draft/art.png` 等合法相对路径失败。 | 按路径分段和真实目录边界判断，合法文件名正常核验，路径穿越仍拒绝。 |
| N54 | 导入开始时记住素材根；上传尚未完成时重新绑定，提交仍写旧目录并返回成功，当前素材根却找不到新登记的文件。 | 入库取得同一登记锁后再次核对素材根；改变则返回 409 并清理本次临时文件。重新导入写入新目录，保留已有素材和 ID。 |

新增上传错误提示提供中文、英文；素材上传客户端会翻译已登记的服务提示，未知提示保留原文。

## 数据与操作边界

仍需关闭作品的编辑窗口后再绑定、重建和核验。绑定只选择位置，不复制素材、不验证整个目录的完整性，也不重写内容指纹；迁移前应完整复制原目录。外置目录离线时保留原位置，即使作品里存在默认 `assets/`，也不会自动切换过去。

登记锁协调本程序的登记、绑定和入库提交。它不锁住任意外部工具的文件操作；本次不是针对恶意进程反复换链接的完整操作系统级隔离。检查与索引均不回写正文来适应解析器，作品和迁移格式不变。
