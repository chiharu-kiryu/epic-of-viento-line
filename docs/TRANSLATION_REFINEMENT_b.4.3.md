# 翻译完善记录

2026-09-24，基于 `38c7f61d` 的 b.4.3 工作区，接续中英日翻译、实际使用优化和字段编辑。本轮保持版本号不变，未提交、推送、打包或替换已安装程序。

## 本轮变化

- 增加 63 条英日翻译，两份词典各 626 条。补齐模板与类型校验、字段解析、素材插入、导出完整性等提示；调整读取、预览、保存等操作名称，让英文、日语错误和超时句子更自然。
- 错误提示中的具体原因随语言一起切换。项目配置警告、模板预览失败、字段读取失败、导出失败和素材部分导入后的恢复提示均保留可重新翻译的消息结构。
- 程序自动补充的“内容”标题在阅读器和分享导出中翻译；作者写的同名标题、字段名称、作品标签与正文保持原文。已有缓存索引需重建后获得这项区分。
- JSON / YAML 空文档的字段编辑提示改为添加对象字段或列表项；文字格式继续提示添加“字段名：值”。
- 文件名和路径按精确字符串保留，避免全角 / 半角字符、末尾空格造成提示缓存混淆。普通参数不会因为恰好等于“保存”等界面词语而被翻译。

## 实现边界

后端错误保留原有字符串和状态信息，额外提供 `userMessage: { key, values }`；配置警告附带对应描述。客户端只识别词典内的消息键，显式嵌套界面消息，其他参数原样呈现。未知的解析器或系统诊断不猜测翻译，也不对作品正文进行自动翻译。

项目解析规则校验现在返回可解释的 400 输入错误，重复分组字段等情况不再被当成未知服务器错误。校验失败发生在写入之前。生成章节仅增加可选的标题来源标记，保留原有布局版本；没有标记的旧布局按原文显示。
