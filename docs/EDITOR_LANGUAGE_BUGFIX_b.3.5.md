## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N84 | 切换语言无条件重绘目录，把加载中的提示替换为旧目录统计或“无文档”；加载失败后的错误和清缓存重试文案也被覆盖。 | 单独保存当前目录请求的展示状态，按所选语言重绘加载、失败原因和对应重试入口。成功后恢复普通列表；迟到的旧失败不能改写当前请求状态。 |
| N85 | 语言刷新先锁定操作按钮，再由模式刷新无条件启用“编辑”；保存中或后端只读时显示可点击，禁用状态与辅助技术提示不一致。 | 模式刷新和操作状态共用同一套按钮规则，保存期间保持锁定，完成后解除；只读后端始终禁用编辑入口。原有操作处理器已有忙碌拦截，本问题未造成重复写入。 |
| N86 | 新建类型下拉框的内置名称在切换语言后仍停留在旧语言。 | 原位更新内置名称，保留选项节点、已选类型、草稿路径和正在读取的模板。用户自定义类型名称继续保留原文，即使名称与内置词条相同。 |

改动仅涉及编辑器控制器和回归测试，不改写正文、模板、元数据或素材。
