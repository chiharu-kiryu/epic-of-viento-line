# 部分素材导入失败后的恢复 · b.4.1 工作树

2026-09-24，基于 b.4.1 发布提交 `40923a0b`，第四十轮检查 F28–F29：批量导入 → 部分成功 → 失败或取消 → 重选已导入素材 → 保存、重开与索引。

## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N111 | 部分素材已登记后，失败分支还要等待重新读取完整列表。读取失败会退回旧列表，使新素材不可选；读取缓慢时取消仍锁住编辑器。旧搜索、类型或分页状态也可能遮住已成功导入的素材。 | 直接复用上传成功响应中的登记摘要，按稳定 ID 去重并优先展示；只在已有成功导入时重置筛选和分页。恢复不依赖第二次列表请求，立即解除忙碌状态。 |

原有列表中未被本次导入更新的记录继续保留，包括离线状态；再次打开窗口仍读取当前作品完整列表。只成功登记的素材进入恢复列表，失败文件不生成引用，部分成功不会自动改写正文。JSON/YAML 插入准备失败也可重选已入库素材，不必重新上传。
