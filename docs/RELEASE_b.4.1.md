# b.4.1 发布记录

2026-09-24。本版由 b.4.0 更新为 **b.4.1**，内部安装版本 **0.4.1**；下一版为 b.4.2。收录第三十七至三十九轮 **N107–N110** 修复，共新增 29 个执行场景。

## 本次修复

- 导出分段下载收齐后，正确释放空闲任务的名额，避免下载过三个包后无法继续导出。重叠、乱序、缺段或中断不会误判完成，活动下载仍受保护。
- 浏览器下载前核对临时文件是否可用。过期后可在原窗口重新生成，普通网络错误保留重试入口；取消或关闭后，迟到响应不会再启动下载。
- 分块编辑中，素材拖入目标段落，不再因焦点留在旧段而误替换旧段选中的正文。
- 快速重开素材窗口时，旧关闭事件不再清除新的插入位置和素材列表请求。

详情见[导出分段下载](EXPORT_DOWNLOADS_BUGFIX_b.4.0.md)、[浏览器下载重试](EXPORT_BROWSER_BUGFIX_b.4.0.md)、[素材拖放与窗口重开](MEDIA_DROP_BUGFIX_b.4.0.md)。这些报告保留排查时的 b.4.0 标记及原始验证结果。

版本清单、锁文件、编辑器和作品库版本显示已同步；[功能链路图](FUNCTION_NETWORK.md)更新为修订 55。项目目录、元数据、素材引用及迁移包格式继续兼容。

## 验证

- 发布应用检查 **519 项全部通过，零失败、零跳过**；包含实际 Node/Rust 归档往返及登记一致性检查。138 份 JavaScript 语法、版本和 API 契约检查通过。
- 重新编译生产归档模块和官方 CLI，Rust 测试 **13 通过、0 失败、1 忽略**；忽略项需要真实大体积作品。61 份依赖的版本和校验和匹配项目锁文件。
- 保留此前完整 Tauri 库 **22 通过、1 忽略**的结果，并重新核对相关源码指纹。本轮没有重编完整宿主或重跑原生窗口、文件选择器、媒体解码。
- 浏览器导出在开发阶段已实测两次下载，落盘 ZIP 摘要与服务端一致。拖放及关闭时序使用实际控制器与可控 DOM，素材导入、保存、重开及索引经过真实 HTTP 服务；本轮发布没有重复操作浏览器原生拖放。
- 核验离线锁定的 Cargo 依赖解析、121 份 glib 修复副本文件，以及源码归档 664 份文件的字节、权限和解包后的依赖解析。临时编译目录和验证包完成后清理。

完整证据见[发布验证记录](test-results/release-b.4.1/results.json)。测试仅使用临时作品，日常正文、素材和备份未修改。

本次提交和推送源码版本，未构建或替换桌面发行包；已安装程序须安装后续包含本版的构建，才会应用这些修复。
