## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N76 | 取消读取只阻止外层进入编辑，底层仍先更新正文缓存和版本。重新编辑并保存后，迟到的旧响应还能回退窗口内缓存；选择文档时发起的读取也可能在切回浏览后重新填入已清空的编辑区。 | 更新缓存之前核对请求代次、当前模式、选中文档及源路径。失效响应返回空结果，显示层不再应用；新保存的缓存和版本继续有效，退出状态保持完整。 |
| N77 | 读取失败在检查请求是否仍有效之前就写入诊断。已经切换到另一份文档，旧请求的权限错误仍会出现在当前窗口。 | 读取层先返回失败信息，仅当前请求可以记录错误和更新提示；当前文档的读取失败仍正常报告并允许重试。 |
| N78 | 读取过程中刷新索引，即使文档标识不变，原索引对象也可能已被替换。旧请求仍进入编辑，可能把旧路径正文用于新条目；冲突重读也可能用已失效的结果替换草稿并标记已同步。 | 同时核对当前索引对象身份。失效读取不进入编辑，并解除原读取的忙碌状态；失效的冲突重读保留草稿和原基线，只有重新读取当前条目成功后才更新内容与版本。 |

本轮没有改变磁盘正文、接口格式、文档身份或作品迁移结构。修复发生在窗口内的请求、缓存与编辑状态衔接。
