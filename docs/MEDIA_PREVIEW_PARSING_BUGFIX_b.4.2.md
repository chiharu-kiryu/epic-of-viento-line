# 结构化草稿预览与解析一致性 · b.4.2 工作树

2026-09-24，第四十三轮沿 F18、F21、F29、F30 检查结构化草稿的解析、预览恢复、保存和重开。基于 b.4.2 发布提交 `03265ba0`。

## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N114 | JSON/YAML 暂时缺少括号等语法错误会被解析器标记，但预览接口忽略错误，仍返回成功和空素材列表。编辑器因此移除已有图片、暂停音视频。 | 预览接口将解析失败返回为格式错误，编辑器保留上一份有效预览；合法删除素材则正常清空。草稿与光标不变，不隐式保存。 |
| N115 | 前端依赖源文本中的 `src`、`asset:` 等文字决定是否请求解析；合法的转义字段名可能没有这些字样，只有 `{` 的未完成草稿也会提前清空预览。 | JSON、YAML、YML 始终经防抖后交给通用解析器判断。普通文本仍保留快速过滤，代码围栏示例不会生成播放器。 |

解析器和数据格式保持原样；接口沿用现有格式错误提示。错误不会触发自动循环重试，后续修改、保存及重新进入编辑继续按当前草稿刷新。

## 浏览器实测

独立临时 JSON 文档使用转义的 `s\u0072c` 字段引用合成 SVG。进入编辑后图片自动显示，自然尺寸为 64 × 48；改成 `{` 后草稿仍可编辑、显示未保存，原图片保持。服务端统计确认对应预览返回一次 HTTP 400。改成合法纯文字对象后预览隐藏，再恢复有效引用、修改正文、保存并重载，文字和图片仍在。

独立核对保存的正文、BOM/CRLF、素材摘要、唯一登记和索引引用，作品校验通过。重载后的额外图片尺寸读取因定位器超时未完成；重载结果以页面正文和图片节点为据，不声称完成重载后的解码测量。首次独立摘要检查使用了错误的登记字段，改为 `content.sha256` 后通过。详见[浏览器记录](test-results/media-preview-parsing-2026-09-24/browser.json)。

真实浏览器覆盖 JSON 和 SVG；YAML/YML、音频控件身份与暂停行为由控制器和 HTTP 测试覆盖，不作为真实音频播放证据。测试页、服务、作品及 5 份中断遗留夹具已清理，日常作品与备份未读写。
