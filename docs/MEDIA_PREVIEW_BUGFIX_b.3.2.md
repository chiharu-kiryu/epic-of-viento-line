# 素材预览与编辑切换修复 · b.3.2 工作树

2026-09-23。继续沿 F15、F16、F17、F18、F21、F30 检查读取原文、素材预览、模板切换、退出编辑及保存，保留上一轮 N64–N65 的修改。基线为 b.3.2 发布提交 `ca8a8d8`。

## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N66 | 开始编辑时先刷新预览，再填入最新原文。之前显示的内容不带媒体时，新读到的音视频不会自动出现，必须再输入或切换编辑方式。 | 最新原文和编辑基线就绪后重新安排预览，不需要额外输入，不把文档标记为未保存。 |
| N67 | 切回浏览模式会隐藏编辑器，但重置编辑状态时没有通知素材控制器，隐藏的音视频仍可继续播放。 | 编辑状态重置同步更新素材预览，暂停音视频、隐藏预览并使旧请求失效。 |
| N68 | 模式切换的清理逻辑只在项目已有文档时执行。空项目的第一份新建草稿确认退出后，仍残留新建、编辑及未保存状态，正文区域也未恢复。 | 空项目同样执行退出清理并恢复空项目提示；取消丢弃确认则完整保留草稿及播放状态。 |
| N69 | 预览在编辑器忙碌时提前返回，切换模板等待新正文期间，旧播放器没有及时清除；只比较路径也遗漏了类型变化。 | 等待模板时先核对路径和文档类型，再决定是否请求预览。上下文改变立即清除、暂停旧播放器，旧响应不能重新显示。 |

同一份草稿在源码、区块之间切换及保存时，如果媒体没有变化，继续使用现有播放器。测试同时核对 BOM、CRLF 和媒体引用原文，确认保存内容没有被预览改写。

## 验证

- 新增 **8 个执行场景**：新读原文自动预览；已有文档和首份草稿退出；不同路径及相同路径的类型切换；空项目取消与确认退出；源码/区块切换及保存；删除媒体、退出重进后的迟到响应。
- 在临时源码副本中，用当前测试对照 b.3.2 的原始两个控制器：**6 个场景复现失败、2 个兼容场景通过**；13 个既有场景因名称筛选未运行。临时副本已删除。
- 编辑弹窗、编辑器、媒体、导出及请求生命周期五组专项：**97 项，96 通过、0 失败、1 跳过**。
