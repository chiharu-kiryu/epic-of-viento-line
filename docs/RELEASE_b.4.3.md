# b.4.3 发布记录

2026-09-24。本版由 b.4.2 更新为 **b.4.3**，内部安装版本 **0.4.3**；下一版为 b.4.4。收录第四十三至四十五轮 **N114–N120** 修复，共新增 32 个执行场景。

## 本次修复

- 编辑 JSON / YAML 时，临时语法错误保留上一次有效的素材预览；合法删除引用才清空预览。转义字段名也能正确识别素材。
- 素材预览与正文使用相同的说明规则，保留 `alt`、用户嵌套字段中的素材及 YAML 别名的每次引用；递归引用仍受保护，保留 100 项预览上限。
- 顶层列表和字符串在阅读、模板预览中使用通用渲染，图片等素材正常展示。空对象 `{}` 和空列表 `[]` 在阅读和导出中明确显示。

详情见[结构化预览解析](MEDIA_PREVIEW_PARSING_BUGFIX_b.4.2.md)、[素材预览内容一致性](MEDIA_PREVIEW_CONTENT_BUGFIX_b.4.2.md)、[结构化值展示](STRUCTURED_VALUES_BUGFIX_b.4.2.md)。这些报告保留排查时的 b.4.2 标记及原始验证结果。

版本清单、锁文件、编辑器和作品库版本显示已同步；[功能链路图](FUNCTION_NETWORK.md)更新为修订 63。项目结构、元数据、素材引用和迁移包格式继续兼容，正文保持原有字节与换行。
