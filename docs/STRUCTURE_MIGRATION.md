## 首次整理时的交付

本机 `dist/current/` 集中保存：

- `Viento-Studio_0.2.0_amd64.AppImage`：Linux x86_64 便携程序，内置 Node.js 和转换器，不包含作品数据。
- `epic-of-viento-line.viento.zip`：唯一保留的当前完整作品备份，约 3.16 GB。
- `Viento-Studio_0.2.0_source.tar.gz`：包含当前未提交代码的程序源码归档及逐文件哈希清单，不重复打包作品或构建缓存。
- `SHA256SUMS`、`verification.json` 和 `README.md`：传输校验、恢复验证结果及使用说明。

复制整个交付目录即可携带当前程序、作品和可重新构建的源码；更新程序时只需替换应用。该目录不纳入 Git，复制和备份时应显式包含；同一磁盘上的迁移包提供恢复入口，迁到其他设备时应复制这份已经校验的包。

## 删除的旧文件与回查

旧的 `working-tree.tar`（3,372,912,640 字节）在新整库包恢复验证和当前源码归档校验通过后删除。旧 0.1.0 AppImage/deb、旧文档及网页缓存、旧测试截图、已取代的桌面化前代码副本也已删除。遗留的 AppImage/deb 测试解包目录已经清除；原生测试改为管理自己的临时解包目录，测试结束自动清理，不再依赖可能被 WebDriver 中断的 AppImage 外层进程执行删除。

早期清理暂存的 5,201 个 AppleDouble 旁车文件已检查：资源分支全部是相同的空白占位内容；这些旁车副本已删除。唯一与正文不同的旧浏览器草稿仍保留在原来的小型草稿备份目录，未作为重复文件删除。

迁移前的原路径、大小、SHA-256 及目录映射继续保存在本机 `/home/chiharukiryu/.codex/backups/project-layout-20260909-111617/` 的小型 JSON 记录中，便于回查原始内容。该目录不再存放大容量数据快照。Git 历史及既有未提交工作保留，本轮未提交或重置。
