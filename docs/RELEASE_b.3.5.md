# b.3.5 发布记录

2026-09-23。本补丁收录第二十一、二十二轮功能链路检查中的 **N76–N80 共 5 处修复**，版本由 b.3.4 更新为 **b.3.5**，内部安装版本为 **0.3.5**。

## 本次修复

- 取消读取、切换文档或返回浏览后，迟到的原文响应不再回退正文缓存和版本，也不会重新填入已经退出的编辑区。
- 旧读取的失败不再误报到当前窗口；当前请求的读取错误仍正常提示，并可恢复后重试，包括合法空文件。
- 索引替换条目后，旧读取不能错误进入编辑或覆盖冲突草稿；重新读取当前条目成功后才更新正文和编辑基线。
- 编辑中的目录条目改指另一份源文件时，拒绝用新路径接管旧草稿。不完整的新目录不会移走正在编辑的对象，保留当前列表、配置、草稿与版本并提示重试。
- 重建和新文件首次获得目录标识时，保留已读取或已保存的完整正文与版本；保存期间的并行刷新同样受保护。源码和区块草稿仍保持未保存状态，明确放弃后恢复原基线。

功能图更新为修订 31，保留此前二十二轮复现和验证证据。详细记录见 [原文读取与失效响应修复](SOURCE_LOADING_BUGFIX_b.3.4.md) 和 [保存与目录刷新修复](EDITOR_INDEX_REFRESH_BUGFIX_b.3.4.md)，两份报告保留排查时的 b.3.4 标记。

正文、文档与素材 ID、归属关系及迁移包格式保持兼容，无需手工迁移作品。版本编号继续遵循 [既定进位规则](RELEASE_b.2.9.md#版本规则)。
