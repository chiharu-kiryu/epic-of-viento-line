## 缓存兼容与数据边界

新缓存为 `<标准缓存根>/.entries/<相对源路径的 SHA-256>.json`。哈希只表示缓存地址，不替代元数据中的文档 ID，也不依赖作品所在磁盘位置。缓存保留 `source.path`、原文、解析结果和布局；编辑接口仍读写原始正文。

统一缓存读取器兼容旧镜像目录与新格式混合存在。局部重建成功写入所选记录后，按记录的源路径清理旧副本，不重新解析或改写范围外缓存；完整重建最终清理旧副本。源文件删除后，精确指定该源路径也能清理对应的损坏新缓存。新缓存入口目录是链接时，构建与索引读取均拒绝，保留原索引及链接目标；缓存写入也逐层检查目标路径。

实际更新发生在下一次正常重建，本次验证仅针对临时作品。权威正文、模板、元数据、素材及迁移包格式没有改变；缓存仍不进入完整备份。超过文件系统或接口已有路径限制的名称仍会拒绝，不保证任意长度的路径都可保存。
