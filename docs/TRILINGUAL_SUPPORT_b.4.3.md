# 中英日翻译强化与验证

2026-09-24，基于 `38c7f61d` 的 b.4.3 工作区。本轮新增日语并补齐翻译链路，版本号保持 b.4.3；未提交、推送或替换日常安装程序。

## 完成的行为

- 设置提供简体中文、English、日本語。英文和日文词典各 531 条，覆盖作品库、编辑器、类型模板、素材、保存、导出和状态提示；原生窗口标题、文件选择和关闭确认同步支持日语。
- 语言选择保留在本机配置，作品库和编辑器同步；应用完整重启后仍保留。切换不重建源码或分段编辑器，不改变草稿、选区、筛选、文件路径和作者定义的字段。
- 文档分享包按开始导出时的语言生成目录、关联素材标题、音视频下载按钮、页脚和解压说明。并发中英日导出互不串语言，生成中途切换界面不改变已开始的导出。原始正文、元数据与素材按字节保留，完整项目包不携带本机语言偏好。
- 新建作品库时，未改动的默认名称跟随语言；用户已经输入的名称保持不变。模板格式中的纯文本选项接入翻译。
- 修正英文词典的重复条目、字符统计和下载状态措辞；未知消息不再误读对象原型属性。公共语言列表供界面与接口共同校验，格式化函数无共享语言状态。
- 新增词典与源码覆盖检查，检查漏译、重复条目、空译文、参数和原生语言枚举。Acorn 仅为开发依赖，已确认不进入桌面运行资源。
