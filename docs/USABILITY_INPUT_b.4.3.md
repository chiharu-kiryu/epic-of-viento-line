# 多语言编辑的实际使用优化

2026-09-24，接续中英日翻译强化，基于 `38c7f61d` 的 b.4.3 工作区。版本保持不变；本轮未提交、推送或替换日常安装程序。

## 修复和改进

- 输入法确认候选字时，正文保存、文件名回车创建、模板保存和冲突数字快捷键均保持等待。按住快捷键不再重复提交或继续推进冲突操作。
- 编辑期间的 `Ctrl/Cmd+S` 覆盖正文、文件名、目录搜索框与工具栏焦点；`Ctrl/Cmd+Enter` 只作用于源码和分段正文。设置、素材、导出等弹窗隔离底层文档保存，类型模板窗口只处理自己的保存。
- 搜索保留已确认的查询，组词过程中暂停筛选；确认或取消组词后恢复待执行的搜索。
- 窄窗口的顶部和编辑工具栏允许换行。375 像素宽、日语界面此前扩展到 458 像素，浏览、编辑和刷新预览按钮被挤到屏幕外；调整后三语均无横向溢出。
- 阅读区按内容高度分配行高。375 像素窗口中，封面实际高 311 像素，旧布局只保留 150 像素，遮住后面的文件信息和正文；修复后行高为 311 像素，下一区域与封面保持 10 像素间距，内容可正常滚动。
- 切换语言后，可编辑文件位置继续显示原始文件路径；封面分类提示和图片替代文字同步翻译。原图节点、作者名称、正文与自定义类型标签保持原样。英文和日文词典现各 535 条。

输入法兼容判断同时使用 `isComposing` 与 `keyCode === 229`，处理确认键与组词结束事件次序的差异，依据 [MDN 的 IME 键盘事件说明](https://developer.mozilla.org/en-US/docs/Web/API/Element/keydown_event#keydown_events_with_ime)。

| 验证 | 结果 |
| --- | --- |

| 键盘、弹窗、语言、图片及词典针对性测试 | 73 通过，0 失败 |
| 程序全量检查 | 558 通过，0 失败，2 跳过；150 个脚本语法与 API 契约检查通过 |
| 日语新建 → 文件名中 Ctrl+S | 创建预期文件且继续编辑，保存内容逐字节一致 |
| 日语搜索 → 英语切换 → 分段编辑 → Ctrl+Enter | 查询找到文档，切换语言保留未保存草稿，分段保存与索引刷新成功 |
| 设置弹窗中 Ctrl+S | 未写入底层文档，关闭弹窗后草稿仍为未保存 |
| 英文分享包生成 | 页面显示可下载；检查生成的 ZIP，网页 `lang=en`、说明为英文、原始正文逐字节一致 |

| 浏览器运行日志 | 测试完成时无 warning / error |

浏览器实测使用独立临时 v3 项目，已有两篇中日文文档，另新建一篇键盘测试文档；检查前两篇原文未变。已目视检查窄屏搜索、编辑、阅读及导出界面。关闭导出窗口后，临时分享包已自动释放。

输入法状态由控制器回归测试覆盖，本轮未操作系统输入法候选窗；macOS 的 Command 保存由回归测试验证。本轮没有重建 Tauri，两个依赖 `VIENTO_TEST_ARCHIVE_BINARY` 的原生归档测试因此跳过；上轮独立的原生测试证据仍保存在[翻译验证记录](TRILINGUAL_SUPPORT_b.4.3.md)，不计入本轮通过数。未实测 Windows / macOS 桌面窗口。
