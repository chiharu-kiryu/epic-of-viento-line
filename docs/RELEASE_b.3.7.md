# b.3.7 发布记录

2026-09-23。本补丁收录第二十六至二十八轮功能链路检查中的 **N88–N93 共 6 处修复**，版本由 b.3.6 更新为 **b.3.7**，内部安装版本为 **0.3.7**。

## 本次修复

- 项目设置读取期间发生外部修改时，表单与版本标记来自同一份清单。旧表单保存会正确提示冲突，避免覆盖外部更新的类型名称和解析规则。
- 模板名称含 `#`、`%` 或字面的百分号转义文本时，新建文档准确读取配置中的文件，不再请求失败或误读相近文件。
- 网络读取模板时保留 UTF-8 BOM；Markdown、TXT、JSON、YAML、YML 的新建、保存和原文重开继续保留编码标记与原始换行。
- 封面、旧技能图及其占位图统一使用图片地址解析和回退函数，与列表缩略图、图库一致，特殊文件名不再导致读错文件或缺图。
- 允许素材文件名和目录名内部出现连续点，例如 `原画..定稿.png`；完整的父目录跳转路径仍被拒绝。
- 通用文档封面缺失、且没有旧英雄占位路径时，正确显示名称头像；候选图片耗尽后停止重试。

功能图更新为修订 39，保留二十八轮复现与验证证据。详细记录见 [项目设置读取与冲突](PROJECT_SNAPSHOT_BUGFIX_b.3.6.md)、[模板网络读取](TEMPLATE_HTTP_BUGFIX_b.3.6.md) 和 [图片显示与缺图回退](IMAGE_DISPLAY_BUGFIX_b.3.6.md)，三份报告保留排查时的 b.3.6 标记。

正文、元数据、素材和迁移包格式保持兼容，无需手工迁移作品。版本编号继续遵循 [既定进位规则](RELEASE_b.2.9.md#版本规则)。
