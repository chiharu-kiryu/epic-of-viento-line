# 素材说明、嵌套字段与重复引用 · b.4.2 工作树

2026-09-24，第四十四轮继续检查 F13、F18、F29、F30、F32，核对草稿预览与正文阅读、引用索引和导出的内容是否一致。基于 b.4.2 发布提交 `03265ba0` 及上一轮 N114–N115 工作树，保留之前的修复。

## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N116 | 草稿预览提取素材时丢弃 `alt`。正文和导出有说明，编辑预览却没有图片说明、音视频名称；只修改 `alt` 也不会更新预览。 | 按正文渲染的 `caption → alt` 规则提取有效说明；预览标题、图片替代文本、音视频可访问名称和下载名称一致，已有 `caption` 保持优先。 |
| N117 | 递归提取器把任意 `type: code` 对象当作代码示例，遗漏通用字段中嵌套的图片、音视频和行内引用。 | 只过滤解析器生成的顶层代码块；自定义字段里的 `type` 作为用户数据处理，插入新素材时也保留原有引用。 |
| N118 | 全局访问去重使 YAML 别名复用只显示第一次；同一组素材出现在三个位置时，预览缺少后两处。 | 只阻止当前递归路径上的循环，按正文顺序保留每次复用。循环引用仍能结束，预览上限仍为 100 项；索引和导出素材文件继续按身份去重。 |

修复集中在预览提取器，原始正文、解析器布局和素材登记格式不变。有效说明相同时，编辑器仍保留原有播放器。
