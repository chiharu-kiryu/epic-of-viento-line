# 导出作品

点击编辑器右上角的 **导出**。阅读模式、编辑模式和空白项目均可打开；导出使用已保存内容，有草稿时先保存再导出。

## 文档分享

- **离线网页**：生成 ZIP，解压整个文件夹后打开 `index.html`。可以阅读任意类型的档案、查看图片、播放视频和音频；播放器带原文件下载入口，不自动播放。网页也提供适合打印的样式。
- **Markdown**：生成 ZIP，解压后打开 `document.md`。图片使用相对路径，视频和音频提供原文件链接，便于继续编辑或交给其他工具。
- 默认包含通过 `part-of` 归属当前档案的所有附属内容，例如角色背景故事及其经历片段；可以取消勾选。
- 分享包携带实际引用及明确绑定的素材，包含外置素材；不复制项目中无关的素材。`sources/` 保留原始正文的准确字节，`metadata/` 保留所选文档与素材的登记，`manifest.json` 记录对应关系及每个文件的大小、SHA-256。
- 正文展示沿用编辑器的通用解析布局，支持文本、Markdown、JSON、YAML、自定义字段、列表、表格和代码区块。音视频保留原始编码，播放支持取决于阅读软件。

附属故事的章节标题随所属文档整体下移，保留原有层级差异（最高为六级标题）。素材路径按实际文件名编码：`take one.wav` 与 `take%20one.wav` 是两个不同文件，分享包保留各自的 UUID、登记和准确内容；改名后的旧路径仍可按登记解析。

分享包用于阅读和交换文档。恢复项目请使用完整项目包。

## 完整项目包

生成与作品库“导出备份”兼容的 `.viento.zip`，可在作品库中选择 **导入迁移包** 恢复到新目录。

包含 `workspace.json`、正文、模板、全部元数据与全部素材；外置素材打包到包内的 `assets/`。新项目保持 v3 通用目录，旧项目保持原有目录和版本；正文和元数据均不改写。

排除缓存、会话锁、导出临时文件、本机素材路径绑定及程序本体。兼容标记 `.viento/workspace.json` 按项目版本保留。素材或已登记正文缺失、素材校验不一致、文件名无法跨系统迁移，或者导出期间源文件发生变化时，会报告原因并停止生成。

作品库原生备份和导入也会核对登记指向的正文、素材绑定及已有素材指纹，包内文件的校验和正确并不能代替登记一致性。失败时保留原备份或撤销本次恢复目录。路径检查覆盖每层目录、文件与目录冲突，以及大小写和 Unicode 等价写法；只报告冲突，不自动改名或合并文件。

原生归档同时按编辑器的规则检查文档类型、解析方式、关系目标、重复关系及循环归属，以及素材名称、类别、标签和旧路径别名。不同素材的旧路径与当前位置不能冲突；同一素材的重复别名继续兼容。共享背景、一般引用关系、旧登记中省略的可选字段及未知素材指纹保留原样。损坏登记在正式替换备份或保留恢复目录之前报错，修正后可以重试。

原生备份在写入前固定文件快照和素材根，打开文件及发布前再次检查，同时核对项目清单和本机素材绑定。Unix 平台另核对文件身份与状态变更时间，避免同大小、保留修改时间的文件替换漏检。

## 保存和临时空间

- 桌面版显示系统保存窗口；取消后可以重新选择。打开窗口前先持有准备好的文件，等待期间即使缓存过期，当前保存仍可完成，不额外复制一份临时包。文件先完整写入并复核，再替换选定的目标，失败不会留下半个正式导出包。
- 取消后再保存，如果原任务已经过期，窗口会显示提示并恢复“开始导出”，可以在原窗口重新生成；普通保存位置错误仍保留原包，方便重选位置。覆盖已有文件时，取消系统确认会保留旧文件。
- 保存请求断线后重试同一份包，旧窗口的迟到结果不会结束新一次保存等待，也不会提前释放导出包。
- 浏览器版准备完成后点击 **下载文件**，由浏览器管理下载位置。
- 准备导出时可取消，不会改动原始正文或素材。
- 临时包只保存在作品的 `.viento/cache/exports/`。桌面保存完成或未下载就关闭窗口时释放；活动下载结束后才删除文件。浏览器导出任务默认空闲 15 分钟过期，额度满时可回收已完整下载的空闲包；未完成或中断的下载保留重试机会。进程意外退出的旧包在后续导出时清理。
- 临时文件暂时无法删除时，服务保留待清理记录并每 30 秒重试；清理成功后才让出导出名额。清理故障不会改变已经完成的下载，也不会覆盖原本的取消或失败原因。

## 实现与验证

本轮真实 Linux 保存窗口、过期、取消、覆盖和重试的结果见[编辑器导出实测](NATIVE_EXPORT_TEST_b.2.8.1.md)。

`export-package.mjs` 负责选择正文、解析归属、收集素材和流式生成 ZIP；`export-render.mjs` 从通用布局生成网页或 Markdown；`export-service.mjs` 管理任务与临时空间。`/api/export` 提供准备、下载和释放接口，编辑服务与只读服务均可使用，准备操作沿用接口令牌规则。桌面保存通过会话校验后交给原生文件选择器。

导出不会把整个视频或完整项目读入内存。项目包遵循既有迁移格式、大小限制和文件校验，回归测试覆盖归属内容、结构化字段、素材缺失、路径边界、变化检测、下载以及清理；原生流程测试覆盖保存窗口取消重试及恢复后的逐文件一致性。

[导出清理回归](EXPORT_CLEANUP_BUGFIX_b.3.8.md)补充文件暂时被占用时的主动释放、并发释放、自动过期、取消和额度回收；真实 HTTP 下载与临时作品的原始字节均核对，失败注入仅作用于临时路径。

[桌面保存交接回归](EXPORT_BRIDGE_BUGFIX_b.3.8.md)补充独立保存请求、旧结果隔离、断线重试和回执早于 HTTP 确认的情况；桌面桥校验请求标识，宿主成功、取消与失败结果均回传对应标识。

[归档互通回归](../scripts/tests/export.test.mjs)与[原生登记一致性回归](../scripts/tests/archive-registry.test.mjs)可通过 `VIENTO_TEST_ARCHIVE_BINARY=/完整路径/workspace-archive npm run check -- --app-only` 启用。它们使用编译后的原生归档命令，验证 Node 导出 → Rust 导入/导出 → Node 再导出，逐文件比较 v2/v3 的正文、登记、UUID 和外置图片/视频/音频，并检查缓存与本机绑定未进入包。还独立构造校验和正确但登记损坏的包，验证两端拒绝规则、旧备份保护、恢复目录清理及修正后重试。未提供该二进制时跳过这两组原生归档检查，普通应用测试继续运行。
