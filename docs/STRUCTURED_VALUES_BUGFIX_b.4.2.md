独立临时 JSON 列表包含 `0`、`false`、`null`、`{}`、`[]`、嵌套图片及行内图片。阅读页按顺序显示全部值，两张图片均加载为 64 × 48；进入编辑时预览相同。修改一个字段、保存、返回阅读、重载并重新选择该文档后，修改内容、空容器和两张图片仍完整，图片自然尺寸再次核对通过。另一个顶层空对象文档明确显示 `{}`。

独立核对两份源文件、BOM/CRLF、唯一素材的摘要与登记、引用索引及作品校验。两种格式的导出计划均保留空容器和两次图片出现，只携带一份素材。
