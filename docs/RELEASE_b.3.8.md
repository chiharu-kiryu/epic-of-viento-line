# b.3.8 发布记录

2026-09-23。本补丁收录第二十九至三十一轮功能链路检查中的 **N94–N100 共 7 处修复**，版本由 b.3.7 更新为 **b.3.8**，内部安装版本为 **0.3.8**。

## 本次修复

- 已经迁移过的背景故事也能通过明确映射修正归属，保留其他关系、归属名称和备注。普通重跑保持原有关系与字段顺序，避免无变化的元数据被重写。
- 文档归属迁移共用登记锁和路径保护，私有目录、日志目录或锁文件是链接时，在写入前拒绝，保留原描述与链接目标。
- 文档迁移和采用项目定义分别创建独立恢复日志。同一毫秒内的连续操作不再覆盖旧记录，也不会因日志重名而使失败后的立即重试报错。
- 没有独立模板文件的类型也会校验自动生成正文、默认目录和解析规则，避免导入后无法新建文档。旧配置仍可打开并修正。
- 原生备份和导入按编辑器约定检查文档类型、解析方式、关系目标、重复关系及循环归属，防止导入成功后项目却无法读取；合法共享背景和旧可选字段保持兼容。
- 原生归档补齐素材字段与旧路径别名校验，拒绝跨素材的大小写及 Unicode 等价冲突。失败保留原备份、清理本次恢复目录，修正登记后可重试。

功能图更新为修订 43，保留三十一轮复现与验证证据。详细记录见 [文档归属迁移](DOCUMENT_MIGRATION_BUGFIX_b.3.7.md)、[项目定义与模板校验](PROJECT_DEFINITION_BUGFIX_b.3.7.md)和[原生归档登记一致性](ARCHIVE_REGISTRY_BUGFIX_b.3.7.md)，报告保留排查时的 b.3.7 标记。

正文、元数据、素材及迁移包格式保持兼容。版本编号继续遵循[既定进位规则](RELEASE_b.2.9.md#版本规则)。
