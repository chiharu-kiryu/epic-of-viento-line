# b.4.2 发布记录

2026-09-24。本版由 b.4.1 更新为 **b.4.2**，内部安装版本 **0.4.2**；下一版为 b.4.3。收录第四十至四十二轮 **N111–N113** 修复，共新增 35 个执行场景。

## 本次修复

- 批量导入部分失败或取消后，已成功入库的素材立即显示在列表中，可直接重新选择。恢复不再等待另一次列表读取，也不会被旧搜索、类型或分页遮住。
- 图片、音频和视频读取失败后提供“重试加载”，只重新读取选中的资源；加载成功后清除旧错误，保留草稿、其他播放器及素材引用。
- 输入、保存、切换路径或退出编辑时取消过期预览请求，避免旧请求一直占用连接。新预览、主动上传和插入各自独立，迟到结果不能覆盖当前状态。

详情见[部分导入恢复](MEDIA_RECOVERY_BUGFIX_b.4.1.md)、[素材读取恢复](MEDIA_LOADING_BUGFIX_b.4.1.md)、[预览请求取消](MEDIA_PREVIEW_REQUESTS_BUGFIX_b.4.1.md)。这些报告保留排查时的 b.4.1 标记及原始验证结果。

版本清单、锁文件、编辑器和作品库版本显示已同步；[功能链路图](FUNCTION_NETWORK.md)更新为修订 59。项目目录、元数据、素材引用及迁移包格式继续兼容。

## 验证

- 发布应用检查 **554 项全部通过，零失败、零跳过**，包含实际 Node/Rust 归档往返及登记一致性检查；141 份 JavaScript 语法、版本及 API 契约检查通过。
- 重新编译生产归档模块和官方 CLI，Rust 测试 **13 通过、0 失败、1 忽略**；忽略项需要真实大体积作品。61 份依赖的版本与校验和匹配项目锁文件。
- 保留此前完整 Tauri 库 **22 通过、1 忽略**的结果，并重新核对相关源码指纹；本轮没有重编完整宿主或测试原生窗口。
- 三轮开发阶段均使用真实浏览器：混合文件上传后复用并保存；SVG/WAV/WebM 缺失后重试恢复；故障代理下取消旧预览并保存重开。相关记录与源码指纹核对通过，发布阶段未重复这些浏览器操作。播放、拖动进度和实际外置设备重连未验证；取消读取不保证中断服务端同步解析。
- 核验离线锁定的 Cargo 依赖解析、121 份 glib 修复副本文件，以及源码归档 704 份文件的逐文件字节、可执行权限和解包后的依赖解析。临时编译目录和验证包完成后清理。

完整证据见[发布验证记录](test-results/release-b.4.2/results.json)。发布检查使用应用自带 Node v24.19.0，正常退出；此前系统 Node 18 工作进程不退出的观察和测试夹具纠正记录继续保留。测试仅使用临时作品，日常正文、素材和备份未修改。

本次提交和推送源码版本，未构建或替换桌面发行包；已安装程序须安装后续包含本版的构建，才会应用这些修复。
