## 补齐的操作

- **真实播放**：WAV、MP3、Ogg、Opus、FLAC、M4A、AAC，以及 WebM / VP8、MP4 / H.264 完成实际解码、播放进度推进、暂停和跳至 1.5 秒。继续覆盖无自动播放、筛选、复用、粘贴、拖入、保存重开及稳定素材 ID。
- **编辑与布局**：角色自己的背景故事和下级片段可进入、保存、搜索和返回；物品属性分开显示，数值 0 保留。源码与分段切换、未保存保护、类型新增取消 / Escape / 返回、760×600 窗口中的操作按钮均验证通过。
- **类型和语言**：修改项目自己的 YAML 模板、预览、保存、新增类型、自选目录创建文档和重开；中英文切换与重启记忆、作品库和编辑器同步均保留草稿和路径。
- **导出与恢复**：真实 GTK 保存窗口取消后重试，两种编辑器导出均完成；完整项目导入后逐文件核对大小、SHA-256、正文、模板、元数据及素材。损坏包回滚、非法目标报错、重试和最近记录保持正确。
- **作品库保护与退出**：编辑会话存在时阻止会改变项目的入口；返回 / 继续编辑保留草稿；中英文关闭确认、取消关闭、确认丢弃和引擎停止均通过。
- **功能图交互**：在本机 HTTP 打开自包含 HTML，核对 50 条链路、66 个节点、150 个模块；筛选 F30、查看节点上下游、模块循环依赖、空搜索结果、接口行搜索、11 个原生命令、7 个维护命令及刷新后的定位。浏览器控制台没有错误或警告。工具清空输入和标题定位的两次操作纠正另行记录，不作为产品故障。
