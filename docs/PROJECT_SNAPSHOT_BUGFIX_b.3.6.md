## N88：旧表单带上新配置的版本标记

服务原先先读取并解析项目清单，再异步读取同一个文件计算版本标记。如果清单在两次读取之间被另一处修改，响应中的类型名称和解析规则仍来自旧清单，版本标记却属于新清单。用户保存这份旧表单时，冲突校验可以通过，使外部更新的名称或规则被旧值覆盖。

现在从生成当前响应所用的同一份清单对象计算版本标记，并继续计入实际读取的模板内容。旧内容只会携带旧标记，重新保存时返回 409；用户重新读取后可以正常编辑。清单仅调整 JSON 缩进或空白、不改变配置值时，不再因此改变版本标记。
