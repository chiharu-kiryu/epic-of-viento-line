# b.3.1 发布记录

2026-09-23。本补丁收录第十三、十四轮功能链路检查中的 **N50–N58 共 9 处修复**，发布版本由 b.3.0 更新为 **b.3.1**，内部安装版本为 **0.3.1**。

## 本次修复

- 素材目录绑定与登记使用同一把写锁，保留其他本机配置，拒绝通过链接写到作品外；核验会检查真实文件及路径边界，并允许 `..portrait.png` 等合法名称。
- 上传过程中素材目录发生切换时，拒绝提交到旧位置，清理临时内容并显示可翻译的重试提示。
- 合法的长文件名可以正常新建与保存；短临时名称保留独占创建、保存冲突判断、文件权限和原始正文格式。
- 标准缓存改用完整相对源路径的固定长度哈希，解决长名称及文件/目录命名冲突；支持旧缓存读取、局部迁移和过期记录清理。
- 受管理作品从正文根扫描，`assets`、`templates`、`tmp` 等普通正文子目录中的文档可以正常进入预览，隐藏目录和 `node_modules` 仍排除。
- 功能图更新到修订 19，保留前十四轮复现记录、源码指纹及此前 glib 安全修复。

触发条件和逐项验证见 [素材绑定修复记录](ASSET_BINDING_BUGFIX_b.3.0.md) 与 [新建、保存及预览修复记录](CREATION_WORKFLOW_BUGFIX_b.3.0.md)。两份排查报告保留当时的 b.3.0 版本标记。

正文、模板、登记、素材及完整迁移包格式保持兼容；缓存会在正常重建时更新，不需要手工迁移作品。版本编号继续遵循 [既定进位规则](RELEASE_b.2.9.md#版本规则)。
