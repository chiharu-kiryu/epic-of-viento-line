# b.3.9 发布记录

2026-09-23。本补丁收录第三十二、三十三轮功能链路检查中的 **N101–N103 共 3 处修复**，版本由 b.3.8 更新为 **b.3.9**，内部安装版本为 **0.3.9**。

## 本次修复

- 导出临时包删除失败时，保留待清理记录和名额，服务运行期间每 30 秒自动重试；主动重试必须实际删除成功，并发释放等待同一次结果。取消和生成失败也使用相同清理机制，活动下载结束后才删除文件。
- 清理异常不再把成功下载算作失败，也不会覆盖原本的下载中断、取消或生成错误。尚未领取的包和正在下载的文件继续受保护，故障期间不会通过提前释放名额不断积累临时包。
- 桌面保存每次使用独立请求标识，界面、处理服务和宿主同步传递。同一 ZIP 断线后重试时，旧保存窗口的成功、取消或错误不会提前结束新等待，也不会释放当前导出包。当前回执先于 HTTP 确认到达时仍正常处理。

功能图更新为修订 46，保留三十三轮复现与验证证据。详细记录见 [导出清理与失败恢复](EXPORT_CLEANUP_BUGFIX_b.3.8.md)和[桌面保存回执与重试](EXPORT_BRIDGE_BUGFIX_b.3.8.md)，报告保留排查时的 b.3.8 标记。

正文、元数据、素材及迁移包格式保持兼容。桌面界面、服务和宿主的私有保存协议同步更新。版本编号继续遵循[既定进位规则](RELEASE_b.2.9.md#版本规则)，b.3.9 的下一版为 b.4.0。

## 验证

发布阶段重新编译生产归档模块和官方 CLI，Rust 归档测试 **13 通过、0 失败、1 忽略**；忽略项需要真实大体积作品。61 份解析后的依赖版本与校验和均匹配项目锁文件。桌面保存修复在升版前已通过实际 Tauri 库编译和 **22 项库测试**，另 1 项真实作品测试忽略；发布时核对相关源码指纹，保留该轮证据，未重复编译完整宿主。原生窗口、媒体解码和独立集成测试未重跑，未构建或安装桌面发行包。
