## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N94 | 已有 `relations` 字段的记录直接跳过明确传入的归属映射；第一次迁移生成空关系后，补充映射也不生效。完整描述还会因默认字段被移到前面而无故重写。 | 明确映射只更新对应文档的 `part-of`，保留其他关系、仍保留的归属名称与备注。默认执行不改已有关系，填充默认值不重排完整描述；重复执行无变化。循环、未知目标继续在写入前拒绝。 |
| N95 | 迁移单独获取登记锁，未使用共享路径检查；`.viento`、迁移日志目录或锁文件为链接时仍可继续，可能向链接目标写入日志或替换链接锁。 | 使用共享登记锁及日志路径检查，在写入描述前拒绝作品内部的链接路径，保留目标内容、原描述和锁链接。 |
| N96 | 日志名称只有毫秒时间戳，同一毫秒内两次迁移会覆盖第一份恢复记录。 | 日志名称增加独立 UUID，并以禁止覆盖的方式创建，保留每次操作的前后描述。 |
