## 对数据和兼容性的影响

正文、文档 UUID、素材元数据和 `part-of` 关系继续保留。修复没有搬动实际作品，也没有对真实正文执行批量转换。

缓存命名现在是 `documents/规则.md.json`、`documents/规则.txt.json`、`documents/规则.json.json` 等。它们位于作品的 `.viento/cache/docs-standard/`；旧项目的实际缓存根沿用原来的路径。重建先写新缓存，再按源范围删除过期缓存。完整重建迁移全部派生文件，局部重建只处理选定范围，不要求手动删除缓存。

文档索引的 `source.path` 仍指向原始正文。旧的无歧义展示路径继续保留；发生同名歧义时才使用稳定标识，并重建上级、子文档链接。重复缓存指向同一个源文档时仍报错，防止掩盖损坏的索引。

完整迁移包继续排除缓存和本机配置，文档分享包继续携带原始正文及引用素材。导出格式和 Rust 导入契约没有改变。
