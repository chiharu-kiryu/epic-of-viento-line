# Android 项目包迁移（b.4.4 开发记录）

本轮接续 [Android 宿主](ANDROID_HOST_b.4.4.md)，接通作品库中的完整项目包导入、导出。版本保持 b.4.4 / 0.4.4；未提交、推送或替换已安装的桌面程序。

## 使用方式

在手机作品库选择“导入项目包”，通过系统文件选择器选取桌面导出的 Viento ZIP。作品通过完整性和移动端可读性检查后，才出现在列表中。每份作品右侧提供“导出项目包”，打包完成后选择保存位置。

包内保留已保存的正文、模板、项目类型、元数据、图片、视频和音频，以及原有作品和文档 UUID、故事归属和素材绑定。编辑草稿属于本机恢复数据，须先打开作品保存，再导出。移动端目前仍不能管理或预览包内素材。

同一作品 UUID 已在本机存在时拒绝重复导入，不自动覆盖或合并，也不重新分配文档身份。旧 v2 和通用 v3 格式均可迁移；v1 需先在桌面版升级。未登记的正文会明确报错，避免导入成功却看不到内容。

## 实现与中断处理

- 作品库仅发送导入/导出动作及作品 ID。系统选择的 `content://` 地址和临时绝对路径留在原生层。
- Kotlin 使用 Android 的 `ACTION_OPEN_DOCUMENT` / `ACTION_CREATE_DOCUMENT`。流式复制在后台线程执行；没有增加全盘存储权限，也没有向页面开放通用文件系统命令。
- Rust 复用桌面 `workspace.rs` 的 ZIP 清单、路径、SHA-256、登记一致性检查。导出先在私有缓存完成，再复制到所选位置。
- 导入先放在 `workspaces/.mobile-import/` 下的独立临时目录，全部检查通过后改名发布。失败时删除暂存目录，保留原包及已有作品；进程被终止后，下次启动清理未发布导入。
- 导入、导出共用原生操作锁；取消选择会恢复界面。传输临时 ZIP 在正常完成、取消、失败时清理，进程中断的遗留缓存在下次启动清理。
- 导出写入失败会尝试删除本次新建的目标文档；若文件提供器拒绝删除，界面提示用户清理不完整文件。进程被系统终止时，外部位置仍可能留下未完成文件，因此操作提示要求保持应用打开。

移动预览限制：ZIP 最大 1 GiB，展开后最大 4 GiB，最多 50,000 个归档条目；每份正文或元数据文件最大 1 MiB，正文合计和元数据合计分别最大 32 MiB，登记文档最多 20,000 份。归档清单最大 64 MiB。空间检查和流式复制会为本机保留一定余量；超过限制的作品可继续在桌面版使用。

系统选择器的设计依据：[Android 文件访问说明](https://developer.android.com/training/data-storage/shared/documents-files)；原生调用方式参考 [Tauri 移动插件接口](https://v2.tauri.app/develop/plugins/develop-mobile/)。

## 验证结果

| 验证 | 结果 |
| --- | --- |
| 最终程序检查 | 191 个 JavaScript 文件语法、接口契约通过；646 项测试通过，0 跳过 |
| Rust 原生测试 | 36 通过，1 项既有优化构建专项测试忽略 |
| v2 / v3 跨实现往返 | 桌面 JavaScript 打包 → 移动 Rust 导入 → 通用引擎索引 → 修改保存 → 移动导出 → 桌面 Rust 恢复通过 |
| 数据保留 | 正文 BOM / CRLF、稳定 ID、故事归属、模板、三类媒体和登记均保留；仅指定字段变化 |
| 异常路径 | 重复 UUID、损坏 ZIP、超限包/文本/元数据、无效 UTF-8、缺少登记均拒绝；原包及已有作品保留 |
| 中断导入 | 冷启动清理未发布目录，已有作品保持逐字节一致 |
| 390 × 844 浏览器联调 | 导入 → 角色字段 100 → 175 → 保存 → 导出通过；18 个归档文件经逐字节比对和摘要核验，仅该字段变化 |
| 界面状态 | 中英日切换；重复导入提示、损坏包日语提示、重试重新选择、取消后恢复可用；无浏览器错误或横向溢出 |
| Android 构建 | ARM64 调试 APK；签名校验通过；原生库与编译结果一致；DEX 含系统文件选择器桥接类；无广泛存储权限 |

首轮全量程序检查有一项既有桌面下载测试偶发失败（完整下载后申请下一份导出返回 409）。单独重跑 8 项下载测试通过，最终全量 646 项通过；本轮未修改桌面下载逻辑。失败和复测日志均保留，此偶发问题仍需后续跟踪，未作为已修复的问题报告。

浏览器测试替代了 Tauri IPC 传输和系统选择器，实际导入、编辑、导出使用同一份 Rust 存储代码及临时作品。**尚未真机测试**，不能证明 Android 系统选择器、第三方文件提供器、后台回收或外部文件残留清理在设备上的表现。

更新后的 APK 位于 `dist/android-preview/Viento-Studio_b.4.4_android-arm64-debug.apk`，约 51.23 MiB，最低 API 26、目标 API 36。调试签名仅供预览；未安装到设备。详细日志、APK 摘要及截图见 [验证记录](test-results/android-transfer-b.4.4/)。

构建后已清除本轮约 2.96 GB 的临时编译/测试目录，以及项目内的移动前端和 Gradle 生成文件。APK、源码包、Android 源工程和验证记录保留；共享 SDK/依赖缓存及用户作品不参与清理。

后续继续接入素材访问/插入、项目类型及模板配置，并安排真机上的文件授权、返回键、软键盘和进程回收验证。
