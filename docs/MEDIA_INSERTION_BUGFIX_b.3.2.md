# 结构化素材插入修复 · b.3.2 工作树

2026-09-23。基于 b.3.2 发布提交 `ca8a8d8`，继续检查素材导入、复用、连续插入、保存重读、索引和分享导出。本轮不增加版本或提交、安装。

## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N64 | 有缩进的 YAML 对象包含行内素材列表时，插入内容固定使用两格缩进，导致合法列表无法追加素材。列表单独放在下一行时也可能失败。 | 按列表开始位置的实际缩进添加内容和结束符，支持连续追加，保留原有值、注释、BOM 和换行格式。 |
| N65 | 只有 YAML 指令、`---`、注释及结束标记的空文档被解析成隐式空值，插入器将其当作不支持的普通数值而拒绝。 | 识别没有显式值、标签或锚点的空文档，在注释之后、结束标记之前添加媒体列表。显式 `null`、数值、文本、标签及锚点仍受保护，不会被替换成对象。 |

插入只准备草稿，正文在用户保存后才写入。素材复用、文档和素材 UUID、原文中的注释与既有字段值保持完整，数据布局和迁移包格式不变。
