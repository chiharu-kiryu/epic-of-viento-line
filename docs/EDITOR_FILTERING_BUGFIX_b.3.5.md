# 编辑中的筛选与目录刷新修复 · b.3.5 工作树

2026-09-23。基于 b.3.5 发布提交 `c05024d`，检查 F11、F12、F15、F16、F18、F21：搜索、分类切换、开始编辑或新建、保存后重建，以及窄窗口侧栏。

## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N81 | 筛选列表时自动选择第一个匹配文档。当前文档不匹配时，源码/区块草稿会弹出放弃确认，干净的编辑会话或原文读取会被切走；保存后的内容不再匹配搜索时，重建会关闭刚保存的编辑器。 | 编辑、新建及原文读取期间保留当前选中文档，搜索和分类只更新列表。保存后继续编辑同一源文件及其重建条目，内容、输入模式、版本与未保存状态保持正确；明确点击另一份文档时仍执行原有确认。 |
| N82 | 搜索没有结果时提前结束刷新；保存后虽然目录已换成新对象，当前文档仍未交给显示层重新渲染。 | 即使筛选结果为空，也先刷新当前编辑文档的显示，再更新空结果提示。测试确认显示层收到最新目录条目。 |
| N83 | 窄窗口中，筛选触发的自动选中也执行收起侧栏。搜索框位于侧栏内，输入时侧栏会自动消失。 | 自动刷新保留侧栏状态，浏览与编辑均适用；明确点选文档仍可正常收起侧栏。 |

没有改变筛选匹配规则、文档与素材结构或磁盘正文。浏览模式仍自动选中匹配结果；调用方显式要求保留选中状态时继续遵从。
