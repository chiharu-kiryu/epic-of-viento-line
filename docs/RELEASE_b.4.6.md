# b.4.6 发布记录

2026-09-25。本版从 b.4.5 更新到 **b.4.6**，内部安装版本 **0.4.6**，下一版为 b.4.7。收录上一轮功能链路实测修复，并整理面向公开使用与开发的文档；项目格式、文档和素材的稳定 ID 保持兼容。

## 修复

- **完整下载后仍提示导出名额不足**：限制文件流的读取终点，避免客户端收齐内容并关闭连接后，服务还在等待多余的 EOF 读取。文档分享和完整项目导出均增加确定性回归，同时检查空文件、范围请求和真正中断的保护。
- **Android 键盘和系统栏遮挡编辑**：原生窗口处理系统栏、刘海和输入法边界，避免 WebView 重复留白；写作界面改为整页滚动，字段和源码输入能随键盘保持可见。
- **Android 取消文件选择后停留在忙碌状态**：系统选择器返回时等待 Activity 恢复，再交付迁移结果。实际模拟器连续交替取消 20 次，以及损坏包后的重试取消均通过。

## 发行边界

Android 继续作为功能预览：支持编辑与完整项目迁移，媒体访问 / 插入 / 播放、模板配置界面和文档分享尚未接入。APK 使用调试签名，不是商店发行包。实体手机、中日输入法组合输入、系统低内存回收、更多系统 / WebView 和第三方文件提供方仍待验证。
