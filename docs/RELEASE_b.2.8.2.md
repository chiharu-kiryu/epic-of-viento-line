# b.2.8.2 发布记录

2026-09-13。本次补丁收录音频资源引用、类型编辑返回操作，以及围绕功能链路排查和原生实测完成的修复。

## 本次更新

- **音频素材**：支持导入、拖入、筛选、复用配音、音乐和音效，正文内播放；文本、Markdown、JSON、YAML 共用稳定素材引用，分享和完整迁移携带原文件。见 [音频资源引用](AUDIO_RESOURCES.md)。
- **项目类型与模板**：新增类型提供取消与返回，离开未保存表单时确认；保存后等待索引刷新，失败可重试，并保留模板原有换行、缩进和 BOM。见 [项目工作流](PROJECT_WORKFLOW.md)。
- **编辑与索引**：修复同名不同格式的缓存冲突、局部重建范围错误、不可迁移的新建名称、旧文档身份被复用，以及迟到请求覆盖草稿或界面状态的问题。
- **归属与素材解析**：补齐结构化音视频和旧路径的引用索引，排除代码示例；正确区分文件名中的百分号与空格，导出附属背景故事时保留标题层级。
- **桌面与语言设置**：完善启动中退出、子进程回收、关闭确认和超时恢复；修复跨窗口语言切换被旧请求覆盖，关闭按钮随界面语言显示。已有编辑窗口时，作品库在选择目录和写入前限制新建、打开其他作品与导入。
- **导出与迁移**：修复下载后任务占位、活动下载被清理、原生保存等待期间缓存过期，以及失效任务无法重新生成；保留覆盖取消与失败重试。Node 与 Rust 归档共同校验正文、登记、素材指纹和可迁移路径，失败时保留旧目标并回滚未完成恢复。
- **维护资料**：保存 50 条业务链路的 [功能网络](FUNCTION_NETWORK.md)、离线交互图和源码指纹；[连续修复记录](NETWORK_BUGFIX_b.2.8.1.md) 枚举十轮 N01–N45 的触发条件、处理与验证。

## 版本规则

对外版本为 **b.2.8.2**，Tauri、Cargo、npm 与安装器的内部版本为 **2.8.2**。以根目录 [VERSION](../VERSION) 为准，同步应用清单、锁文件及编辑器和作品库的版本标识；完整规则沿用 [补丁号约定](RELEASE_b.2.8.1.md#版本规则)。

## 验证与数据

本次升版后使用应用内置 Node v24.20.0 执行程序检查，**193 项应用测试通过、无失败或跳过**，包括 v2/v3 项目的 Node/Rust 双向归档互通、正文/登记/外置素材逐字节比较。版本一致性、117 个 JavaScript 文件语法及 API 契约预检通过。Rust **22 项核心测试和 1 项启动测试通过**，原有 1 项依赖真实大体积作品的迁移测试按设置忽略；Rust 格式和功能图指纹、内嵌数据、源码引用及文档链接也完成检查。见 [验证结果与日志](test-results/release-b.2.8.2/results.json)。

首次用系统 Node v18.19.1 执行完整检查时，193 项断言通过，但请求生命周期测试进程在完成 4 项用例后持续占用 CPU、未退出；约三分钟后主动终止该进程，整次检查因此报告失败。该文件在系统和内置运行时各自复跑均为 4 项通过并正常退出，最终内置运行时的完整检查通过；此次退出异常的根因尚未确认，原始日志一并保留。

升版前的 [编辑器桌面实测](NATIVE_WORKFLOW_TEST_b.2.8.1.md)、[作品库实测](NATIVE_LIBRARY_TEST_b.2.8.1.md) 与 [导出实测](NATIVE_EXPORT_TEST_b.2.8.1.md) 保留当时的 b.2.8.1 版本、截图、日志及源码/二进制指纹；报告中的修复均包含在本次发布。此轮升版不重跑原生窗口交互，不代表已验证 Windows/macOS 安装包。

正文、模板、元数据和用户素材继续保存在独立作品库。本次提交包含程序、文档与临时样例的测试证据；不会迁移日常作品，也不会自动替换已安装的应用。安装包需从此版本重新构建。
