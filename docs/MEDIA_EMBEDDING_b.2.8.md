# 在编辑器中嵌入图片和视频

2026-09-12，应用版本 b.2.8。

进入文档编辑状态，点击 **插入图片 / 视频**：可以从电脑选择多个文件，也可以搜索、筛选并插入作品已有素材。图片可直接粘贴到编辑区，图片和视频均可拖入编辑区。文本、Markdown 的插入位置跟随当前光标；源码与区块模式均可使用。

编辑时显示素材预览，视频提供播放、暂停和进度控制，不自动播放。保存后，媒体在正文对应位置显示。导入完成后仍需保存文档；导入文件已进入作品素材库，取消文档编辑不会自动删除它们，之后可从列表再次选择。

## 文件与引用

支持 PNG、JPEG、WebP、GIF、SVG 图片，以及 MP4、WebM、MOV 视频。单个文件上限 256 MB。视频能否播放取决于容器内的编码及系统解码器；Linux 桌面验证覆盖 PNG 显示、VP8 WebM 和 H.264 MP4 的播放与跳转。无法解码或素材离线时会显示提示，视频仍提供原文件入口。

Linux AppImage 在启动 WebKit 前补充系统媒体插件目录，直接双击程序包也能使用已安装的解码器，不依赖本机安装脚本额外设置环境变量。

导入文件保存在作品当前素材存储中：

```text
assets/media/images/<UUID>.png
assets/media/videos/<UUID>.mp4
metadata/assets/<UUID>.json
```

若作品绑定了外置素材目录，文件进入该目录中的 `media/`；不会放入程序源码或安装目录。显示名称保留原文件名，实际文件名使用独立 ID，避免同名文件互相覆盖。内容一致且原文件完整时复用已有素材，不重复占用空间。

文本与 Markdown 使用以下媒体块：

```md
![角色立绘](asset:00000000-0000-0000-0000-000000000001)

!video[动作参考](asset:00000000-0000-0000-0000-000000000002)
```

`!video` 是 Viento 的视频扩展语法；图片沿用 Markdown 图片形式。代码围栏内的示例不会当作媒体渲染。已有 `assets/...` 本地路径继续可读。

JSON / YAML 会向 `媒体` 列表插入 `{type, src, caption}` 对象；根文档本身为列表时直接追加。已有同名非列表字段保留，改用 `媒体附件` 等空闲名称。插入按原文位置追加，保留既有值、注释、引号、BOM 和换行风格；语法不完整时提示先修正，不覆盖草稿。

## 保存和迁移

素材引用通过稳定 ID 解析，文档保存并重建后更新引用索引。完整作品备份同时包含正文、素材登记与原文件；恢复到不同目录后仍通过同一 ID 读取，不依赖本机绝对路径。外置素材在完整备份中归入 `assets/`。

上传中断或文件格式不符时清理未完成的临时文件；多文件导入中已完成的素材保留在列表中。导入期间暂时禁用保存、文档切换和退出编辑，保护插入位置与现有草稿。

## 验证

- `scripts/tests/media.test.mjs` 覆盖解析与渲染、JSON/YAML 原文保留、并发复用、上传中断、格式与大小拒绝、外置目录和链接边界、写入鉴权、分段读取、保存重建与异地恢复。
- `desktop/tests/native-smoke.py` 在隔离作品库的实际 Tauri / WebKit 窗口中验证选择、导入、预览、视频播放与跳转、窄窗口、粘贴与拖入、区块转换、保存和重新打开。
- 本次编辑器功能不迁移或改写现有作品正文与元数据。
