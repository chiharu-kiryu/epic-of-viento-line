# 导出准备与复查取消 · b.3.9 工作树

2026-09-23，基于 b.3.9 发布提交 `a55ddc0`，接续 N104–N105，第三十六轮检查 F32、F33、F35：读取登记 → 扫描文件 → 读取正文 → 最终复查 → 取消/输出失败 → 重新导出。仅使用临时作品，日常正文和素材未读取或修改。

## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N106 | 准备和最终复查没有把停止信号传入目录扫描与登记读取，取消后仍继续扫描、读取后续文件，延长任务忙碌时间。迟到的坏正文还可能把取消改报为解析错误；请求开始前已经取消时，仍可能先回收旧的已完成导出包。 | 贯穿传递取消信号，在异步文件操作返回后检查，并支持文件读取自身的取消。最终复查采用 ZIP 写入器的停止信号，输出失败也会停止剩余扫描。保留取消或首次写入错误，开始准备及回收名额前检查取消状态。 |

共享目录扫描、登记读取增加可选的取消参数；未提供时保持原有读取与校验。不能中止的当前文件操作仍需返回后才能收尾，后续目录和记录不再继续处理；沿用 N105 的实际文件关闭等待。未取消时，损坏正文和登记仍正常报错，修正后可以重试。

## 复现和验证

新增 [16 个场景](../scripts/tests/export-preparation.test.mjs)。最终测试文件在隔离副本中回放 N104–N105 工作树代码，得到 **13 个失败、3 个兼容场景通过**；修复后全部通过。回放源码指纹与功能图修订 48 一致，临时副本已清理。

- 文档分享和完整包：取消元数据目录扫描、记录读取或最终文件状态检查后，没有继续发起其他正文、模板、登记和素材读取。
- ZIP 写入失败但客户端没有取消时，两种导出的最终登记复查也会停止，保留原写入错误。
- 正文读取后取消，迟到的合法/损坏内容都保留取消结果；完整包的素材递归扫描也会停止。
- 已经取消的规划不读取元数据；已经取消的创建不回收三个仍可访问的已完成任务。
- 未取消的坏正文、坏登记仍被拒绝，恢复原字节后可成功导出。
- 真实 HTTP 请求在登记读取期间断开连接：服务停止剩余扫描，随后重新创建、下载和释放完整项目包成功。

文件操作在独立进程中对指定临时路径暂停，完成当前操作后再核对后续调用；没有依靠耗时阈值判断扫描是否停止。成功包和重试包独立解码并核对文件数量、大小、SHA-256 和准确内容，覆盖 BOM/CRLF 正文、模板、元数据、图片、视频与音频测试字节。
