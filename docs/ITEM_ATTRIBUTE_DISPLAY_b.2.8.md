# b.2.8 物品属性显示修复

2026-09-09。邪魔匕首的源文和标准化数据已经保留属性换行，但“关键参数”把整段内容当成一个值，并用 `white-space: nowrap` 显示，导致多项属性挤在一行并超出卡片。

修复后按属性名称逐行展示：

| 名称 | 数值 |
| --- | --- |
| 价格 | 4000 |
| 技能伤害 | +15% |
| 魔法上限 | +350 |
| 移动速度 | +20 |

- 统一识别 `属性`、`属性加成`、`属性加值`、`加成`，多个字段的补充条目都保留。
- 支持每行“数值 名称”“名称：数值”“名称 数值”，以及数组、对象形式的属性。
- 百分比、负数、零、等级公式和括号附注保留；无法拆分的文字继续显示，不丢弃说明。
- 物品卡片不再把金币、百分比和移动速度等不同单位画成相互比较的进度条。
- 基础信息不再重复已经显示的整段属性；窄卡片允许长名称和数值换行。

此变更只调整前端展示，原作品、元数据和转换格式不改写。实现位于 `web/modules/app-render.js` 和 `web/styles.css`。

新增 3 个回归用例在旧实现上失败，修复后通过。原生桌面测试增加物品选择、四行值核对、220px 卡片边界检查和截图，再继续原有编辑保存流程。完整结果见 `dist/current/verification.json`。
