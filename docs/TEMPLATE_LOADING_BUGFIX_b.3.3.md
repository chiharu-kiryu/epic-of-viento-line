## 修复

| 编号 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| N70 | 取消新建后，迟到的模板请求仍更新缓存或错误记录。旧成功响应能覆盖新模板缓存，旧失败也会使合法空模板显示加载失败，并记录与当前草稿无关的错误。 | 模板缓存、错误记录与正文应用使用同一个请求代次；仅当前请求可以更新缓存和诊断。已经接受的模板仍可复用，失败后仍可重新读取。 |
| N71 | 取消初次新建后重新新建同一类型，旧请求结束时，外层新建流程仍继续执行，把新草稿的光标与滚动位置重置。 | 模板应用明确返回是否仍有效；失效请求停止整个后续新建流程，保留新草稿的选择范围、滚动位置、路径、内容及未保存状态。 |
| N72 | 新建路径输入框不在正文编辑区域内。手动修改文件扩展名后，没有通知素材预览，迟到的旧路径解析结果还可能重新显示。 | 路径值发生变化时通知预览控制器，清除旧播放器并使用当前路径和类型解析；旧响应不能恢复预览，路径修改本身不重写正文。 |

缓存只存放在当前窗口内。本轮没有改变作品文件结构、正文格式、稳定 ID 或迁移包约定；新建保存仍使用当前草稿、当前路径和所选类型。
