# 界面语言

在作品库首页或编辑器右上角打开 **设置 → 界面语言**，选择 **简体中文 / English / 日本語**。切换立即生效，无需刷新页面。首次使用默认为简体中文。三种语言均随程序提供，不需要联网翻译。

语言切换保留当前文档、搜索与分类筛选、目录展开状态、源码、分段和字段草稿、保存位置以及素材播放状态。作品库与编辑器共享桌面应用的语言选择，关闭再打开应用后仍然有效。

界面翻译涵盖作品库、浏览与编辑操作、保存及冲突提示、素材选择、导出和应用提供的文件选择窗口标题。原生关闭确认的标题、正文和“继续编辑 / 关闭并丢弃”按钮也跟随应用语言。正文、文件名、角色名称、项目自行定义的类型标签、模板及元数据字段保持原文；语言设置不修改作品，也不随作品迁移包导出。操作系统提供的文件窗口按钮和底层原始诊断仍由系统或对应服务提供。

新建作品库窗口中尚未修改的默认名称随语言切换；一旦输入自己的名称，切换语言便保留该名称。项目自带的示例正文、类型名称和模板属于作品数据，仍按原文显示。

程序自动补充的“内容”章节标题跟随界面和导出语言；作者自己写的同名标题保持原文。该区分保存在新生成的布局中，已有索引需重新构建后生效。项目类型、模板、字段、素材和导出操作的已知错误原因也会翻译；提示显示之后再次切换语言，其内部原因同步更新，输入中的草稿仍保留。底层解析器或系统返回的未知原始诊断保留原文。相关验证见[翻译完善记录](TRANSLATION_REFINEMENT_b.4.3.md)。

中日文输入法组词期间，确认候选字不会触发正文、文件名或模板保存，也不会选择保存冲突操作；搜索在组词结束后再更新结果。小窗口中的工具栏可换行，阅读区按内容高度排列，长译文和封面不会挡住操作或正文。相关验证见[实际使用优化记录](USABILITY_INPUT_b.4.3.md)。

Android 预览版也提供这三种界面语言，并保留编辑草稿；它目前没有文档分享入口。语言选择保存在该应用 WebView 的本机存储中，清除应用数据或卸载后不再保留。系统文件选择器自己的按钮和语言仍由 Android 提供。

## 导出语言

桌面 / 浏览器文档分享包使用**点击开始导出时**的界面语言。离线网页的目录、关联素材标题、原文件下载按钮、页脚，以及 Markdown 的媒体标签和包内 `README.txt` 都跟随这一选择。生成期间再次切换界面语言不会混用已经开始的导出；下一次导出使用新选择。

导出的网页声明对应的 `lang`，原始正文保存在 `sources/`，素材与元数据保持原始字节。作品名称和媒体说明不翻译；网页 ZIP 文件名的格式后缀可随语言变化。完整项目包仍只保存作品数据，不带本机语言偏好。

## 存储与迁移

- 桌面版：使用 Tauri 应用配置目录内的 `preferences.json`。Linux 默认位置为 `~/.config/io.viento.studio/preferences.json`；文件与作品选择配置、最近作品列表分开保存。
- 浏览器版：保存在当前站点的本地存储 `viento-ui-language` 中，同源标签页自动同步。浏览器清除站点数据后恢复默认语言。
- 保存设置失败时显示提示，并保留当前已确认的语言；超时会中止尚未完成的请求，允许重试。已被宿主提交的选择仍以实际窗口通知为准。

作品库与编辑器先监听语言通知，再读取初始设置；读取或保存期间收到的新通知优先，迟到响应不会把界面切回旧语言。浏览器标签页按当前本地存储同步，忽略无关存储事件；删除语言设置或清除站点数据会同步恢复默认语言。读取到无效设置会提示失败，不会把损坏的值当作成功读取的默认值，也不会自动重写配置。

设置窗口中的进度、保存结果和错误提示随语言一起更新。处理保存时暂时锁定选择及关闭按钮，完成或失败后恢复操作。

## 增加语言

公共语言模块位于 `web/i18n/`。静态界面使用 `data-i18n` 标记，动态提示使用 `t()` 或带参数的模板字符串。只标记程序界面，不能对正文或任意 DOM 文本自动翻译。

`en.js` 和 `ja.js` 以简体中文原始提示作为键；参数采用 `{0}`、`{1}` 等占位符。`languages.js` 是浏览器与设置接口共享的语言列表，桌面宿主使用对应的语言枚举。`messages.js` 提供无共享语言状态的格式化函数，供界面和并发导出共同使用。普通字符串参数始终保留原文，它们可能是作者输入的内容；只用显式的 `uiMessage()` 包装嵌套界面消息，或用 `asUiMessage()` 保留已经由 `t()` 生成的消息结构，才能在之后切换语言时重新翻译内部原因。消息缓存按精确字符串匹配，不归一化全角字符或移除空格。

后端通过 `scripts/lib/user-message.mjs` 生成 `{ key, values }` 描述，响应保留兼容的 `error` 字符串，并可附带 `userMessage`；配置警告使用对应的 `problemMessage`、`warningMessages` 或 `indexWarningMessage`。前端 `diagnostics.js` 只接受词典中已知的键和受限的嵌套结构，文件名、路径与作者标签均为原样参数。新增诊断应补充两份词典，不能通过替换任意错误文本片段来猜测翻译。

增加语言时补充词典、公共语言列表和桌面宿主枚举。`scripts/tests/i18n-coverage.test.mjs` 检查词典键一致、重复条目、空译文、参数完整性及宿主语言列表；通过 Acorn 解析已标记的界面、导出和后端诊断代码，发现新增文字漏译。Acorn 只用于开发检查，不进入桌面运行包。`npm test` 和 `npm run check -- --app-only` 都会执行这些检查。

[设置工作流回归](../scripts/tests/settings.test.mjs) 执行真实语言模块、设置控制器和作品库入口，控制初始读取、通知与保存回复的先后次序，覆盖跨窗口同步、失败重试、存储清除及草稿文本/选区/路径保留；另用真实本地 HTTP 连接验证保存超时确实中止请求。此测试不替代原生窗口交互测试。

桌面准备步骤将这份公共模块复制到作品库界面，无需维护第二套翻译。副本 `desktop/ui/i18n/` 属于生成文件，不提交、不加入源码包，可由准备命令重新生成。

设置 `VIENTO_TEST_LANGUAGE=1` 运行 `desktop/tests/native-smoke.py`，可验证英文、日语设置经过实际桌面应用重启后仍有效，切换语言时草稿及作品文件保持一致。配合 `VIENTO_TEST_GENERIC_CREATE` 和 `VIENTO_TEST_XDOTOOL`，还会验证日语原生保存窗口、取消重试、两种导出与完整恢复；默认的旧项目场景覆盖中日原生关闭确认与跨窗口通知。
