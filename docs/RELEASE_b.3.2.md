# b.3.2 发布记录

2026-09-23。本补丁收录第十五、十六轮功能链路检查中的 **N59–N63 共 5 处修复**，发布版本由 b.3.1 更新为 **b.3.2**，内部安装版本为 **0.3.2**。

## 本次修复

- 分享导出携带正文中声明的素材 ID 和旧图片路径引用；未知 ID 或缺失文件会明确报错，修复后可重试。
- 同一素材具有多个附件角色时，每篇文档只追加一次关联素材展示；正文嵌入、附属故事和原有角色绑定保留。
- 相对图片路径按原始正文目录解析，修复 v2、v3 项目中引用和缺失提示被遗漏的问题。
- “新增类型”使用已有标识时会被拒绝，避免覆盖旧类型规则和模板；失败后保留草稿，支持修改重试或取消。
- 类型模板的默认目录与新建文档共用校验，提前拒绝隐藏、保留或过长目录；旧配置仍能打开并修正。

功能图更新为修订 22，保留前十六轮复现与验证证据。逐项记录见 [素材引用与分享导出修复](EXPORT_REFERENCES_BUGFIX_b.3.1.md) 和 [项目类型与模板修复](PROJECT_SETTINGS_BUGFIX_b.3.1.md)，两份排查报告保留当时的 b.3.1 标记。

正文、文档与素材 ID、归属关系和完整迁移包格式保持兼容，无需手工迁移作品。版本编号继续遵循 [既定进位规则](RELEASE_b.2.9.md#版本规则)。

## 验证

b.3.2 完整应用检查 **243 项：242 通过、0 失败、1 跳过**；120 份 JavaScript 语法、版本一致性及 API 契约预检通过。跳过项需要额外的原生归档互通工具，本轮原生归档代码未变。

发布检查核对 Cargo 清单与锁文件、功能图引用、源码包逐文件内容及解包后的依赖解析，确认仍使用包内的 glib 修复副本。证据见 [发布验证记录](test-results/release-b.3.2/results.json)。本次未重跑 Rust 或原生窗口交互，未构建或安装桌面包；测试使用临时作品，验证源码包在检查后清理。
